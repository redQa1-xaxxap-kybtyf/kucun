## 按钮变体规范

### 1. 变体类型

项目使用 shadcn/ui Button 组件,支持以下变体:

```typescript
type ButtonVariant =
  | 'default' // 主要操作(蓝色背景)
  | 'destructive' // 危险操作(红色背景)
  | 'outline' // 次要操作(边框样式)
  | 'secondary' // 辅助操作(灰色背景)
  | 'ghost' // 幽灵按钮(透明背景)
  | 'link'; // 链接样式
```

### 2. 使用场景

| 操作类型     | 推荐变体      | 使用场景                 | 示例                   |
| ------------ | ------------- | ------------------------ | ---------------------- |
| **主要操作** | `default`     | 页面主要操作按钮         | 新建、保存、提交、确认 |
| **次要操作** | `outline`     | 辅助操作按钮             | 取消、关闭、返回、导出 |
| **危险操作** | `destructive` | 删除、作废等不可逆操作   | 删除、作废、清空       |
| **文本操作** | `ghost`       | 表格行内操作、下拉菜单项 | 编辑、查看、详情       |
| **链接操作** | `link`        | 跳转链接                 | 查看详情、了解更多     |
| **辅助操作** | `secondary`   | 不常用的辅助操作         | -                      |

### 3. 代码示例

#### ✅ 正确示例

```tsx
// 主要操作 - 使用 default 变体
<Button variant="default" onClick={handleSave}>
  <Save className="mr-2 h-4 w-4" />
  保存
</Button>

// 次要操作 - 使用 outline 变体
<Button variant="outline" onClick={handleCancel}>
  取消
</Button>

// 危险操作 - 使用 destructive 变体
<Button variant="destructive" onClick={handleDelete}>
  <Trash2 className="mr-2 h-4 w-4" />
  删除
</Button>

// 表格行内操作 - 使用 ghost 变体
<Button variant="ghost" size="sm" onClick={handleEdit}>
  <Pencil className="h-4 w-4" />
</Button>
```

#### ❌ 错误示例

```tsx
// ❌ 错误: 删除操作未使用 destructive 变体
<Button variant="default" onClick={handleDelete}>删除</Button>

// ❌ 错误: 取消操作使用了 default 变体
<Button variant="default" onClick={handleCancel}>取消</Button>

// ❌ 错误: 表格行内操作使用了 outline 变体
<Button variant="outline" size="sm" onClick={handleEdit}>编辑</Button>
```

## 按钮尺寸规范

### 1. 尺寸类型

```typescript
type ButtonSize =
  | 'default' // 默认尺寸 (h-10, 40px)
  | 'sm' // 小尺寸 (h-9, 36px)
  | 'lg' // 大尺寸 (h-11, 44px)
  | 'icon'; // 图标按钮 (h-10 w-10, 40x40px)
```

### 2. 使用场景

| 使用场景           | 推荐尺寸          | 说明                                        |
| ------------------ | ----------------- | ------------------------------------------- |
| **列表页面工具栏** | `lg`              | 页面头部主要操作按钮,使用大尺寸增强视觉层次 |
| **表单提交按钮**   | `default`         | 表单底部的提交/取消按钮,使用默认尺寸        |
| **对话框操作**     | `default`         | 对话框底部的确认/取消按钮,使用默认尺寸      |
| **表格行内操作**   | `sm` 或 `icon`    | 节省空间,使用小尺寸或图标按钮               |
| **移动端按钮**     | `default` 或 `lg` | 考虑触摸友好性,使用默认或大尺寸             |

### 3. 代码示例

#### ✅ 正确示例

```tsx
// 列表页面工具栏 - 使用 lg 尺寸
<Button size="lg" className="h-11">
  <Plus className="mr-2 h-4 w-4" />
  新建客户
</Button>

// 表单提交按钮 - 使用 default 尺寸
<Button type="submit">保存</Button>

// 表格行内操作 - 使用 sm 尺寸或 icon 尺寸
<Button variant="ghost" size="sm">
  <Pencil className="h-4 w-4" />
</Button>

<Button variant="ghost" size="icon">
  <MoreHorizontal className="h-4 w-4" />
</Button>
```

## 按钮图标规范

### 1. 图标使用原则

- ✅ **主要操作按钮**: 推荐使用图标,增强识别度
- ✅ **表格行内操作**: 推荐只使用图标,节省空间
- ❌ **次要操作按钮**: 可选使用图标
- ❌ **文字按钮**: 不推荐使用图标

### 2. 图标位置

- **图标 + 文字**: 图标在左侧,使用 `mr-2` 间距
- **只有图标**: 不需要间距

### 3. 图标尺寸

- **默认尺寸**: `h-4 w-4` (16x16px)
- **大按钮图标**: `h-5 w-5` (20x20px) - 仅用于 `size="lg"` 的按钮

### 4. 推荐图标

| 操作类型  | 推荐图标         | 来源         |
| --------- | ---------------- | ------------ |
| 新建/创建 | `Plus`           | lucide-react |
| 编辑      | `Pencil`         | lucide-react |
| 删除      | `Trash2`         | lucide-react |
| 保存      | `Save`           | lucide-react |
| 导出      | `Download`       | lucide-react |
| 导入      | `Upload`         | lucide-react |
| 搜索      | `Search`         | lucide-react |
| 刷新      | `RefreshCw`      | lucide-react |
| 返回      | `ArrowLeft`      | lucide-react |
| 查看      | `Eye`            | lucide-react |
| 更多操作  | `MoreHorizontal` | lucide-react |

### 5. 代码示例

#### ✅ 正确示例

```tsx
// 图标 + 文字 - 图标在左侧,使用 mr-2 间距
<Button>
  <Plus className="mr-2 h-4 w-4" />
  新建客户
</Button>

// 只有图标 - 不需要间距
<Button variant="ghost" size="icon">
  <Pencil className="h-4 w-4" />
</Button>

// 大按钮图标 - 使用 h-5 w-5
<Button size="lg">
  <Plus className="mr-2 h-5 w-5" />
  新建订单
</Button>
```

#### ❌ 错误示例

```tsx
// ❌ 错误: 图标在右侧
<Button>
  新建客户
  <Plus className="ml-2 h-4 w-4" />
</Button>

// ❌ 错误: 图标尺寸不一致
<Button>
  <Plus className="mr-2 h-3 w-3" />  {/* 应该使用 h-4 w-4 */}
  新建客户
</Button>

// ❌ 错误: 只有图标但使用了间距
<Button variant="ghost" size="icon">
  <Pencil className="mr-2 h-4 w-4" />  {/* 不应该有 mr-2 */}
</Button>
```

## 按钮文案规范

### 1. 统一术语

| 操作类型 | 推荐文案  | 避免使用               | 说明           |
| -------- | --------- | ---------------------- | -------------- |
| 新建     | "新建XXX" | "添加"、"创建"、"新增" | 统一使用"新建" |
| 编辑     | "编辑"    | "修改"、"更新"         | 统一使用"编辑" |
| 删除     | "删除"    | "移除"、"清除"         | 统一使用"删除" |
| 保存     | "保存"    | "确定"、"提交"         | 统一使用"保存" |
| 取消     | "取消"    | "关闭"、"返回"         | 统一使用"取消" |
| 导出     | "导出"    | "下载"                 | 统一使用"导出" |
| 导入     | "导入"    | "上传"                 | 统一使用"导入" |
| 确认     | "确认"    | "确定"、"OK"           | 统一使用"确认" |

### 2. 文案长度

- **简洁明了**: 2-6个字为宜
- **避免冗长**: 不超过8个字
- **语义清晰**: 用户一眼能看懂操作含义

### 3. 代码示例

#### ✅ 正确示例

```tsx
<Button>新建客户</Button>  {/* ✅ 使用"新建" */}
<Button>编辑</Button>      {/* ✅ 使用"编辑" */}
<Button>删除</Button>      {/* ✅ 使用"删除" */}
<Button>保存</Button>      {/* ✅ 使用"保存" */}
<Button>取消</Button>      {/* ✅ 使用"取消" */}
```

#### ❌ 错误示例

```tsx
<Button>添加客户</Button>  {/* ❌ 应该使用"新建客户" */}
<Button>修改</Button>      {/* ❌ 应该使用"编辑" */}
<Button>移除</Button>      {/* ❌ 应该使用"删除" */}
<Button>确定</Button>      {/* ❌ 应该使用"保存"或"确认" */}
<Button>关闭</Button>      {/* ❌ 应该使用"取消" */}
```

## 按钮组合规范

### 1. 对话框底部按钮

**规则**: 取消在左,确认在右

```tsx
// ✅ 正确
<DialogFooter>
  <Button variant="outline" onClick={onCancel}>取消</Button>
  <Button variant="default" onClick={onConfirm}>确认</Button>
</DialogFooter>

// ❌ 错误: 顺序颠倒
<DialogFooter>
  <Button variant="default" onClick={onConfirm}>确认</Button>
  <Button variant="outline" onClick={onCancel}>取消</Button>
</DialogFooter>
```

### 2. 列表页面工具栏按钮

**规则**: 主要操作在左,次要操作在右

```tsx
// ✅ 正确
<div className="flex items-center gap-2">
  <Button variant="default" size="lg">
    <Plus className="mr-2 h-4 w-4" />
    新建客户
  </Button>
  <Button variant="outline" size="lg">
    <Download className="mr-2 h-4 w-4" />
    导出
  </Button>
</div>
```

### 3. 表格行内操作按钮

**规则**: 使用 `ghost` 变体 + `sm` 或 `icon` 尺寸

```tsx
// ✅ 正确
<div className="flex items-center gap-1">
  <Button variant="ghost" size="sm" onClick={onEdit}>
    <Pencil className="h-4 w-4" />
  </Button>
  <Button variant="ghost" size="sm" onClick={onDelete}>
    <Trash2 className="h-4 w-4" />
  </Button>
</div>
```

### 4. 表单底部按钮

**规则**: 取消在左,提交在右

```tsx
// ✅ 正确
<div className="flex justify-end gap-4">
  <Button type="button" variant="outline" onClick={onCancel}>
    取消
  </Button>
  <Button type="submit">保存</Button>
</div>
```

## 最佳实践

### 1. 使用语义化的 variant

```tsx
// ✅ 正确: 删除操作使用 destructive 变体
<Button variant="destructive" onClick={handleDelete}>
  <Trash2 className="mr-2 h-4 w-4" />
  删除
</Button>

// ❌ 错误: 删除操作使用 default 变体
<Button variant="default" onClick={handleDelete}>删除</Button>
```

### 2. 保持一致的图标位置

```tsx
// ✅ 正确: 图标始终在左侧
<Button><Plus className="mr-2 h-4 w-4" />新建</Button>
<Button><Save className="mr-2 h-4 w-4" />保存</Button>
<Button><Download className="mr-2 h-4 w-4" />导出</Button>
```

### 3. 使用合适的尺寸

```tsx
// ✅ 正确: 页面头部使用 lg 尺寸
<PageHeader
  actions={
    <Button size="lg">
      <Plus className="mr-2 h-4 w-4" />
      新建客户
    </Button>
  }
/>

// ✅ 正确: 表格行内使用 sm 尺寸
<TableCell>
  <Button variant="ghost" size="sm">
    <Pencil className="h-4 w-4" />
  </Button>
</TableCell>
```

## 反模式

### ❌ 不要手动设置颜色

```tsx
// ❌ 错误: 手动设置颜色
<Button className="bg-red-500 text-white">删除</Button>

// ✅ 正确: 使用 destructive 变体
<Button variant="destructive">删除</Button>
```

### ❌ 不要混用不同的文案

```tsx
// ❌ 错误: 同一操作使用不同文案
<Button>新建客户</Button>  // 客户页面
<Button>添加产品</Button>  // 产品页面
<Button>创建订单</Button>  // 订单页面

// ✅ 正确: 统一使用"新建"
<Button>新建客户</Button>
<Button>新建产品</Button>
<Button>新建订单</Button>
```

### ❌ 不要在表格行内使用大按钮

```tsx
// ❌ 错误: 表格行内使用 default 尺寸
<TableCell>
  <Button variant="ghost">编辑</Button>
</TableCell>

// ✅ 正确: 使用 sm 尺寸或 icon 尺寸
<TableCell>
  <Button variant="ghost" size="sm">
    <Pencil className="h-4 w-4" />
  </Button>
</TableCell>
```

## 🎯 常见问题

### Q1: 什么时候使用 `default` 变体,什么时候使用 `outline` 变体?

**A**:

- **`default`**: 页面主要操作,用户最常用的功能(如"新建"、"保存"、"提交")
- **`outline`**: 次要操作,辅助功能(如"取消"、"导出"、"返回")

### Q2: 表格行内操作按钮应该使用什么尺寸?

**A**:

- **推荐**: `size="sm"` 或 `size="icon"`
- **变体**: `variant="ghost"`
- **原因**: 节省空间,避免表格过于拥挤

### Q3: 删除按钮一定要使用 `destructive` 变体吗?

**A**:

- **是的**,所有危险操作(删除、作废、清空等)都应该使用 `destructive` 变体
- **原因**: 提醒用户这是危险操作,避免误操作

### Q4: 对话框底部按钮的顺序是什么?

**A**:

- **规则**: 取消在左,确认在右
- **原因**: 符合用户习惯,避免误操作

### Q5: 按钮图标应该放在左边还是右边?

**A**:

- **规则**: 图标始终在左边
- **间距**: 使用 `mr-2` (8px)
- **例外**: 只有图标的按钮不需要间距
