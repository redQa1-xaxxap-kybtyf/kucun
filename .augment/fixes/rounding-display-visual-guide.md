## 用户操作流程

### 查看订单抹零信息

1. 打开销售订单详情页面
2. 查看顶部统计卡片
3. 找到"订单抹零"卡片
4. 查看金额和说明(加价/减价)

### 查看收款记录明细

1. 滚动到"收款记录"区域
2. 查看"订单金额总览"
3. 查看每笔收款记录
4. 如果有抹零，会显示"实际到账 + 抹零"明细

### 理解金额计算

1. **实际应收** = 订单总金额 + 订单抹零
2. **等效已收款** = 实际到账汇总 + 收款抹零汇总
3. **待收金额** = 实际应收 - 等效已收款

## 常见问题

### Q1: 为什么订单抹零统一显示负号?

**A**: 为了统一显示格式，便于用户理解。负号表示这是对订单总额的调整:
- 加价: -¥10.00 (加价) → 实际应收增加
- 减价: -¥10.00 (减价) → 实际应收减少

### Q2: 收款抹零和订单抹零有什么区别?

**A**: 
- **订单抹零**: 订单创建时设定，影响实际应收金额
- **收款抹零**: 收款时的优惠减免，影响实际到账金额

### Q3: 为什么有时候看不到抹零明细?

**A**: 只有当抹零金额不为0时才显示明细，保持界面简洁。

### Q4: 实际到账金额和等效已收款有什么区别?

**A**:
- **实际到账金额**: 真正到账的金额 (不含抹零)
- **等效已收款**: 实际到账 + 收款抹零 (视为已收款)
