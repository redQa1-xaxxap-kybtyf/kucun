# 关键业务 E2E 验收

## 目标

商业交付前，必须证明核心链路能在接近生产的配置下跑通，而不是只证明单个页面能打开。

## 自动化入口

```bash
npm run test:business-fullchain
npm run test:e2e
```

如 E2E 环境尚未完全配置，至少完成下面的手工验收并记录截图/订单号/数据 ID。

## 必测链路

| 链路 | 验收点 |
| --- | --- |
| 登录与权限 | 登录、退出、改密、禁用用户、权限不足页面 |
| 产品与分类 | 新建分类、产品、规格、图片；禁用/删除限制 |
| 入库 | 正常入库、期初库存、破损入库、库存批次生成 |
| 出库 | 销售出库、手动出库、库存不足拦截 |
| 盘点 | 创建、开始、提交、完成盘点，差异生成调整 |
| 销售订单 | 创建草稿、确认、扣库存、收款、取消/回滚 |
| 退货退款 | 退货审批、退款、库存回流、往来账变化 |
| 采购/厂家发货 | 下单、到货、入库、费用、应付账款 |
| 财务 | 应收、应付、收付款、月报、利润报表 |
| 打印 | 模板预览、真实单据打印/导出 |
| 小程序 | 商品目录、详情、图片、调货请求 |

## 阻断条件

- 任一核心链路出现 5xx。
- 金额、库存、往来账不一致。
- 低权限用户能访问管理员/财务/成本能力。
- 生产开关检查失败。
- 备份恢复演练失败或未执行。
