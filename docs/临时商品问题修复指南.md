# 临时商品未保存问题 - 快速修复指南

## 🎯 问题概述

**症状**：调货销售订单中手动添加的临时商品未保存到 `temporary_products` 表

**影响**：无法在后续订单中复用临时商品，每次都需要重新输入

**根本原因**：前端提交的数据中 `productCode` 字段可能为空，导致后端跳过临时商品创建逻辑

## 🔍 快速诊断

### 方法 1: 运行诊断脚本

```bash
npx tsx scripts/diagnose-temporary-products.ts
```

查看输出中的"临时商品创建成功率"，如果为 0% 则确认存在问题。

### 方法 2: 直接查询数据库

```bash
# MySQL
mysql -u root -p kucun_dev < scripts/check-temporary-products.sql

# 或者直接查询
mysql -u root -p kucun_dev -e "
SELECT
  COUNT(*) AS manual_items,
  SUM(CASE WHEN temporary_product_id IS NOT NULL THEN 1 ELSE 0 END) AS with_temp,
  SUM(CASE WHEN temporary_product_id IS NULL THEN 1 ELSE 0 END) AS without_temp
FROM sales_order_items soi
JOIN sales_orders so ON soi.sales_order_id = so.id
WHERE soi.is_manual_product = 1 AND so.order_type = 'TRANSFER';
"
```

### 步骤 3: 用户操作指导

**问题可能出在用户操作上**：

1. 用户在添加临时商品时**没有填写产品编码**
2. 或者填写了产品编码但**没有点击"添加商品"按钮**

**解决方案**：

#### 方案 A: 增强前端提示（推荐）

在临时商品对话框中添加更明显的提示：


#### 方案 B: 增强后端验证（推荐）

修改 `lib/validations/sales-order/validators.ts`，为调货销售强制要求 `productCode`：

```typescript
export function validateManualProductFields(
  items: SalesOrderItemFormData[],
  status: string,
  orderType?: 'NORMAL' | 'TRANSFER'
): boolean {
  // ✅ 调货销售的手动商品必须有 productCode（包括草稿状态）
  if (orderType === 'TRANSFER') {
    for (const item of items) {
      if (item.isManualProduct) {
        const hasCode =
          typeof item.productCode === 'string' &&
          item.productCode.trim() !== '';
        if (!hasCode) {
          return false;
        }
      }
    }
  }

  // 非草稿状态的其他验证
  if (status !== 'draft') {
    for (const item of items) {
      if (item.isManualProduct) {
        const hasCode =
          typeof item.productCode === 'string' &&
          item.productCode.trim() !== '';
        if (!hasCode) {
          return false;
        }
      } else {
        if (!item.productId || item.productId.trim() === '') {
          return false;
        }
      }
    }
  }

  return true;
}
```

## 🎓 用户培训

### 正确的操作流程

1. **创建调货销售订单**
2. **选择供应商**（必须）
3. **添加商品**：
   - 点击"添加临时商品"
   - **填写产品编码**（必填）
   - 填写商品名称（可选，但推荐填写）
   - 填写规格、重量等信息
   - 点击"添加商品"按钮
4. **填写数量和价格**
5. **提交订单**

### 常见错误

❌ **错误 1**：没有填写产品编码

- **后果**：临时商品不会被保存
- **解决**：必须填写产品编码

❌ **错误 2**：没有选择供应商

- **后果**：临时商品不会被保存
- **解决**：必须先选择供应商

❌ **错误 3**：使用了库存商品而不是临时商品

- **后果**：不会创建临时商品记录
- **解决**：确认使用"添加临时商品"功能
