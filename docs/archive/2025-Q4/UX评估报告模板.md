> 用途：把“主观评价”变成“可复核交付物”。建议每次评估都输出本模板所列的最小字段，并在结论处标注置信度（✅/⚠️/❌）。

## 2. 评估方法与样本

### 2.1 启发式走查（Heuristic Review）

- 使用规则：Nielsen 10 原则 / 自定义 ERP 规则（列出清单链接）
- 覆盖页面：
- 输出物：问题清单（含严重级别 S0~S3）、截图、复现步骤、建议方案

### 2.2 任务型可用性测试（Task-based）

| 任务 | 目标用户 | 成功标准 | 样本量 | 成功率 | 平均耗时 | 主要阻塞点 |
|---|---|---|---:|---:|---:|---|
| 例：创建采购单并入库 | 仓库 | 订单生成且库存增加 |  |  |  |  |

### 2.3 可访问性（Accessibility）

- 工具：axe / Lighthouse / 手工键盘走查
- 指标：对比度抽样、键盘可达性、ARIA 语义、焦点管理
- 输出物：扫描报告 + 问题清单（含截图/定位/建议）

### 2.4 性能（Performance）

- 工具：Lighthouse / WebPageTest / RUM（线上真实监控）
- 口径：样本量、环境、统计分位（P75/P95）
- 输出物：页面指标 + API 延迟分位 + 慢查询样本
