## 📊 问题回顾

### 原始问题

- 用户在数字字段（`inputQuantity`、`unitCost` 等）中**不输入任何内容**
- 点击"提交"按钮
- **前端没有显示验证错误**（字段没有红色高亮，没有错误信息）
- 请求直接发送到后端
- **后端返回验证错误**，用户才看到错误提示

### 根本原因

Zod Schema 的 `z.preprocess` 逻辑问题：

- 当用户不填写字段时，`val` 为 `undefined`
- 预处理函数返回 `undefined`
- `z.number()` 接收到 `undefined`
- **但是 `z.number()` 默认是可选的**，所以 `undefined` 通过了验证！

---

## ✅ 修复方案

### 核心修改

在 `lib/validations/inbound.ts` 中为必填数字字段添加 `required_error` 和 `invalid_type_error`：

```typescript
// 修改前
z.number({ message: '数量必须是数字' });

// 修改后
z.number({
  required_error: '请填写入库数量',
  invalid_type_error: '数量必须是数字',
});
```

### 修改的字段

#### 1. `inputQuantity` 字段（第37-53行）

```typescript
inputQuantity: z.preprocess(
  val => {
    if (val === undefined || val === null || val === '') {
      return undefined;
    }
    const num = typeof val === 'number' ? val : Number(val);
    return Number.isNaN(num) ? undefined : num;
  },
  z
    .number({
      required_error: '请填写入库数量',  // ✅ 添加
      invalid_type_error: '数量必须是数字',  // ✅ 添加
    })
    .min(1, { message: '数量必须大于等于1' })
    .max(999999, { message: '数量不能超过999999' })
    .int({ message: '数量必须是整数' })
),
```

#### 2. `quantity` 字段（第58-76行）

