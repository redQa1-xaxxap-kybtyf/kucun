# 采购单创建页面表格列宽优化

## 📋 优化概述

**优化日期**: 2025-01-24  
**优化目标**: 优化采购单创建页面的表格列宽分配，提升用户体验  
**影响文件**:

- `components/purchase-orders/purchase-order-items-table.tsx`
- `components/purchase-orders/purchase-order-item-row.tsx`

---

## 🎯 优化目标

### 问题描述

1. **备注列占用宽度过大**：使用 `min-w-[150px]` 无最大宽度限制，导致表格横向过宽
2. **列宽分配不合理**：未根据内容重要性和长度优化列宽
3. **用户体验不佳**：表格需要频繁横向滚动，重要信息不能一目了然

### 优化要求

1. 限制备注列宽度，避免浪费空间
2. 优化其他列宽，提升重要信息的可见性
3. 保持表格整体视觉平衡

---

## ✅ 优化方案

### 1. 列宽调整对比

| 列名     | 优化前          | 优化后                    | 变化说明                                 |
| -------- | --------------- | ------------------------- | ---------------------------------------- |
| 序号     | `w-[50px]`      | `w-[50px]`                | ✅ 保持不变                              |
| 产品信息 | `w-[180px]`     | `w-[200px]`               | ⬆️ 增加 20px，提升可读性                 |
| 供应商   | `w-[160px]`     | `w-[160px]`               | ✅ 保持不变                              |
| 规格     | `w-[120px]`     | `w-[120px]`               | ✅ 保持不变                              |
| 批次号   | `w-[120px]`     | `w-[120px]`               | ✅ 保持不变                              |
| 数量     | `w-[100px]`     | `w-[100px]`               | ✅ 保持不变                              |
| 单位     | `w-[70px]`      | `w-[70px]`                | ✅ 保持不变                              |
| 每件片数 | `w-[90px]`      | `w-[90px]`                | ✅ 保持不变                              |
| 采购单价 | `w-[100px]`     | `w-[120px]`               | ⬆️ 增加 20px，金额更清晰                 |
| 总价     | `w-[100px]`     | `w-[120px]`               | ⬆️ 增加 20px，金额更清晰                 |
| **备注** | `min-w-[150px]` | `w-[180px] max-w-[180px]` | 🎯 **核心优化：固定宽度 + 最大宽度限制** |
| 操作     | `w-[60px]`      | `w-[80px]`                | ⬆️ 增加 20px，按钮更易点击               |

### 2. 备注列优化细节

#### 表头优化

```tsx
// 优化前
<TableHead className="h-10 min-w-[150px] border-r py-2 text-xs font-medium text-foreground">
  备注
</TableHead>

// 优化后
<TableHead className="h-10 w-[180px] max-w-[180px] border-r py-2 text-xs font-medium text-foreground">
  备注
</TableHead>
```

#### 单元格优化

```tsx
// 优化前
<Input {...field} placeholder={placeholder} className="h-9 text-sm" />

// 优化后
<Input
  {...field}
  placeholder={placeholder}
  className={cn(
    'h-9 text-sm',
    isRemarksField && 'max-w-[180px]'  // 备注列添加最大宽度
  )}
  title={isRemarksField && field.value ? String(field.value) : undefined}  // 鼠标悬停显示完整内容
/>
```

### 2. 备注输入框优化

**文件**: `components/purchase-orders/purchase-order-item-row.tsx`

```tsx
function TextInputCell({
  form,
  name,
  placeholder,
  cellClassName,
}: TextInputCellProps) {
  // 判断是否为备注列
  const isRemarksField = name.includes('remarks');

  return (
    <TableCell className={cn('border-r px-3 py-3', cellClassName)}>
      <FormField
        control={form.control}
        name={name}
        render={({ field }) => (
          <FormItem>
            <FormControl>
              <Input
                {...field}
                placeholder={placeholder}
                className={cn(
                  'h-9 text-sm',
                  isRemarksField && 'max-w-[180px]' // 备注列限制最大宽度
                )}
                title={
                  isRemarksField && field.value
                    ? String(field.value)
                    : undefined
                } // 悬停提示
              />
            </FormControl>
            <FormMessage />
          </FormItem>
        )}
      />
    </TableCell>
  );
}
```
