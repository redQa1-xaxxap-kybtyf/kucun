### 根本原因

**InventoryCount 和 InventoryCountItem 模型缺少多个关系定义**：

#### InventoryCount 模型缺失（4 个）：
1. ❌ `creator` - 有 `creatorId` 外键但无 `@relation`
2. ❌ `operator` - 有 `operatorId` 外键但无 `@relation`
3. ❌ `approver` - 有 `approverId` 外键但无 `@relation`
4. ❌ `items` - 缺少反向关系（`InventoryCountItem[]`）

#### InventoryCountItem 模型缺失（3 个）：
1. ❌ `count` - 有 `countId` 外键但无 `@relation`
2. ❌ `variant` - 有 `variantId` 外键但无 `@relation`
3. ❌ `counter` - 有 `countedBy` 外键但无 `@relation`

**这是第 27-33 个相同模式的 Prisma 关系定义缺失问题！**

## 🛠️ 修复方案

### 修复策略

遵循之前修复 26 个错误的相同模式：

1. **添加前向关系**: 在模型中定义所有缺失的 `@relation`
2. **添加反向关系**: 在目标模型中添加数组类型的反向关系
3. **使用命名关系**: 区分 User 的多种角色（creator、operator、approver、counter）
4. **使用正确的 onDelete 策略**:
   - `Restrict` - 核心数据（User 作为 creator）
   - `SetNull` - 可选关系（operator、approver、variant、counter）
   - `Cascade` - 从属数据（InventoryCountItem 依赖 InventoryCount）

### 修复代码
