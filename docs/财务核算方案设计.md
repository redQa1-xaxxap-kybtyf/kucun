本系统已运行一段时间，现需为已有库房设计完整的财务核算方案，实现：

- ✅ 期初库存数据的准确录入和成本确定

3. **数据准确性**: 所有成本计算保留2位小数，使用事务保证一致性
4. **审计追溯**: 所有财务操作记录完整的审计日志

### 1.3 现状分析

**已有功能**:

- ✅ 库存管理 (Inventory 表，支持 unitCost)

## 2. 期初库存处理方案

### 2.1 业务场景

系统上线时，需要将现有库存数据导入系统，包括：

- 产品信息（已存在）
- 库存数量
- **期初成本**（关键）

### 2.2 行业标准处理流程

根据ERP系统实施的行业最佳实践，期初库存处理遵循以下标准流程：

```
阶段1: 数据准备（上线前1-2周）
├─ 实物盘点：仓库全面盘点，确定实际库存数量
├─ 成本确定：财务查账，确定每个产品的账面成本
└─ 数据整理：编制Excel导入模板

阶段2: 数据导入（上线前1-3天）
├─ 基础资料：产品、客户、供应商信息
├─ 期初库存：数量 + 成本价格
└─ 期初余额：应收、应付、现金等

阶段3: 数据验证（上线当天）
├─ 核对总账：库存金额 = 数量 × 成本
├─ 试运行：测试几笔业务
└─ 正式上线
```

**关键原则**：

- ✅ **数据准确性优先**：期初数据直接影响后续所有财务核算
- ✅ **财务审批必须**：所有期初数据必须经财务主管审批
- ✅ **批次管理重要**：瓷砖行业需按批次和色号分别录入

### 2.3 期初成本确定方法

#### 方法1: 财务查账法（推荐）✅

**适用场景**: 系统初次上线，有财务账本记录

**操作流程**:

```
1. 财务翻阅账本，找到每个产品的采购记录
2. 使用最近一次采购价作为期初成本
3. 如果有多个批次，分批次录入不同成本
4. 记录成本来源（如"2024年10月采购价"）
```

**示例**:

```
产品A（红色，批次2024-10）：
- 账本记录：2024年10月15日采购，单价12.50元
- 期初成本：12.50元
- 成本来源：2024年10月采购价

产品A（蓝色，批次2024-09）：
- 账本记录：2024年9月20日采购，单价13.00元
- 期初成本：13.00元
- 成本来源：2024年9月采购价
```

#### 方法2: 供应商询价法

**适用场景**: 无法查到历史账本，但有长期合作供应商

**操作流程**:

```
1. 联系供应商，询问当前报价
2. 使用当前报价作为期初成本
3. 记录成本来源（如"供应商2025年11月报价"）
```

#### 方法3: 市场估值法（备选）

**适用场景**: 完全无历史数据，无法联系供应商

**操作流程**:

```
1. 参考市场同类产品价格
2. 取市场价的70%-80%作为成本
3. 需要财务主管特别审批
4. 记录成本来源（如"市场估值"）
```

### 2.4 瓷砖行业特殊处理

#### 2.4.1 批次和色号管理

**重要性**：

- 同一产品，不同批次的色号可能不同
- 客户要求同一批次供货（避免色差）
- 必须按批次分别管理库存和成本

**数据结构**：

```typescript
// 期初库存数据示例

  productId: "xxx",           // 产品ID
  productCode: "P001",        // 产品编码
  productName: "抛光砖800x800",
  variantId: "yyy",           // 变体ID（规格）
  colorCode: "RED",           // 色号
  batchNumber: "2024-10",     // 批次号
  quantity: 100,              // 数量
  unitCost: 12.50,            // 单位成本
  costSource: "2024年10月采购价",  // 成本来源说明
  location: "A-01"            // 库位
}
```

#### 2.4.2 运费分摊处理

**场景**: 采购时产生的运费需要分摊到单位成本

**计算方法**:

```typescript
// 示例：采购100箱瓷砖，采购价50元/箱，运费5000元
const purchasePrice = 50; // 采购单价
const quantity = 100; // 数量
const freight = 5000; // 运费

// 分摊后的单位成本
const unitCost = purchasePrice + freight / quantity;
// = 50 + (5000 / 100) = 100元/箱
```

**期初录入**:

- 如果期初库存的成本已包含运费，直接录入总成本
- 如果未包含，需要手动计算分摊后的成本

#### 2.4.3 破损处理

**场景**: 入库时有破损，需要将成本分摊到完好产品

**计算方法**:

```typescript
// 示例：采购100箱，破损5箱，完好95箱，总成本5000元
const totalQuantity = 100; // 总数量
const damagedQuantity = 5; // 破损数量
const goodQuantity = 95; // 完好数量
const totalCost = 5000; // 总成本

// 完好产品的单位成本
const unitCost = totalCost / goodQuantity;
// = 5000 / 95 = 52.63元/箱
```

**期初录入**:

- 只录入完好产品的数量
- 成本已分摊破损部分

```typescript
// 导入时的校验规则
const validationRules = {
  // 1. 产品编码必须存在
  productCode: async (code: string) => {
    const product = await prisma.product.findUnique({
      where: { code },
    });
    if (!product) {
      throw new Error(`产品编码 ${code} 不存在`);
    }
    return product;
  },

  // 2. 数量必须大于0
  quantity: (qty: number) => {
    if (qty <= 0) {
      throw new Error('数量必须大于0');
    }
  },

  // 3. 成本必须大于等于0
  unitCost: (cost: number) => {
    if (cost < 0) {
      throw new Error('成本不能为负数');
    }
  },

  // 4. 总金额校验（可选）
  totalAmount: (
    items: Array<{ quantity: number; unitCost: number }>,
    expectedTotal: number
  ) => {
    const actualTotal = items.reduce(
      (sum, item) => sum + item.quantity * item.unitCost,
      0
    );
    const diff = Math.abs(actualTotal - expectedTotal);
    if (diff > 0.01) {
      // 允许0.01元的误差
      throw new Error(`总金额不匹配：期望${expectedTotal}，实际${actualTotal}`);
    }
  },
};
```

```typescript
// 审批盘点差异并自动调整库存
export async function approveCountAdjustment(
  countId: string,
  userId: string,
  adjustmentData: {
    items: Array<{
      itemId: string;
      differenceReason: string;
      remarks?: string;
    }>;
  }
) {
  return await prisma.$transaction(async tx => {
    // 1. 验证盘点计划状态
    const count = await tx.inventoryCount.findUnique({
      where: { id: countId },
      include: { items: true },
    });

    if (count.status !== 'completed') {
      throw new Error('只有已完成的盘点可以审批调整');
    }

    // 2. 为每个差异项创建库存调整记录
    for (const item of count.items) {
      if (item.difference === 0) continue;

      const adjustmentNumber = await generateAdjustmentNumber(tx);
      const adjustment = await tx.inventoryAdjustment.create({
        data: {
          adjustmentNumber,
          productId: item.productId,
          variantId: item.variantId,
          batchNumber: item.batchNumber,
          beforeQuantity: item.systemQuantity,
          adjustQuantity: item.difference,
          afterQuantity: item.actualQuantity,
          reason: `盘点调整: ${item.differenceReason}`,
          notes: item.remarks,
          status: 'approved',
          operatorId: userId,
          approverId: userId,
          approvedAt: new Date(),
        },
      });

      // 3. 更新库存数量（不改变成本）
      await tx.inventory.update({
        where: {
          productId_variantId_batchNumber: {
            productId: item.productId,
            variantId: item.variantId || null,
            batchNumber: item.batchNumber || null,
          },
        },
        data: {
          quantity: { increment: item.difference },
        },
      });

      // 4. 关联调整记录
      await tx.inventoryCountItem.update({
        where: { id: item.id },
        data: {
          status: 'adjusted',
          adjustmentId: adjustment.id,
          differenceReason: adjustmentData.items.find(i => i.itemId === item.id)
            ?.differenceReason,
        },
      });
    }

    // 5. 更新盘点计划状态
    await tx.inventoryCount.update({
      where: { id: countId },
      data: {
        status: 'adjusted',
        approverId: userId,
        approvedAt: new Date(),
      },
    });

    return { success: true };
  });
}
```

## 4. 成本核算方案

### 4.1 成本核算方法

**采用加权平均法**（项目已实现）

#### 4.1.1 核心公式

```typescript
// lib/utils/cost-calculation.ts
新单位成本 = (原库存金额 + 入库金额) / (原库存数量 + 入库数量);

export function calculateWeightedAverageCost(
  currentQuantity: number,
  currentUnitCost: number,
  inboundQuantity: number,
  inboundUnitCost: number
): number {
  const totalQuantity = currentQuantity + inboundQuantity;

  if (totalQuantity === 0) return 0;

  const currentTotalCost = currentQuantity * currentUnitCost;
  const inboundTotalCost = inboundQuantity * inboundUnitCost;
  const totalCost = currentTotalCost + inboundTotalCost;

  return Math.round((totalCost / totalQuantity) * 100) / 100;
}
```

```typescript
export async function executeMinimalInboundTransaction(data: {
  productId: string;
  quantity: number;
  unitCost: number; // 采购单价
  // ...
}) {
  return await prisma.$transaction(async tx => {
    // 1. 创建入库记录
    const totalCost = data.quantity * data.unitCost;
    const inboundRecord = await tx.inboundRecord.create({
      data: {
        // ...
        unitCost: data.unitCost,
        totalCost,
      },
    });

    // 2. 更新库存成本
    const existingInventory = await tx.inventory.findFirst({
      where: { productId: data.productId /* ... */ },
    });

    let newUnitCost: number;
    if (existingInventory) {
      // 计算加权平均成本
      newUnitCost = calculateWeightedAverageCost(
        existingInventory.quantity,
        existingInventory.unitCost || 0,
        data.quantity,
        data.unitCost
      );

      await tx.inventory.update({
        where: { id: existingInventory.id },
        data: {
          quantity: { increment: data.quantity },
          unitCost: newUnitCost,
        },
      });
    } else {
      // 新建库存，直接使用入库成本
      newUnitCost = data.unitCost;
      await tx.inventory.create({
        data: {
          productId: data.productId,
          quantity: data.quantity,
          unitCost: newUnitCost,
        },
      });
    }

    return inboundRecord;
  });
}
```

```typescript
// lib/services/sales-order-service.ts
export async function calculateSalesOrderCost(orderId: string) {
  const order = await prisma.salesOrder.findUnique({
    where: { id: orderId },
    include: {
      items: true,
      feeItems: true,
      outboundRecords: true,
    },
  });

  // 1. 汇总出库成本
  const totalCost = order.outboundRecords.reduce(
    (sum, record) => sum + (record.totalCost || 0),
    0
  );

  // 2. 计算利润
  const totalRevenue = order.totalAmount;
  const totalProfit = totalRevenue - totalCost;
  const profitMargin =
    totalRevenue > 0 ? (totalProfit / totalRevenue) * 100 : 0;

  // 3. 更新订单成本
  await prisma.salesOrder.update({
    where: { id: orderId },
    data: {
      costAmount: totalCost,
      profitAmount: totalProfit,
    },
  });

  return { totalCost, totalProfit, profitMargin };
}
```

#### 5.2.1 按金额比例分摊（已实现）

```typescript
// lib/services/sales-order-expense-service.ts
export function allocateExpensesByValue(
  items: Array<{ id: string; subtotal: number }>,
  totalExpense: number
): Map<string, number> {
  const totalValue = items.reduce((sum, item) => sum + item.subtotal, 0);

  if (totalValue === 0) {
    return new Map();
  }

  const allocations = new Map<string, number>();
  let allocatedSum = 0;

  items.forEach((item, index) => {
    if (index === items.length - 1) {
      // 最后一项用差额，避免舍入误差
      allocations.set(item.id, totalExpense - allocatedSum);
    } else {
      const allocated = roundToTwoDecimals(
        (item.subtotal / totalValue) * totalExpense
      );
      allocations.set(item.id, allocated);
      allocatedSum += allocated;
    }
  });

  return allocations;
}
```

### 9.6 数据迁移方案

#### 9.6.1 迁移步骤

```
1. 数据准备（上线前1-2周）
   - 仓库全面盘点，确定实际库存数量
   - 财务查账，确定每个产品的账面成本
   - 整理批次、色号信息（瓷砖行业特殊要求）
   - 编制Excel导入文件（使用系统提供的模板）
   - 财务主管审核数据准确性

2. 测试环境验证（上线前1周）
   - 导入测试数据到测试环境
   - 验证成本计算正确性（加权平均法）
   - 验证报表数据准确性
   - 测试几笔入库、出库业务
   - 确认库存金额 = 数量 × 成本

3. 生产环境迁移（上线前1-3天）
   - 选择业务低峰期（如周末）
   - 完整备份数据库
   - 执行数据库Schema变更（扩展Inventory表）
   - 执行Excel批量导入
   - 验证数据完整性和准确性
   - 核对总账：库存金额是否正确

4. 上线后监控（上线后1周）
   - 监控成本计算准确性
   - 检查每笔入库、出库的成本计算
   - 收集用户反馈
   - 及时修复问题
```

#### 9.6.2 期初数据准备清单

**必须准备的数据**:

| 数据项   | 说明         | 来源     | 示例             |
| -------- | ------------ | -------- | ---------------- |
| 产品编码 | 产品唯一标识 | 系统已有 | P001             |
| 产品名称 | 用于核对     | 系统已有 | 抛光砖800x800    |
| 色号     | 瓷砖色号     | 仓库盘点 | RED              |
| 批次号   | 生产批次     | 仓库盘点 | 2024-10          |
| 数量     | 实际库存数量 | 仓库盘点 | 100              |
| 单位成本 | 账面成本     | 财务查账 | 12.50            |
| 成本来源 | 成本依据说明 | 财务说明 | 2024年10月采购价 |
| 库位     | 仓库位置     | 仓库盘点 | A-01             |

**数据准备流程**:

```
1. 仓库盘点（仓库负责人）
   - 全面盘点所有产品
   - 记录数量、批次、色号、库位
   - 填写《仓库盘点表》

2. 财务查账（财务负责人）
   - 翻阅采购账本
   - 确定每个产品的最近采购价
   - 记录成本来源（如"2024年10月采购价"）
   - 填写《期初成本确定表》

3. 数据整理（系统管理员）
   - 合并盘点表和成本表
   - 使用系统模板整理Excel文件
   - 核对数据完整性和准确性

4. 财务审批（财务主管）
   - 审核数据准确性
   - 确认总金额合理性
   - 签字批准导入
```

#### 9.6.3 回滚方案

```sql
-- 如果迁移失败，可以回滚

DELETE FROM inbound_records WHERE reason = 'initial_stock';

-- 使用数据库备份恢复

-- 3. 验证数据一致性

```
