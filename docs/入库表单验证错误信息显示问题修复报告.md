## 📊 问题回顾

### 原始问题

在执行了入库表单空输入验证问题的修复后（添加了 `required_error` 和 `invalid_type_error`），仍然出现以下控制台错误：

```json
[
  {
    "code": "invalid_type",
    "path": ["inputQuantity"],
    "message": "Invalid input: expected number, received undefined" // ❌ 应该显示 "请填写入库数量"
  },
  {
    "code": "invalid_type",
    "path": ["unitCost"],
    "message": "Invalid input: expected number, received undefined" // ❌ 应该显示 "请填写单位成本"
  }
]
```

### 核心问题

- **`inputQuantity` 字段**：显示默认错误信息，而不是自定义的 "请填写入库数量"
- **`unitCost` 字段**：显示默认错误信息，而不是自定义的 "请填写单位成本"
- **原因**：使用了 Zod 3 的 `required_error` 和 `invalid_type_error` 参数，但项目使用的是 Zod 4.x

---

## 🔍 问题根源分析

### Zod 4.x 的重大变更

根据 [Zod 4 迁移指南](https://zod.dev/v4/changelog)，**`invalid_type_error` 和 `required_error` 参数已被移除**！

**官方说明**：

> The `invalid_type_error` / `required_error` params have been dropped. These were hastily added years ago as a way to customize errors that was less verbose than errorMap. They came with all sorts of footguns (they can't be used in conjunction with errorMap) and do not align with Zod's actual issue codes (there is no required issue code).

### Zod 版本确认

项目使用的 Zod 版本：

```json
// package.json
{
  "dependencies": {
    "zod": "^4.1.11" // ✅ Zod 4.x
  }
}
```

### 为什么之前的修复没有生效？

```typescript
// ❌ Zod 3 语法（已废弃，在 Zod 4 中不生效）
z.number({
  required_error: '请填写入库数量',
  invalid_type_error: '数量必须是数字',
});

// ✅ Zod 4 语法（正确方式）
z.number({
  error: issue =>
    issue.input === undefined ? '请填写入库数量' : '数量必须是数字',
});
```

## ✅ 修复方案

### 核心修改

将 `required_error` 和 `invalid_type_error` 替换为 Zod 4 的 `error` 参数：

```typescript
// 修改前（Zod 3 语法）
z.number({
  required_error: '请填写入库数量',
  invalid_type_error: '数量必须是数字',
});

// 修改后（Zod 4 语法）
z.number({
  error: issue =>
    issue.input === undefined ? '请填写入库数量' : '数量必须是数字',
});
```

### 修改的字段

#### 1. `inputQuantity` 字段（第37-53行）

```typescript
inputQuantity: z.preprocess(
  val => {
    if (val === undefined || val === null || val === '') {
      return undefined;
    }
    const num = typeof val === 'number' ? val : Number(val);
    return Number.isNaN(num) ? undefined : num;
  },
  z
    .number({
      error: issue =>
        issue.input === undefined
          ? '请填写入库数量'  // ✅ Zod 4 语法
          : '数量必须是数字',
    })
    .min(1, { message: '数量必须大于等于1' })
    .max(999999, { message: '数量不能超过999999' })
    .int({ message: '数量必须是整数' })
),
```

#### 2. `quantity` 字段（第60-76行）

```typescript
quantity: z.preprocess(
  val => {
```

#### 3. `unitCost` 字段（第150-171行）

