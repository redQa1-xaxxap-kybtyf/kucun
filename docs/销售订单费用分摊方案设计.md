# 销售订单费用分摊方案设计

> 区分客户承担和公司承担的费用处理方案
>
> **设计日期**: 2025-11-10
> **优先级**: P0（立即实施）
> **工作量**: 2-3天

---

## 📊 执行摘要

### 核心问题

当前系统的销售订单费用（运费、加工费等）**未区分承担方**，导致：
1. **客户承担的费用**被错误地计入公司成本，导致利润被低估
2. **公司承担的费用**未分摊到销售成本，导致利润被高估
3. **财务报表不准确**，无法正确反映真实的经营状况

### 解决方案

**核心设计原则**：
- **客户承担的费用** = 代收代付，计入销售收入，不影响成本和利润
- **公司承担的费用** = 销售成本，需分摊到订单项，影响利润

**实施步骤**：
1. 扩展 `SalesOrderFeeItem` 表，增加 `paidBy` 字段
2. 修改发货逻辑，区分两种费用的处理方式
3. 更新前端表单，让用户选择费用承担方
4. 调整财务报表，正确反映两种费用

## 🎯 业务场景分析

### 场景1: 客户承担运费（代收代付）

**业务流程**：
```
1. 客户下单购买瓷砖，总价10000元
2. 物流公司收取运费500元
3. 公司代客户支付运费500元
4. 客户支付总计10500元（货款10000 + 运费500）
```

**财务处理**：
- **销售收入**: 10500元（货款10000 + 代收运费500）
- **销售成本**: 6000元（库存成本，不包含运费）
- **代付费用**: 500元（运费，不计入成本）
- **毛利润**: 10000 - 6000 = 4000元（运费不影响利润）
- **净利润**: 4000元（运费是代收代付，不影响利润）

**会计分录**：
```
借：应收账款 10500
  贷：主营业务收入 10000
  贷：其他应付款-代收运费 500

借：主营业务成本 6000
  贷：库存商品 6000

借：其他应付款-代收运费 500
  贷：银行存款 500（支付物流公司）
```

### 场景2: 公司承担运费（销售费用）

**业务流程**：
```
1. 客户下单购买瓷砖，总价10000元
2. 公司承诺包邮，运费500元由公司承担
3. 客户只需支付10000元
```

**财务处理**：
- **销售收入**: 10000元（货款）
- **销售成本**: 6500元（库存成本6000 + 运费500）
- **毛利润**: 10000 - 6500 = 3500元（运费计入成本，影响利润）
- **净利润**: 3500元

**会计分录**：
```
借：应收账款 10000
  贷：主营业务收入 10000

借：主营业务成本 6500
  贷：库存商品 6000
  贷：银行存款 500（运费）
```

### 场景3: 混合承担（部分客户承担，部分公司承担）

**业务流程**：
```
1. 客户下单购买瓷砖，总价10000元
2. 运费500元，客户承担300元，公司承担200元
3. 客户支付10300元（货款10000 + 运费300）
```

**财务处理**：
- **销售收入**: 10300元（货款10000 + 代收运费300）
- **销售成本**: 6200元（库存成本6000 + 公司承担运费200）
- **代付费用**: 300元（客户承担的运费）
- **毛利润**: 10000 - 6200 = 3800元
- **净利润**: 3800元

## 🗄️ 数据库设计方案

### 方案1: 扩展 SalesOrderFeeItem 表（推荐）

**新增字段**：

```prisma
model SalesOrderFeeItem {
  id           String   @id @default(uuid()) @db.Char(36)
  salesOrderId String   @map("sales_order_id") @db.Char(36)
  feeType      String   @map("fee_type")
  feeName      String   @map("fee_name")
  feeAmount    Float    @map("fee_amount")
  
  // ✅ 新增字段
  paidBy       String   @default("customer") @map("paid_by") @db.VarChar(20)
  // 值域: 'customer' | 'company'
  // 默认值: 'customer' (客户承担，代收代付)
  
  remarks      String?
  createdAt    DateTime @default(now()) @map("created_at")
  updatedAt    DateTime @updatedAt @map("updated_at")

  // 关系定义
  salesOrder SalesOrder @relation("SalesOrderFeeItems", fields: [salesOrderId], references: [id], onDelete: Cascade, onUpdate: Cascade)

  @@index([salesOrderId], map: "idx_sales_order_fee_items_order")
  @@index([feeType], map: "idx_sales_order_fee_items_type")
  @@index([paidBy], map: "idx_sales_order_fee_items_paid_by") // ✅ 新增索引
  @@map("sales_order_fee_items")
}
```

**字段说明**：
- `paidBy`: 费用承担方
  - `'customer'`: 客户承担（代收代付），计入销售收入，不影响成本
  - `'company'`: 公司承担（销售费用），计入销售成本，影响利润
- **默认值**: `'customer'`（保持向后兼容，现有数据默认为客户承担）

### 数据迁移脚本

```sql
-- 1. 添加 paid_by 字段（默认值为 'customer'）
ALTER TABLE `sales_order_fee_items` 
ADD COLUMN `paid_by` VARCHAR(20) NOT NULL DEFAULT 'customer' 
COMMENT '费用承担方: customer=客户承担, company=公司承担' 
AFTER `fee_amount`;

-- 2. 添加索引
CREATE INDEX `idx_sales_order_fee_items_paid_by` 
ON `sales_order_fee_items` (`paid_by`);

-- 3. 验证数据
SELECT 
  COUNT(*) as total_fees,
  SUM(CASE WHEN paid_by = 'customer' THEN 1 ELSE 0 END) as customer_paid,
  SUM(CASE WHEN paid_by = 'company' THEN 1 ELSE 0 END) as company_paid
FROM `sales_order_fee_items`;
```

## 💼 业务逻辑设计

### 1. 费用承担方的判断规则

**默认规则**：
- **运费（shipping）**: 默认客户承担（`paidBy: 'customer'`）
- **加工费（processing）**: 默认公司承担（`paidBy: 'company'`）
- **其他费用（other）**: 默认客户承担（`paidBy: 'customer'`）

**用户可修改**：
- 用户在创建/编辑销售订单时，可以手动选择每个费用项的承担方
- 前端表单提供下拉选择：`客户承担` / `公司承担`

### 2. 客户承担费用的处理逻辑

**计入销售收入**：
```typescript
// 客户承担的费用计入订单总额
const customerPaidFees = feeItems
  .filter(fee => fee.paidBy === 'customer')
  .reduce((sum, fee) => sum + fee.feeAmount, 0);

const totalAmount = itemsAmount + customerPaidFees + roundingAdjustment;
```

**不影响成本**：
```typescript
// 客户承担的费用不分摊到销售成本
// 发货时，只分摊公司承担的费用
const companyPaidFees = feeItems
  .filter(fee => fee.paidBy === 'company')
  .reduce((sum, fee) => sum + fee.feeAmount, 0);

// 只分摊公司承担的费用
const expenseAllocations = allocateExpensesByValue(
  order.items,
  companyPaidFees // ✅ 只分摊公司承担的费用
);
```

### 3. 公司承担费用的分摊算法

**推荐使用**: 按金额比例分摊（`allocateExpensesByValue`）

**分摊公式**：
```typescript
// 订单项A的分摊费用 = 公司承担的总费用 × (订单项A的金额 / 订单总金额)

const itemAllocatedExpense = 
  companyPaidFees * (item.subtotal / order.itemsAmount);
```

**示例**：
```
订单项A: 金额6000元
订单项B: 金额4000元
订单总金额: 10000元
公司承担运费: 500元

订单项A分摊费用 = 500 × (6000 / 10000) = 300元
订单项B分摊费用 = 500 × (4000 / 10000) = 200元
```

## 📐 成本和利润计算公式

### 公式定义

```typescript
// 1. 销售收入
const salesRevenue = itemsAmount + customerPaidFees + roundingAdjustment;

// 2. 销售成本
const salesCost = inventoryCost + companyPaidFees;

// 3. 毛利润
const grossProfit = salesRevenue - salesCost;
// 或者：grossProfit = itemsAmount - inventoryCost - companyPaidFees;

// 4. 毛利率
const grossProfitMargin = (grossProfit / salesRevenue) * 100;
```

### 示例计算

**场景**: 销售订单包含2个产品，运费500元客户承担，加工费300元公司承担

| 项目 | 订单项A | 订单项B | 合计 |
|------|---------|---------|------|
| 销售金额 | 6000元 | 4000元 | 10000元 |
| 库存成本 | 3600元 | 2400元 | 6000元 |
| 分摊加工费 | 180元 | 120元 | 300元 |
| **销售成本** | **3780元** | **2520元** | **6300元** |
| **毛利润** | **2220元** | **1480元** | **3700元** |

**订单总计**：
- **销售收入**: 10000 + 500（客户承担运费）= 10500元
- **销售成本**: 6000（库存）+ 300（公司承担加工费）= 6300元
- **代付费用**: 500元（客户承担运费，不影响利润）
- **毛利润**: 10000 - 6300 = 3700元
- **毛利率**: 3700 / 10500 = 35.24%

### 3. 财务计算函数

```typescript
// lib/api/handlers/sales-orders/financials.ts

import type { SalesOrderFeeItem } from '@/lib/types/sales-order-fee';

/**
 * 计算客户承担的费用总额
 */
export function calculateCustomerPaidFees(
  feeItems: SalesOrderFeeItem[]
): number {
  return feeItems
    .filter(fee => fee.paidBy === 'customer')
    .reduce((sum, fee) => sum + fee.feeAmount, 0);
}

/**
 * 计算公司承担的费用总额
 */
export function calculateCompanyPaidFees(
  feeItems: SalesOrderFeeItem[]
): number {
  return feeItems
    .filter(fee => fee.paidBy === 'company')
    .reduce((sum, fee) => sum + fee.feeAmount, 0);
}

/**
 * 计算订单财务数据（区分费用承担方）
 */
export const calculateFinancials = (
  data: CreateInput,
  transferMode: CreateInput['transferMode']
) => {
  const { itemsAmount, costAmount, profitAmount } = calculateItemTotals(
    data,
    transferMode
  );
  
  // ✅ 区分客户承担和公司承担的费用
  const customerPaidFees = calculateCustomerPaidFees(data.feeItems || []);
  const companyPaidFees = calculateCompanyPaidFees(data.feeItems || []);
  
  // ✅ 客户承担的费用计入销售收入
  const additionalFees = roundCurrency(customerPaidFees);
  
  const roundingAdjustment = roundCurrency(data.roundingAdjustment ?? 0);
  
  // ✅ 订单总额 = 商品金额 + 客户承担费用 + 尾差调整
  const totalAmount = roundCurrency(
    itemsAmount + additionalFees + roundingAdjustment
  );
  
  // ✅ 公司承担的费用计入成本（后续发货时分摊）
  // 这里先记录，发货时再分摊到订单项
  const expenseAmount = roundCurrency(companyPaidFees);

  return {
    itemsAmount,
    costAmount,
    profitAmount,
    additionalFees,      // 客户承担的费用
    expenseAmount,       // 公司承担的费用
    roundingAdjustment,
    totalAmount,
  };
};
```
