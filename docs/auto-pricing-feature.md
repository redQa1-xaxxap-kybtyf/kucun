# 厂家发货自动定价功能使用指南

## 📋 功能概述

在厂家发货创建/编辑页面，系统可以根据**进货价**和**运费**自动计算**建议销售价**，确保每个产品都有合理的利润率。

## 🎯 核心特性

### 1. 智能计算

- **输入**: 进货价 + 运费
- **输出**: 建议销售价（默认 20% 利润率）
- **算法**: 销售价 = (进货价 + 分摊运费/数量) × (1 + 利润率)

### 2. 运费分摊

- **分摊方式**: 按进货价比例分摊
- **公式**: 单个产品分摊运费 = 总运费 × (该产品进货价总和 / 所有产品进货价总和)

### 3. 利润保障

- **目标利润率**: 20%（可配置）
- **最低利润率**: 10%（可配置）
- **价格取整**: 四舍五入到分

## 📖 使用步骤

### 步骤 1: 填写产品信息

1. 点击"添加产品"按钮
2. 选择产品或添加临时产品
3. 填写**进货价**（必填）
4. 填写数量、单位等其他信息

### 步骤 2: 添加运费

1. 在"费用项"部分添加运费
2. 选择费用类型（如"运费"）
3. 填写费用金额

### 步骤 3: 计算建议销售价

1. 点击"计算建议销售价"按钮
2. 系统验证：
   - 至少有一个产品
   - 所有产品都有进货价
3. 系统计算并显示结果对话框

### 步骤 4: 查看计算结果

对话框显示：

- **汇总信息**:
  - 总运费
  - 产品数量
  - 平均利润率
- **明细表格**:
  - 进货价
  - 分摊运费
  - 最终成本
  - 建议售价
  - 利润率

### 步骤 5: 应用建议价格

1. 检查计算结果
2. 点击"应用建议价格"按钮
3. 系统自动填充销售价（只更新未填写或为 0 的销售价）

## 💡 使用技巧

### 1. 批量计算

- 一次性为所有产品计算建议销售价
- 节省手动计算时间

### 2. 保留手动调整

- 已填写的销售价不会被覆盖
- 可以先计算，再手动微调

### 3. 利润率提示

- 绿色：利润率 ≥ 20%（优秀）
- 黄色：利润率 10% ~ 20%（合格）
- 红色：利润率 < 10%（偏低）

### 4. 重新计算

- 修改进货价或运费后，可以重新点击"计算建议销售价"
- 系统会基于最新数据重新计算

## 📊 计算示例

### 示例 1: 单个产品

**输入**:

- 产品 A: 进货价 100 元，数量 10 件
- 运费: 200 元

**计算过程**:

1. 分摊运费 = 200 元（只有一个产品）
2. 单位分摊运费 = 200 / 10 = 20 元/件
3. 最终单位成本 = 100 + 20 = 120 元/件
4. 建议销售价 = 120 × (1 + 20%) = 144 元/件
5. 利润率 = (144 - 120) / 144 × 100% = 16.67%

### 示例 2: 多个产品

**输入**:

- 产品 A: 进货价 100 元，数量 10 件（进货价总和 1000 元）
- 产品 B: 进货价 200 元，数量 5 件（进货价总和 1000 元）
- 运费: 300 元

**计算过程**:

**产品 A**:

1. 分摊运费 = 300 × (1000 / 2000) = 150 元
2. 单位分摊运费 = 150 / 10 = 15 元/件
3. 最终单位成本 = 100 + 15 = 115 元/件
4. 建议销售价 = 115 × 1.2 = 138 元/件

**产品 B**:

1. 分摊运费 = 300 × (1000 / 2000) = 150 元
2. 单位分摊运费 = 150 / 5 = 30 元/件
3. 最终单位成本 = 200 + 30 = 230 元/件
4. 建议销售价 = 230 × 1.2 = 276 元/件

## ⚠️ 注意事项

### 1. 必填字段

- 必须先填写**进货价**才能计算
- 未填写进货价的产品会提示错误

### 2. 运费为 0

- 如果没有运费，系统仍会计算（分摊运费为 0）
- 建议销售价 = 进货价 × (1 + 利润率)

### 3. 手动调整优先

- 已填写的销售价不会被自动覆盖
- 如需重新计算，请先清空销售价

### 4. 利润率配置

- 当前默认利润率为 20%
- 未来版本将支持自定义利润率

## 🔧 技术实现

### 核心服务

- `lib/services/factory-shipment-pricing-service.ts`
  - `calculateSuggestedPrice()`: 计算单个产品建议价
  - `calculateOrderPricing()`: 批量计算订单所有产品

### UI 组件

- `components/factory-shipments/form-sections/items-table.tsx`
  - "计算建议销售价"按钮
  - 计算逻辑集成
- `components/factory-shipments/pricing-result-dialog.tsx`
  - 结果预览对话框

### 配置选项

```typescript
{
  targetProfitMargin: 20,    // 目标利润率 20%
  minProfitMargin: 10,       // 最低利润率 10%
  roundingRule: 'nearest'    // 价格取整规则
}
```
