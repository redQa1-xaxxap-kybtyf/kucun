## 🎯 技术要点

### 1. 幂等性键（idempotencyKey）的使用

**目的**: 防止重复操作（如重复提交表单）

**实现**:

- 创建订单时：可选字段，前端生成
- 更新订单时：必需字段，前端生成
- 不存储在数据库中，只在 API 请求中使用

**生成方式**:

```typescript
const generateIdempotencyKey = (): string => {
  if (
    typeof crypto !== 'undefined' &&
    typeof crypto.randomUUID === 'function'
  ) {
    return crypto.randomUUID();
  }
  return `${Date.now()}-${Math.random().toString(36).slice(2)}`;
};
```

### 2. 表单类型设计

**策略**: 使用统一的表单数据类型

- 表单使用 `CreateFactoryShipmentOrderData` 类型
- `idempotencyKey` 在 schema 中定义为可选
- 提交时根据操作类型（创建/更新）确保字段存在

**优点**:

- 简化表单组件的类型定义
- 避免在创建和更新模式下使用不同的类型
- 提交时灵活处理必需字段

### 3. React Hook Form 最佳实践

**类型安全**:

```typescript
const form = useForm<CreateFactoryShipmentOrderData>({
  resolver: zodResolver(createFactoryShipmentOrderSchema),
```
