## 📝 注意事项

### 开发环境

- 密码认证可选（留空）
- TLS 可以禁用
- 使用默认数据库索引 0

### 生产环境

- **必须**配置密码认证
- **强烈推荐**启用 TLS/SSL
- 根据业务需求选择数据库索引
- 配置合理的连接池大小（5-10）
- 配置淘汰策略和内存限制

### 性能考虑

- 连接池大小根据并发量调整
- 启用自动管道提升性能
- 使用事务保证数据一致性
- 使用 Pub/Sub 实现实时通知
