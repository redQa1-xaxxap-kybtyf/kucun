## 📊 新增功能：库存统计展示

**日期**: 2025-11-19
**问题**: 前端无法直观了解仓库的资金占用情况
**解决方案**: 添加库存统计卡片

### 实现内容

在库存管理页面顶部添加 5 个统计卡片：

1. **库存总金额** - 当前所有库存的总价值（quantity × unitCost）
2. **期初库存金额** - 期初入库记录的总成本
3. **库存产品数** - 当前库存的 SKU 数量
4. **库存总数量** - 所有库存的总片数
5. **库存健康度** - 基于低库存产品占比的健康度指标

### 技术实现

**新增文件**:

- `app/api/inventory/statistics/route.ts` - 统计 API
- `lib/types/inventory-statistics.ts` - 类型定义
- `hooks/use-inventory-statistics.ts` - 数据获取 Hook
- `components/inventory/inventory-statistics-cards.tsx` - UI 组件

**修改文件**:

- `app/(dashboard)/inventory/page-client.tsx` - 集成统计卡片
- `lib/queryKeys.ts` - 添加统计查询键

### 特点

✅ 实时计算库存总金额
✅ 单独统计期初库存金额
✅ 响应式设计（移动端友好）
✅ 数据缓存 5 分钟
✅ 支持按分类筛选
✅ 加载状态骨架屏

详细说明请查看：`docs/features/库存统计功能说明.md`
