## 1. 项目概述

### 1.1 背景问题

**用户反馈：**

- DIY 能力低，无法达到想要的效果
- 体验非常差，制作打印表单难度大
- 难以理解和使用配置选项

**现有系统：**

- ✅ 架构完善（PrintStyleConfig 类型系统完整）
- ✅ 功能齐全（页面、表头、表格、汇总、签名、页脚）
- ❌ 布局固定（无法调整组件顺序）
- ❌ 纯数字输入（需要专业知识）
- ❌ 无可视化反馈（预览与实际打印差距大）

### 1.2 核心目标

**Phase 1: 可视化调整控件**（1-2 周）

- 保留现有配置面板
- 添加可视化调整方式（拖拽、滑块）
- 改进实时预览

**Phase 2: 画布式编辑器**（2-4 周）

- 拖拽调整各区域位置
- 可视化调整间距和尺寸
- 完全替代配置面板

### 1.3 技术约束

**必须满足：**

- ✅ 保留现有 `PrintStyleConfig` 数据结构
- ✅ 向后兼容现有模板
- ✅ 不影响现有打印功能
- ✅ 使用 `@dnd-kit/core` 实现拖拽

**技术栈：**

- 拖拽库：`@dnd-kit/core`（轻量、现代化）
- 状态管理：React Hooks（useState, useMemo）
- 类型安全：TypeScript
- UI 组件：shadcn/ui + Radix UI

## 2. 现状分析

### 2.1 现有配置系统

**数据结构：** `lib/types/print-style.ts`

```typescript
PrintStyleConfig {
  page: PageSettings           // 页面设置
  header: HeaderSettings       // 表头设置
  infoSection: InfoSectionSettings  // 信息区设置
  table: TableSettings        // 表格设置
  summary: SummarySettings    // 汇总区设置
  footer: FooterSettings      // 页脚设置
  signature: SignatureSettings  // 签名区设置
}
```

**编辑器组件：** `components/print/StyleEditor.tsx`

- 标签页式布局（页面 / 表头 / 表格 / 其他）
- 纯数字输入（边距、字号、边框宽度）
- 右侧实时预览（简单 HTML 渲染）

**痛点：**

1. 布局固定：各区域顺序不可调整
2. 调整困难：需要输入精确的数值（如 10.5mm）
3. 缺乏直观：无法看到调整对打印的影响
4. 学习成本高：需要理解边距、padding 等概念

### 2.2 预览系统

**现状：**

- 使用 `PrintLayout` 组件渲染预览
- 基于内联样式，模拟打印效果
- 无分页预览
- 无打印区域高亮

**问题：**

- 预览与实际打印可能不一致
- 无打印边界指示
- 无法预览多页内容

- 🎯 实时预览调整效果

**灵活性：**

- 🎯 支持自定义布局（拖拽调整区域顺序）

### 4.2 技术选型

**拖拽库：** `@dnd-kit/core`

```bash
npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```

**理由：**

- ✅ 轻量级（< 15KB gzipped）
- ✅ 现代化（React Hooks，支持 React 18+）
- ✅ 功能强大（支持拖拽排序、嵌套、约束）
- ✅ 性能优秀（使用 Pointer Events，触摸友好）
- ✅ TypeScript 支持

**替代方案：**

- ❌ `react-dnd`：过时，体积大（~100KB）
- ❌ `react-beautiful-dnd`：性能较差，移动端支持不好
- ❌ `react-grid-layout`：过于复杂，不适合表单场景

**预览方案：**

**Phase 1（过渡期）：**

- 保留现有 `PrintLayout` 预览
- 改进实时性（添加 debounce）
- 添加打印区域高亮

**Phase 2（最终方案）：**

- 使用 `@react-pdf/renderer` 实现真正的 PDF 预览
- 支持分页预览
- 精确还原打印效果

## 5. 数据模型

### 5.1 保留现有结构

**核心原则：** 不修改 `PrintStyleConfig`，确保向后兼容。

**扩展（可选）：**

```typescript
// 新增：布局配置（用于拖拽排序）
export interface LayoutConfig {
  /**
   * 各区域的顺序
   * @default ['header', 'infoSection', 'table', 'summary', 'signature', 'footer']
   */
  sections: SectionType[];

  /**
   * 信息区字段的顺序
   * @default 按字段配置中的默认顺序
   */
  infoFields: string[];

  /**
   * 表格列的顺序
   * @default 按字段配置中的默认顺序
   */
  tableColumns: string[];
}

/**
 * 区域类型
 */
export type SectionType =
  | 'header'
  | 'infoSection'
  | 'table'
  | 'summary'
  | 'signature'
  | 'footer';
```

**存储方式：**

- localStorage：`print_layout_config_${documentType}`
- 与 `PrintStyleConfig` 分开存储
- 优先级高于默认顺序

## 6. 组件设计

### 6.1 组件结构

```
components/print/visual-editor/

│   ├── ConfigPanel.tsx           // 配置面板（保留现有）
│   └── PresetSelector.tsx        // 预设选择器
├── PropertyPanel.tsx             // 属性面板（选中元素）
└── helpers/
    ├── useDragHandlers.ts        // 拖拽逻辑 Hook
    ├── useResizeHandlers.ts      // 调整大小逻辑 Hook
```

### 6.2 核心组件

```typescript
  documentType: DocumentType;

/**
 * 功能：
 * 1. 管理编辑器状态（样式、布局、选中元素）

 */
```

#### **PrintCanvas（画布）**

```typescript
export interface PrintCanvasProps {
  /**
   * 样式配置
   */

  /**
   * 布局配置

  layoutConfig?: LayoutConfig;

   * 预览数据
   */

  /**
   * 是否可编辑（预览模式 vs 编辑模式）

 * 功能：
```

## 8. 风险和注意事项

### 8.1 技术风险

| 风险                | 影响             | 缓解措施               |
| ------------------- | ---------------- | ---------------------- |
| `@dnd-kit` 学习曲线 | 延期 1-2 天      | 提前做 POC，熟悉 API   |
| 性能问题（大订单）  | 用户体验差       | 虚拟化、分片渲染       |
| 浏览器兼容性        | 部分用户无法使用 | 降级方案（纯配置面板） |

### 8.2 兼容性风险

| 风险              | 影响     | 缓解措施                 |
| ----------------- | -------- | ------------------------ |
| 现有模板失效      | 用户反馈 | 保留默认值，向后兼容测试 |
| localStorage 限制 | 无法保存 | 提示用户，考虑 IndexedDB |
| 打印效果不一致    | 用户投诉 | 充分测试，提供打印指南   |

### 8.3 实施建议

**风险控制：**

1. ✅ **渐进式实施**：Phase 1 → Phase 2，逐步升级
2. ✅ **功能开关**：提供配置项，可以禁用可视化编辑器
3. ✅ **A/B 测试**：先给部分用户试用，收集反馈
4. ✅ **快速回滚**：保留旧版 `StyleEditor`，可随时回退

**质量保证：**

1. ✅ **单元测试**：核心组件和 Hook
2. ✅ **E2E 测试**：完整编辑流程
3. ✅ **兼容性测试**：Chrome、Firefox、Safari、Edge
4. ✅ **性能测试**：大订单（100+ 行）拖拽性能

**用户教育：**

1. ✅ **引导提示**：首次使用显示引导
2. ✅ **视频教程**：演示拖拽和可视化调整
3. ✅ **快速开始**：提供一键预设
4. ✅ **帮助文档**：详细的操作指南
