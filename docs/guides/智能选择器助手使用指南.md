# 智能选择器助手使用指南

> 🎯 **目标**: 让您无需了解 CSS 选择器知识，只需复制 HTML 代码，即可自动生成配置

---

## 📖 快速开始

### 步骤 1: 打开智能助手

1. 访问：**基础设置 → 运输管理 → 站点管理**
2. 点击页面右上角的 **"✨ 智能选择器助手"** 按钮

### 步骤 2: 获取 HTML 代码

#### 方法 A：使用浏览器开发者工具（推荐）

1. **打开船舶信息页面**
   - 在浏览器中打开您要配置的船舶追踪网站
   - 搜索一个船舶，打开详情页面

2. **打开开发者工具**
   - Windows: 按 `F12` 或 `Ctrl + Shift + I`
   - Mac: 按 `Cmd + Option + I`
   - 或者右键点击页面 → 选择"检查"

3. **定位信息区域**
   - 点击开发者工具左上角的"选择元素"图标（鼠标箭头图标）
   - 将鼠标移动到船舶信息区域（如：状态、目的地、预到时间等）
   - 点击该区域

4. **复制 HTML 代码**
   - 在开发者工具的 Elements 标签中，找到高亮的 HTML 代码
   - 右键点击该元素 → 选择 **"Copy"** → **"Copy element"**
   - 或者选中代码后按 `Ctrl + C` (Windows) 或 `Cmd + C` (Mac)

#### 方法 B：查看网页源代码

1. 右键点击页面 → 选择"查看网页源代码"
2. 找到包含船舶信息的部分
3. 复制相关的 HTML 代码

### 步骤 3: 粘贴并分析

1. **粘贴 HTML 代码**
   - 在智能助手页面左侧的文本框中粘贴刚才复制的 HTML 代码
   - 确保代码包含完整的信息区域

2. **点击"🔍 智能分析"按钮**
   - 系统会自动识别字段（状态、目的地、预到时间等）
   - 自动生成对应的 CSS 选择器

3. **查看检测结果**
   - 右侧会显示检测到的字段
   - 每个字段包含：
     - **字段名称**（如：当前状态、目的地）
     - **提取的值**（如：用主机航行、天津港）
     - **CSS 选择器**（自动生成）
     - **可信度**（高/中/低）

### 步骤 4: 复制选择器

#### 方法 A：复制单个选择器

- 点击每个字段右侧的"复制"按钮
- 粘贴到站点管理页面的对应字段中

#### 方法 B：复制所有选择器

- 点击右上角的"复制全部"按钮
- 一次性复制所有选择器
- 手动粘贴到站点管理页面的对应字段中

    >用主机航行</span
  >
</li>
<li data-v-5f0b6561="" class="flex-in flex-c">
  <span data-v-5f0b6561="" title="目的地" class="title">目的地</span>
  <span data-v-5f0b6561="">：</span>
  <span data-v-5f0b6561="" title="天津港" class="ship-mmsi">天津港</span>

  <span data-v-5f0b6561="" title="预到时间" class="title">预到时间</span>

  <span data-v-5f0b6561="" title="11-03 15:00" class="ship-mmsi"

**智能助手会自动生成：**

| 字段     | 值          | CSS 选择器                                      | 可信度 |
| -------- | ----------- | ----------------------------------------------- | ------ |
| 当前状态 | 用主机航行  | `li:has(span[title="状态"]) span.ship-mmsi`     | 高     |
| 目的地   | 天津港      | `li:has(span[title="目的地"]) span.ship-mmsi`   | 高     |
| 预计到达 | 11-03 15:00 | `li:has(span[title="预到时间"]) span.ship-mmsi` | 高     |

## 💡 使用技巧

### 1. 确保 HTML 代码完整

- ✅ **正确**: 复制包含多个字段的完整区域
- ❌ **错误**: 只复制单个字段

### 2. 选择合适的复制范围

- **最佳**: 复制整个信息卡片或列表
- **可以**: 复制包含所有需要字段的父元素
- **避免**: 只复制单个 `<span>` 或 `<div>`

### 3. 检查可信度

- **高可信度** ✅: 可以直接使用
- **中可信度** ⚠️: 建议测试后使用
- **低可信度** ❌: 可能需要手动调整

### 4. 测试选择器

在站点管理页面配置后，建议：

1. 保存配置
2. 执行一次测试查询
3. 验证提取的数据是否正确

## ❓ 常见问题

### Q1: 为什么没有检测到任何字段？

**可能原因：**

- HTML 代码不完整
- 字段名称不包含常见关键词（状态、目的地、预到时间等）
- HTML 结构与预期不符

**解决方法：**

- 复制更大范围的 HTML 代码
- 确保包含字段标题和值
- 检查是否有 `title` 属性或文本内容

### Q2: 检测到的字段值不正确？

**可能原因：**

- 选择器匹配到了错误的元素
- HTML 结构复杂，有多个相似元素

**解决方法：**

- 查看生成的选择器是否合理
- 在浏览器控制台测试选择器
- 手动调整选择器

### Q3: 可信度是什么意思？

**可信度说明：**

- **高可信度**: 使用了精确的选择器（如 `:has()` 伪类 + 属性选择器）
- **中可信度**: 使用了相对选择器（如 `+` 相邻兄弟选择器）
- **低可信度**: 使用了通用选择器（如 `:last-child`）

### Q4: 生成的选择器在浏览器中不工作？

**可能原因：**

- 浏览器不支持 `:has()` 伪类（较老的浏览器）
- 页面使用了动态加载

**解决方法：**

- 使用备选选择器（如 `nth-child()`）
- 在站点管理页面手动调整选择器
- 联系技术支持

## 🔧 高级用法

### 在浏览器控制台测试选择器

```javascript
// 测试选择器是否正确
document.querySelector('li:has(span[title="状态"]) span.ship-mmsi')
  ?.textContent;
// 应该返回: "用主机航行"

// 测试是否匹配多个元素
document.querySelectorAll('li:has(span[title="状态"]) span.ship-mmsi').length;
// 应该返回: 1
```

### 手动调整选择器

如果自动生成的选择器不准确，可以手动调整：

**常用选择器模式：**

```css
/* 使用属性选择器 */
li:has(span[title="状态"]) span.ship-mmsi

/* 使用 nth-child */
ul.info-list > li:nth-child(2) span.value

/* 使用类名 */
.ship-info .status-value

/* 使用相邻兄弟选择器 */
span[title="状态"] + span.ship-mmsi
```
