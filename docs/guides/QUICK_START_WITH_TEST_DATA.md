# 快速启动指南 - 使用测试数据

## 🚀 快速开始

### 1. 生成测试数据

```bash
# 运行 seed 脚本生成测试数据
npm run db:seed
```

**预期输出**:

```

✅ 创建收款记录: 81 条
...
🎉 数据库种子数据初始化完成！
```

### 2. 验证数据

```bash
# 运行验证脚本检查数据质量
npx tsx prisma/verify-seed-data.ts
```

```bash
# 启动 Next.js 开发服务器
npm run dev
```

## 🧪 测试场景

### 1. 订单管理测试

#### 查看订单列表

1. 登录系统

5. 测试搜索功能（订单号、客户名称）

#### 创建新订单

1. 点击 "新建订单" 按钮
2. 选择客户（从20个测试客户中选择）
3. 添加产品（从28个测试产品中选择）

5. 保存订单

#### 订单详情

1. 点击任意订单查看详情
2. 查看订单明细

## 🐛 故障排除

### 问题1: Seed 脚本运行失败

**解决方案**:

```bash
# 检查数据库连接
npm run db:studio

# 重置数据库
npm run db:reset
```

### 问题2: 数据显示不正确

**解决方案**:

```bash
# 验证数据
npx tsx prisma/verify-seed-data.ts

# 重新生成数据
npm run db:seed
```

### 问题3: 登录失败

**解决方案**:

- 确认使用正确的邮箱和密码
- 检查用户是否已创建
- 查看 Prisma Studio 中的用户表

### 问题4: 页面报错

**解决方案**:

- 检查浏览器控制台错误
- 查看服务器日志
- 确认数据库连接正常
