# 库存统计功能说明

**日期**: 2025-11-19  
**功能**: 库存总金额和期初库存统计展示  
**状态**: ✅ 已完成

---

## 📋 功能概述

在库存管理页面顶部添加统计卡片，展示以下关键指标：

1. **库存总金额** - 当前所有库存的总价值（数量 × 单位成本）
2. **期初库存金额** - 期初入库记录的总成本
3. **库存产品数** - 当前库存的 SKU 数量
4. **库存总数量** - 所有库存的总片数
5. **库存健康度** - 基于低库存产品占比的健康度指标

---

## 🎯 解决的问题

**问题**: 前端无法直观了解仓库的资金占用情况

**解决方案**:

- ✅ 实时计算库存总金额
- ✅ 单独统计期初库存金额
- ✅ 提供库存健康度指标
- ✅ 支持按分类筛选统计

## 📊 统计逻辑说明

### 1. 库存总金额计算

```sql
SELECT SUM(quantity * unit_cost) as totalValue
FROM inventory
WHERE product.status = 'active'
```

**说明**:

- 仅统计活跃产品的库存
- 使用当前库存的 `unitCost`（最近一次入库成本）
- 如果 `unitCost` 为 NULL，按 0 计算

### 2. 期初库存金额计算

```sql
SELECT SUM(total_cost) as openingBalanceCost
FROM inbound_records
WHERE reason = 'opening_balance'
```

**说明**:

- 统计所有 `reason = 'opening_balance'` 的入库记录
- 使用入库时记录的 `totalCost`（quantity × unitCost）
- 这个金额代表期初资金占用

### 3. 库存健康度计算

```typescript
stockHealthPercentage = ((totalProducts - lowStockCount) / totalProducts) × 100
```

**说明**:

- 低库存产品：可用数量 ≤ 产品阈值（默认 10）
- 健康度越高，表示库存越充足
- 颜色指示：
  - 绿色 (≥80%): 健康
  - 黄色 (60-79%): 警告
  - 红色 (<60%): 危险

## ⚡ 性能优化

1. **并行查询**: 所有统计查询并行执行
2. **数据缓存**: 统计数据缓存 5 分钟
3. **按需加载**: 仅在库存页面加载统计数据
4. **索引优化**: 利用现有的 `reason` 和 `product_id` 索引
5. **骨架屏**: 加载时显示占位内容，避免布局抖动

```typescript

  queryKey: queryKeys.inventory.statistics(),

```

---

## 📝 注意事项

1. **期初库存金额** 是历史数据，不会随当前库存变化而变化
2. **库存总金额** 是实时计算的当前库存价值
3. 两者的差异反映了库存成本的变化趋势
4. 统计数据每 5 分钟自动刷新，也可手动刷新
