# 盘点当前最需要改的 3 件事

> 目标：先把盘点做成“范围准确、录入顺手、查找更快”。

## 1. 盘点范围要准确

- `仓库`保留。
- `库位/存放区域`也保留，但不用强制填写。
- 不填库位，就是盘整个仓库。
- 填了库位，就只盘这个库位。
- 不能出现“本来只盘一个库位，最后把整个仓库都带出来”的情况。

这件事最重要。范围不准，后面的盘点结果就不可靠。

## 2. 现场盘点要按“件 + 片”录入

- 瓷砖行业现场盘点，不适合录小数件。
- 最合适的方式是直接录：
  - `件数`
  - `零片`
- 系统自动换算总片数。
- 页面统一显示成：`1608片（100件8片）`

这样仓库好用，财务也容易核对。

## 3. 商品要更容易查找

- 相近名称的商品要排在一起。
- 例如：
  - `帝王白套线`
  - `帝王白柱子`
  - `帝王白腰线`
- 盘点时要能快速找到商品，至少支持：
  - 按 `商品名称` 查
  - 按 `商品编号` 查
  - 按 `批次` 查
  - `只看未盘`
  - `只看有差异`

这会直接影响盘点速度和对账效率。

## 结论

现在盘点最需要先改的，不是加更多功能，而是先把这三件事做好：

- `范围要准`
- `录入要顺手`
- `查找要更快`

这三项做好以后，盘点就会更符合瓷砖行业和中国用户的使用习惯。
