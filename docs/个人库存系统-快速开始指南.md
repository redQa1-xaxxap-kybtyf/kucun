# 个人库存管理系统 - 快速开始指南

**适用场景**: 个人使用的库存管理系统  
**更新日期**: 2025-11-19

---

## 🚀 快速开始

### 第一步：录入期初库存

1. 访问 **入库记录** 页面 (`/inventory/inbound`)
2. 点击页面右上角的 **"期初入库"** 按钮
3. 填写表单：
   - 选择产品
   - 输入数量（可以按"件"或"片"）
   - 输入单位成本
   - 填写备注（可选）
4. 点击 **"提交"**
5. 在确认对话框中点击 **"确认入库"**

**提示**:

- ✅ 可以分批录入，不需要一次性完成
- ✅ 可以随时录入新的期初库存
- ✅ 如果录入错误，可以通过"库存调整"功能修正

---

### 第二步：查看库存统计

1. 访问 **库存管理** 页面 (`/inventory`)
2. 页面顶部会显示 5 个统计卡片：

```
┌─────────────────────────────────────────────────────────────────┐
│  💰 库存总金额    💼 期初库存金额   📦 库存产品数   📈 库存总数量   ⚠️ 库存健康度  │
│  ¥1,250,000.50   ¥800,000.00      150 SKU       50,000 片      92%       │
│  当前库存总价值    45 条期初记录    产品种类       总片数         12个低库存   │
└─────────────────────────────────────────────────────────────────┘
```

**统计说明**:

- **库存总金额**: 当前仓库里所有产品的总价值
- **期初库存金额**: 期初入库时录入的总成本
- **库存产品数**: 有多少种产品（SKU）
- **库存总数量**: 总共有多少片产品
- **库存健康度**: 库存充足程度（越高越好）

## 📋 常见操作

### 录入普通入库

1. 访问 **入库记录** 页面
2. 点击 **"新增入库"** 按钮
3. 填写表单（与期初入库类似）
4. 选择入库原因：采购入库、退货入库等
5. 提交

### 录入出库

1. 访问 **出库记录** 页面 (`/inventory/outbound`)
2. 点击 **"新增出库"** 按钮
3. 填写表单
4. 提交

### 调整库存

1. 访问 **库存管理** 页面
2. 点击 **"库存调整"** 按钮
3. 选择产品和调整原因
4. 输入调整数量（正数增加，负数减少）
5. 提交

### 查看库存明细

1. 访问 **库存管理** 页面
2. 使用搜索框搜索产品
3. 使用筛选器按分类、库存状态筛选
4. 点击产品行查看详细信息

## 💡 使用技巧

### 1. 期初库存录入建议

**按分类录入**:

```
第一天：录入瓷砖类产品
第二天：录入辅材类产品
第三天：录入工具类产品
```

**记录成本来源**:
在备注中说明成本来源，例如：

- "2024年10月采购价"
- "供应商报价"
- "财务账面成本"

### 2. 库存盘点

定期进行库存盘点，确保账实相符：

1. 访问 **盘点管理** 页面 (`/inventory/counts`)
2. 创建新的盘点任务
3. 录入实际库存数量
4. 系统自动计算差异
5. 根据差异调整库存

### 3. 查看财务报表

1. 访问 **财务报表** 页面
2. 查看利润表、资产负债表
3. 期初库存会自动排除在当期损益之外

## 📊 数据说明

### 库存总金额 vs 期初库存金额

**库存总金额**:

- 当前仓库里所有产品的总价值
- 计算公式：SUM(当前数量 × 单位成本)
- 会随着入库、出库变化

**期初库存金额**:

- 期初入库时录入的总成本
- 历史数据，不会变化
- 反映期初资金占用

**差异分析**:

```
库存总金额 - 期初库存金额 = 库存成本变化

如果 > 0: 库存增加或成本上涨
如果 < 0: 库存减少或成本下降
如果 = 0: 库存成本基本持平
```

## ⚠️ 注意事项

1. **期初入库只能在系统初期使用**
   - 系统运行后，应使用普通入库记录
   - 期初入库不会影响当期利润

2. **成本核算方法**
   - 系统使用"移动加权平均法"
   - 每次入库会更新平均成本

3. **数据备份**
   - 建议定期导出数据备份
   - 重要操作前先备份

4. **库存调整**
   - 调整库存会生成调整记录
   - 可以查看历史调整记录

## 🆘 常见问题

### Q: 期初入库和普通入库有什么区别？

A:

- **期初入库**: 用于系统初始化，不影响当期利润
- **普通入库**: 正常业务入库，会影响库存成本

### Q: 可以修改已录入的期初库存吗？

A: 不能直接修改，但可以：

1. 使用"库存调整"功能修正数量
2. 联系管理员删除错误记录后重新录入

### Q: 库存总金额为什么和期初库存金额不一样？

A: 这是正常的，因为：

1. 库存总金额是实时计算的当前价值
2. 期初库存金额是历史数据
3. 两者的差异反映了库存的变化

### Q: 如何查看某个产品的期初库存？

A:

1. 访问 **入库记录** 页面
2. 使用筛选器选择"期初库存"
3. 搜索产品名称或编码
