# 盘点改进优先级（瓷砖行业）

> 目标：先把盘点做成“盘得准、找得快、看得懂”，不追求功能多。

## 现在最缺的是什么

### 1. 盘点范围要准
- `仓库`要保留。
- `库位/存放区域`也保留，但不是必填。
- 不填库位：按整个仓库盘点。
- 填了库位：只盘这个库位。
- 一旦选了库位，就不能自动扩大到整个仓库。

这条最重要。盘点范围不准，后面录得再认真也容易出错。

### 2. 实盘录入要改成“件 + 片”
- 现场不要录小数件。
- 现场录入方式改成：
  - `件数`
  - `零片`
- 系统自动换算总片数。
- 页面统一显示成：`1608片（100件8片）`

这样最适合瓷砖行业，仓库好录，财务也看得明白。

### 3. 商品要更容易找
- 相近名称的商品要排在一起。
- 例如：
  - `帝王白套线`
  - `帝王白柱子`
  - `帝王白腰线`
- 盘点时至少能按这些方式快速找：
  - `商品名称`
  - `商品编号`
  - `批次`
  - `只看未盘`
  - `只看有差异`

这条会直接影响盘点速度。

## 第二步再补的内容

### 4. 提交流程要更稳
- 没有盘点商品，不能开始盘点。
- 还有商品没盘完，不能提交结果。
- 如果盘点过程中账面数量变了，提交前要提醒复核。

### 5. 页面叫法要统一
- `系统数量` 改成 `账面数量`
- `实际数量` 改成 `实盘数量`
- `位置` 改成 `库位/存放区域`
- `整仓生成明细` 改成 `按范围生成盘点商品`
- `完成盘点` 改成 `提交盘点结果`

## 目前不着急做的
- 扫码
- 现场录入三位小数件数
- 强制维护库位

## 建议的先后顺序
1. 先改 `盘点范围`
2. 再改 `件 + 片录入`
3. 再改 `商品集中排序 + 快速筛找`
4. 最后补 `提交流程` 和 `页面文案`

## 一句话结论

你现在的盘点最缺的不是更多功能，而是这三件事：
`范围准确`、`件片录入`、`找货更快`。
