# Apple风格设计说明

## 设计理念

**极简主义 · 优雅精致 · 关注细节**

参考iOS和Apple官网的设计语言，打造高端、现代、易用的移动端体验。

## 核心设计原则

### 1. 极简主义

- **大留白**：充分的呼吸空间
- **少即是多**：去除多余元素
- **聚焦内容**：让信息说话

### 2. 优雅细节

- **精致圆角**：柔和的曲线
- **微妙阴影**：轻柔的层次感
- **流畅动画**：自然的过渡

### 3. 清晰层次

- **视觉引导**：清晰的信息架构
- **对比分明**：黑白分明的设计
- **空间感**：立体的层次结构

## 色彩系统

### Apple标准色彩

**主色系：**

```
iOS蓝：#007aff - 主要交互色
iOS绿：#34c759 - 成功/库存状态
iOS橙：#ff9500 - 警告/提醒
iOS紫：#5856d6 - 辅助功能
iOS红：#ff2d55 - 强调/错误
```

**灰度系：**

```
纯黑：#000 - 主要文字
深灰：#8e8e93 - 次要文字
背景灰：#f2f2f7 - 页面背景
卡片灰：#e5e5ea - 分隔/占位
纯白：#fff - 卡片/容器
```

**透明度系统：**

```
rgba(0, 122, 255, 0.1) - 10% 浅蓝背景
rgba(52, 199, 89, 0.1) - 10% 浅绿背景
rgba(255, 149, 0, 0.1) - 10% 浅橙背景
rgba(88, 86, 214, 0.1) - 10% 浅紫背景
rgba(255, 255, 255, 0.85) - 85% 半透明白
rgba(255, 255, 255, 0.5) - 50% 半透明白
rgba(255, 255, 255, 0.3) - 30% 半透明白
```

### 渐变系统

**统计卡片渐变：**

```css
/* 蓝紫渐变 */
linear-gradient(135deg, #007aff 0%, #5856d6 100%)

/* 绿色渐变 */
linear-gradient(135deg, #34c759 0%, #30d158 100%)

/* 橙红渐变 */
linear-gradient(135deg, #ff9500 0%, #ff2d55 100%)
```

**特点：**

- 135度对角线渐变
- 同色系过渡自然
- 鲜艳但不刺眼

## 圆角规范

### 分级圆角系统

```
超大圆角：20rpx - 主要容器（快捷功能、分类、产品）
大圆角：18rpx - 快捷图标
中圆角：16rpx - 统计卡片、分类项、产品卡片
小圆角：14rpx - 分类图标容器
```

**原则：**

- 柔和的曲线增加亲和力
- 不同层级使用不同圆角
- 保持视觉统一性

## 阴影系统

### 微妙阴影

```css
/* 标准卡片阴影 */
box-shadow: 0 2rpx 16rpx rgba(0, 0, 0, 0.06);
```

**特点：**

- 极轻的阴影（透明度仅6%）
- 垂直偏移2rpx
- 模糊半径16rpx
- 营造轻盈悬浮感

**原则：**

- 不使用深色阴影
- 阴影越轻越好
- 通过微妙层次区分深度

## 间距规范

### Apple式留白

**页面级间距：**

```
页面边距：32rpx - 充分的呼吸空间
卡片间距：32rpx - 清晰的分隔
底部间距：60rpx - 充足的结束空间
```

**组件级间距：**

```
卡片内边距：24rpx - 舒适的内容区
网格间距：16-20rpx - 适度的元素间隔
文字间距：12rpx - 清晰的行间距
```

**特点：**

- 间距明显大于传统设计
- 营造高端感和呼吸感
- 减少视觉压迫感

## 字体规范

### San Francisco风格

**字号层级：**

```
超大标题：48rpx (600) - 统计数字
大标题：36rpx (700) - 区块标题
标题：30rpx (600) - 产品名称
正文：28rpx (500) - 更多链接
正文：26rpx (500/600) - 标签/库存
说明：24rpx (400/500) - 副标题/编码
```

**字重规范：**

```
Light: 300 - 不使用
Regular: 400 - 辅助信息
Medium: 500 - 一般文字
Semibold: 600 - 重要标题/数字
Bold: 700 - 区块标题
```

**字间距：**

```
letter-spacing: -1rpx - 大号数字（紧凑）
letter-spacing: -0.5rpx - 区块标题（精致）
letter-spacing: -0.3rpx - 产品名称（清晰）
```

**特点：**

- 负值字间距更精致
- 数字字重600显得稳重
- 标题字重700更醒目

## 各区域设计

### 1. 顶部搜索栏

**设计特点：**

- iOS蓝纯色背景 `#007aff`
- 上下留白充足 `24rpx 0 32rpx`
- 简洁无装饰

**风格体现：**

- Apple标志性的蓝色
- 大胆的纯色块
- 专注搜索功能

### 2. 统计卡片

**设计特点：**

- 三色渐变卡片（蓝紫/绿/橙红）
- 白色文字，清晰易读
- 16rpx圆角，柔和曲线
- 微妙阴影 `0 2rpx 16rpx rgba(0, 0, 0, 0.06)`
- 向上偏移 `-16rpx` 叠加搜索栏

**色彩方案：**

```
主卡片：蓝→紫渐变（专业）
成功卡片：绿色渐变（活力）
警告卡片：橙→红渐变（醒目）
```

**数字显示：**

- 48rpx大号字
- 600字重
- -1rpx字间距（紧凑精致）
- 白色，对比鲜明

### 3. 快捷功能

**设计特点：**

- 白色卡片 + 20rpx大圆角
- 80rpx图标容器 + 18rpx圆角
- 10%透明度的色彩背景
- 鲜艳的图标颜色

**色彩搭配：**

```
蓝色组：rgba(0,122,255,0.1) 背景 + #007aff 图标
绿色组：rgba(52,199,89,0.1) 背景 + #34c759 图标
橙色组：rgba(255,149,0,0.1) 背景 + #ff9500 图标
紫色组：rgba(88,86,214,0.1) 背景 + #5856d6 图标
```

**布局特点：**

- 4列均分网格
- 图标和文字垂直居中
- 黑色文字，清晰易读

### 4. 产品分类

**设计特点：**

- 横向滚动列表
- 浅灰底 `#f2f2f7` + 16rpx圆角
- 激活态蓝色 `#007aff`
- 半透明白色图标容器

**激活态效果：**

```
背景：浅灰 → iOS蓝
文字：黑色 → 白色
图标：灰色 → 白色
容器：50%白 → 30%白（更透明）
```

**特点：**

- 激活态对比强烈
- 半透明层次丰富
- 颜色过渡自然

### 5. 热门产品

**设计特点：**

- 2列网格，20rpx间距
- 16rpx大圆角
- 浅灰卡片背景 `#f2f2f7`
- 白色信息区，清晰分隔

**产品卡片结构：**

```
┌─────────────────┐
│  图片区 280rpx   │ #e5e5ea 占位
├─────────────────┤
│  白色信息区      │ #fff
│  · 产品名称      │ 30rpx (600) 黑色
│  · 产品编码      │ 24rpx (400) 灰色
│  · 库存/标签     │ 26rpx (600) 绿色
└─────────────────┘
```

**色彩对比：**

- 灰色背景 + 白色信息区
- 黑色标题 + 灰色副标题
- 绿色库存（醒目）

## 交互设计

### 简洁交互

**原则：**

- 无复杂动画
- 无悬浮效果
- 无缩放变形
- 保持稳定感

**反馈方式：**

- 颜色变化（主要）
- 透明度调整
- 边框高亮
- 背景色切换

### 视觉反馈

**激活态：**

- 分类：背景变蓝，文字变白
- 统计卡片：纯展示，无交互
- 产品卡片：依赖系统点击反馈

## 布局特点

### 卡片式设计

**特点：**

- 所有内容都在卡片内
- 白色卡片 + 微妙阴影
- 20rpx大圆角
- 充分的内边距

### 网格系统

**响应式网格：**

```
统计卡片：3列网格，16rpx间距
快捷功能：4列网格，8rpx间距
产品展示：2列网格，20rpx间距
```

### 视觉层次

**Z轴层次：**

```
页面背景 (z=0)
    ↑
白色卡片 (z=1) - 微妙阴影
    ↑
卡片内容 (z=2)
```

## 移动端优化

### 触摸优化

**最小点击区域：**

```
快捷图标：80rpx × 80rpx
分类项：实际内容 + 内边距
产品卡片：整卡可点击
```

### 手势友好

- 分类横向滚动流畅
- 产品卡片间距充足
- 避免误触

### 性能优化

- 减少阴影使用
- 避免复杂渐变
- 优化图片加载
