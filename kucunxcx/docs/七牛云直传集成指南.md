# 七牛云直传集成指南

## 📋 概述

本项目已集成七牛云直传功能，支持小程序端直接上传文件到七牛云存储，无需通过业务服务器中转文件数据，提高上传速度并减轻服务器压力。

**重要说明**：本实现采用**七牛云官方推荐的标准方案**，使用微信小程序原生 `wx.uploadFile` API，无需引入第三方 SDK，保持代码简洁高效。

## 🎯 架构说明

```
┌──────────┐     ①请求上传参数       ┌──────────┐
│ 小程序端  │ ─────────────────────> │ 业务后端  │
│          │   (fileName, type, kind) │          │
│          │                          │ - 验证权限│
│          │     ②返回上传凭证        │ - 生成token│
│          │ <───────────────────── │ - 返回参数│
│          │   (token, key, url等)   │          │
└──────────┘                         └──────────┘
      │
      │ ③使用 wx.uploadFile 直传
      │   携带 token 和 key
      ↓
┌──────────┐
│ 七牛云   │ ← 文件数据不经过业务后端
└──────────┘
```

**架构优势**：
- ✅ 上传速度快（CDN 就近上传）
- ✅ 减轻服务器压力（文件不经过业务服务器）
- ✅ 安全可控（后端验证权限并生成有时效性的 token）
- ✅ 支持大文件上传（直连 CDN）
- ✅ 自动 CDN 加速访问
- ✅ 无需第三方 SDK（使用微信原生 API）
- ✅ 代码简洁易维护

**安全机制**：
- 后端验证用户身份和权限
- Token 有时效性（默认 1 小时）
- 每次上传前获取新 token
- 后端控制文件存储路径和命名

## 🚀 快速开始

### 1. 确认后端配置

确保后端已配置七牛云相关环境变量：
```env
QINIU_ACCESS_KEY=your_access_key
QINIU_SECRET_KEY=your_secret_key
QINIU_BUCKET=your_bucket_name
QINIU_DOMAIN=https://cdn.your-domain.com
```

后端 API 端点 `/api/upload/qiniu-token` 已实现，会返回：
- `uploadToken`: 上传凭证
- `uploadHost`: 主上传地址
- `fallbackUploadHosts`: 备用上传地址
- `key`: 文件存储路径
- `url`: 完整访问 URL

### 2. 使用上传服务

**无需额外配置**，直接使用 `qiniuService` 即可：

#### 方式一：便捷方法（选择并上传）

```typescript
import qiniuService from '../../services/qiniu-upload.service';

Page({
  async chooseImage() {
    try {
      // 选择并上传图片（一步完成）
      const results = await qiniuService.chooseAndUploadImage(
        'main',  // 图片类型: 'thumbnail' | 'main' | 'effect'
        3        // 最多选择 3 张
      );

      // 保存上传后的 URL
      const urls = results.map(r => r.url);
      this.setData({
        images: [...this.data.images, ...urls],
      });
    } catch (error) {
      console.error('上传失败:', error);
    }
  },
});
```

#### 方式二：手动控制上传流程

```typescript
import qiniuService from '../../services/qiniu-upload.service';

Page({
  async uploadImage() {
    try {
      // 1. 选择图片
      const res = await wx.chooseImage({
        count: 1,
        sizeType: ['compressed'],
        sourceType: ['album', 'camera'],
      });

      // 2. 上传到七牛云
      const result = await qiniuService.uploadImage(
        res.tempFilePaths[0],
        'thumbnail',  // 图片类型
        {
          onProgress: (progress) => {
            console.log(`上传进度: ${progress}%`);
          }
        }
      );

      wx.showToast({ title: '上传成功', icon: 'success' });

      // 3. 保存 URL
      this.setData({
        imageUrl: result.url, // 完整的 CDN URL
      });
    } catch (error) {
      console.error('上传失败:', error);
      wx.showToast({ title: '上传失败', icon: 'none' });
    }
  },
});
```

#### 方式三：批量上传

```typescript
async uploadMultipleImages(filePaths: string[]) {
  try {
    // 批量上传（自动控制并发数为 3）
    const results = await qiniuService.uploadFiles(
      filePaths,
      'main'  // 图片类型
    );

    wx.showToast({
      title: `成功上传 ${results.length} 张`,
      icon: 'success'
    });

    // 保存所有 URL
    const urls = results.map(r => r.url);
    this.setData({
      images: [...this.data.images, ...urls],
    });
  } catch (error) {
    wx.showToast({ title: '上传失败', icon: 'none' });
  }
}
```

## 🔧 API 参考

### qiniuService.uploadImage(filePath, kind, options)

上传单个图片文件。

**参数**：
- `filePath`: string - 文件的本地路径
- `kind`: 'thumbnail' | 'main' | 'effect' - 图片用途
  - `thumbnail`: 缩略图（最大 1MB）
  - `main`: 主图（最大 1MB）
  - `effect`: 效果图（最大 2MB）
- `options`: 上传选项（可选）
  - `onProgress?`: (progress: number) => void - 上传进度回调（0-100）
  - `showLoading?`: boolean - 是否显示加载提示（默认 true）

**返回**：
```typescript
Promise<{
  key: string;    // 文件在七牛云的 key
  url: string;    // 完整的 CDN 访问 URL
  hash?: string;  // 文件的哈希值
}>
```

**示例**：
```typescript
const result = await qiniuService.uploadImage(
  '/temp/image.jpg',
  'thumbnail',
  {
    onProgress: (progress) => console.log(`${progress}%`),
    showLoading: true
  }
);
console.log('上传成功:', result.url);
```

### qiniuService.chooseAndUploadImage(kind, count, options)

选择并上传图片（便捷方法）。

**参数**：
- `kind`: 'thumbnail' | 'main' | 'effect' - 图片用途
- `count`: number - 最多选择几张图片（默认 1）
- `options`: 上传选项（可选）
  - `onProgress?`: (progress: number) => void - 上传进度回调

**返回**：
```typescript
Promise<Array<{
  key: string;
  url: string;
  hash?: string;
}>>
```

**说明**：
- 自动调用 `wx.chooseImage`
- 自动显示上传进度
- 自动显示成功/失败提示
- 支持批量上传，失败的文件不影响其他文件

**示例**：
```typescript
// 选择并上传最多 3 张主图
const results = await qiniuService.chooseAndUploadImage('main', 3);
const urls = results.map(r => r.url);
```

### qiniuService.uploadFiles(filePaths, kind, options)

批量上传文件。

**参数**：
- `filePaths`: string[] - 文件路径数组
- `kind`: 'thumbnail' | 'main' | 'effect' - 图片用途
- `options`: 上传选项（可选）

**返回**：
```typescript
Promise<Array<{
  key: string;
  url: string;
  hash?: string;
}>>
```

**说明**：
- 自动控制并发数量（默认 3 个并发）
- 避免一次性发起太多请求
- 显示批量上传进度

**示例**：
```typescript
const filePaths = ['/temp/1.jpg', '/temp/2.jpg', '/temp/3.jpg'];
const results = await qiniuService.uploadFiles(filePaths, 'effect');
console.log(`成功上传 ${results.length} 张`);
```

## 🔒 安全配置

### 后端 Token 生成

后端已实现 `/api/upload/qiniu-token` 接口，返回格式：

```typescript
{
  "success": true,
  "data": {
    "uploadToken": "xxx",          // 上传凭证
    "uploadHost": "https://...",   // 主上传地址
    "fallbackUploadHosts": [...],  // 备用上传地址
    "key": "product/main/xxx.jpg", // 文件存储路径
    "url": "https://cdn.../xxx.jpg", // 完整访问 URL
    "domain": "https://cdn..."     // CDN 域名
  }
}
```

### Token 有效期

- 默认有效期：1 小时
- 每次上传前自动获取新 token
- Token 过期后会自动重新获取

### 文件大小限制

根据图片用途，后端返回不同的大小限制：

- **缩略图 (thumbnail)**：最大 1MB
- **主图 (main)**：最大 1MB
- **效果图 (effect)**：最大 2MB

### 在产品创建页面使用

```typescript
// pages/products/create.ts
import qiniuService from '../../services/qiniu-upload.service';

Page({
  data: {
    thumbnailUrl: '',
    mainImages: [] as string[],
    effectImages: [] as string[],
  },

  // 上传缩略图
  async onChooseThumbnail() {
    try {
      const results = await qiniuService.chooseAndUploadImage('thumbnail', 1);
      this.setData({
        thumbnailUrl: results[0].url,
      });
    } catch (error) {
      console.error('缩略图上传失败:', error);
    }
  },

  // 添加主图（多张）
  async onAddMainImage() {
    try {
      const results = await qiniuService.chooseAndUploadImage('main', 9);
      this.setData({
        mainImages: [...this.data.mainImages, ...results.map(r => r.url)],
      });
    } catch (error) {
      console.error('主图上传失败:', error);
    }
  },

  // 添加效果图
  async onAddEffectImage() {
    try {
      const results = await qiniuService.chooseAndUploadImage('effect', 9);
      this.setData({
        effectImages: [...this.data.effectImages, ...results.map(r => r.url)],
      });
    } catch (error) {
      console.error('效果图上传失败:', error);
    }
  },

  // 提交表单
  async onSubmit() {
    const payload = {
      // ... 其他字段
      thumbnailUrl: this.data.thumbnailUrl,
      mainImages: this.data.mainImages,
      effectImages: this.data.effectImages,
    };

    await productService.createProduct(payload);
  },
});
```

## ⚠️ 注意事项

### 1. 域名配置

确保七牛云域名已添加到小程序的合法域名列表：

**小程序管理后台 → 开发 → 开发管理 → 服务器域名**

- **uploadFile 合法域名**：
  - `https://up-z0.qiniup.com` (华东)
  - `https://up-z1.qiniup.com` (华北)
  - `https://up-z2.qiniup.com` (华南)
- **request 合法域名**：`https://cdn.your-domain.com` (你的 CDN 域名)

### 2. 并发控制

批量上传时已自动控制并发数（默认 3 个），避免一次性发起太多请求。可以根据实际情况调整 `qiniu-upload.service.ts` 中的 `CONCURRENCY` 常量。

### 3. 错误处理

所有上传方法都会抛出异常，记得使用 try-catch 捕获：

```typescript
try {
  const result = await qiniuService.uploadImage(filePath, 'thumbnail');
} catch (error) {
  console.error('上传失败:', error);
  wx.showToast({ title: '上传失败，请重试', icon: 'none' });
}
```

### 4. 图片压缩

上传前建议使用 `wx.compressImage` 压缩图片：

```typescript
const res = await wx.chooseImage({ count: 1 });
const compressed = await wx.compressImage({
  src: res.tempFilePaths[0],
  quality: 80,
});
await qiniuService.uploadImage(compressed.tempFilePath, 'thumbnail');
```

### 5. 上传进度

可以通过 `onProgress` 回调实时获取上传进度：

```typescript
await qiniuService.uploadImage(filePath, 'main', {
  onProgress: (progress) => {
    console.log(`上传进度: ${progress}%`);
    // 可以更新 UI 显示进度条
  }
});
```

## 🐛 常见问题

### Q1: 上传失败，提示"获取上传凭证失败"

**原因**：后端 token API 返回失败。

**解决**：
1. 检查后端七牛云配置是否正确（AK/SK/Bucket/Domain）
2. 检查用户是否有上传权限（已登录且通过权限验证）
3. 查看后端日志确认具体错误

### Q2: 上传成功但无法访问图片

**原因**：CDN 域名配置错误或未添加到小程序合法域名。

**解决**：
1. 检查七牛云存储空间的 CDN 域名配置
2. 确保域名已绑定并完成备案
3. 检查域名是否已添加到小程序合法域名列表（开发管理 → 服务器域名 → request 合法域名）

### Q3: 上传速度慢

**原因**：上传域名选择不当或网络问题。

**解决**：
1. 确认后端返回的 `uploadHost` 是否与存储空间区域匹配
2. 检查是否有 `fallbackUploadHosts` 备用域名
3. 测试网络连接质量

### Q4: 提示"域名未配置为小程序 request 合法域名"

**原因**：上传域名或 CDN 域名未添加到小程序合法域名列表。

**解决**：
在小程序管理后台添加：
- uploadFile 域名：`https://up-z0.qiniup.com` 等
- request 域名：你的 CDN 域名

### Q5: 并发上传时出现错误

**原因**：并发数过高导致请求堵塞。

**解决**：
调整 `qiniu-upload.service.ts` 中的并发控制：
```typescript
const CONCURRENCY = 2; // 降低并发数
```
