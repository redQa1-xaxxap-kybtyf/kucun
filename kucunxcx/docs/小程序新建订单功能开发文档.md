# 小程序端新建销售订单功能开发文档

**版本**: v1.0
**创建日期**: 2025-12-17
**目标**: 在小程序端实现销售订单创建功能，包括订单图片生成
**权限要求**: 仅管理员 (admin) 和销售 (sales) 角色可用

---

## 1. 功能概述

### 1.1 核心功能

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 创建销售订单 | 填写客户、产品、数量、单价等信息 | P0 |
| 订单图片生成 | 生成可分享的订单发货单图片 | P0 |
| 权限控制 | 仅 admin/sales 角色可见入口和操作 | P0 |
| 客户选择 | 搜索并选择已有客户 | P0 |
| 产品选择 | 搜索产品、查看库存、设置数量和单价 | P0 |
| 订单预览 | 提交前预览订单信息 | P1 |
| 费用项管理 | 添加运费、加工费等附加费用 | P2 |

### 1.2 与 Web 端对比

| 特性 | Web 端 | 小程序端（建议） |
|------|--------|-----------------|
| 订单类型 | 正常销售 + 调货销售 | 仅正常销售（简化） |
| 费用项 | 多种费用类型 | 简化为运费 |
| 预收款冲抵 | 支持 | 暂不支持（后续迭代） |
| 订单图片 | HTML Canvas 渲染 | 小程序 Canvas API |
| 表单验证 | Zod + React Hook Form | WXS 表单验证 |

## 4. 类型定义

### 4.1 订单类型 (`types/order.d.ts`)

```typescript
// 订单状态
type OrderStatus = 'draft' | 'confirmed' | 'shipped' | 'completed' | 'cancelled';

// 订单类型
type OrderType = 'NORMAL' | 'TRANSFER';

// 费用类型
type FeeType = 'SHIPPING' | 'PROCESSING' | 'PACKAGING' | 'OTHER';

// 费用支付方
type FeePayer = 'CUSTOMER' | 'COMPANY';

// 订单明细项
interface OrderItem {
  id?: string;
  productId: string;
  productName?: string;
  productCode?: string;
  quantity: number;           // 系统数量（片数）
  unitPrice: number;          // 片单价
  subtotal?: number;          // 小计
  piecesPerUnit?: number;     // 每件片数（用于显示）
  remarks?: string;
}

// 费用项
interface FeeItem {
  id?: string;
  feeType: FeeType;
  amount: number;
  payer: FeePayer;
  remarks?: string;
}

// 创建订单请求
interface CreateOrderRequest {
  customerId: string;
  status?: OrderStatus;
  orderType?: OrderType;
  items: OrderItem[];
  feeItems?: FeeItem[];
  remarks?: string;
}

// 订单响应（完整订单数据）
interface Order {
  id: string;
  orderNumber: string;
  customer: {
    id: string;
    name: string;
    phone?: string;
    address?: string;
  };
  items: OrderItem[];
  feeItems: FeeItem[];
  totalAmount: number;
  status: OrderStatus;
  orderType: OrderType;
  remarks?: string;
  createdAt: string;
  createdBy?: {
    id: string;
    name: string;
  };
}

// 客户简要信息
interface CustomerBrief {
  id: string;
  name: string;
  phone?: string;
  address?: string;
}

// 产品简要信息（用于选择）
interface ProductBrief {
  id: string;
  name: string;
  code: string;
  piecesPerUnit: number;
  inventory?: {
    availableQuantity: number;
  };
}
```

## 5. 服务层实现

### 5.1 订单服务 (`services/order.service.ts`)

```typescript
import { request } from '../utils/request';
import { API_ENDPOINTS } from '../config/api';
import type {
  Order,
  CreateOrderRequest,
  CustomerBrief,
  ProductBrief
} from '../types/order';

class OrderService {
  /**
   * 生成订单号
   */
  async generateOrderNumber(): Promise<string> {
    const response = await request<{ orderNumber: string }>({
      url: API_ENDPOINTS.ORDERS.GENERATE_NUMBER,
      method: 'GET',
      needAuth: true,
    });
    return response.orderNumber;
  }

  /**
   * 创建订单
   */
  async createOrder(data: CreateOrderRequest): Promise<Order> {
    const response = await request<Order>({
      url: API_ENDPOINTS.ORDERS.CREATE,
      method: 'POST',
      data: {
        ...data,
        status: 'confirmed',      // 小程序端直接确认
        orderType: 'NORMAL',      // 小程序端仅支持正常销售
      },
      needAuth: true,
    });
    return response;
  }

  /**
   * 获取订单详情
   */
  async getOrderDetail(id: string): Promise<Order> {
    const response = await request<Order>({
      url: API_ENDPOINTS.ORDERS.DETAIL(id),
      method: 'GET',
      needAuth: true,
    });
    return response;
  }

  /**
   * 搜索客户
   */
  async searchCustomers(keyword: string): Promise<CustomerBrief[]> {
    const response = await request<{ items: CustomerBrief[] }>({
      url: API_ENDPOINTS.CUSTOMERS.SEARCH,
      method: 'GET',
      params: {
        search: keyword,
        limit: 20,
        status: 'active',
      },
      needAuth: true,
    });
    return response.items || [];
  }

  /**
   * 搜索产品（带库存）
   */
  async searchProducts(keyword: string): Promise<ProductBrief[]> {
    const response = await request<{ items: ProductBrief[] }>({
      url: API_ENDPOINTS.PRODUCTS.LIST,
      method: 'GET',
      params: {
        search: keyword,
        limit: 20,
        status: 'active',
        includeInventory: true,
      },
      needAuth: true,
    });
    return response.items || [];
  }
}

export const orderService = new OrderService();
```

### 5.2 权限扩展 (`services/auth.service.ts`)

在现有 `AuthService` 中添加：

```typescript
class AuthService {
  // ... 现有方法

  /**
   * 检查是否有订单管理权限
   * 对应 Web 端的 sales:manage 权限
   */
  canManageOrders(): boolean {
    const userInfo = this.getUserInfo();
    if (!userInfo) return false;
    return userInfo.role === 'admin' || userInfo.role === 'sales';
  }
}
```

```typescript
    const price = Number(e.detail) || 0;

    items[index].unitPrice = price;
    items[index].subtotal = this.formatMoney(

    this.calculateTotals();
    this.validateForm();
  },

  onShippingFeeChange(e: WechatMiniprogram.CustomEvent) {
    const fee = Number(e.detail) || 0;
    this.setData({ shippingFee: fee });
    this.calculateTotals();
  },

  onRemarksChange(e: WechatMiniprogram.CustomEvent) {
    this.setData({ remarks: e.detail || '' });
  },

  // ========== 计算汇总 ==========
  calculateTotals() {
    const items = this.data.orderItems;

    const totalQuantity = items.reduce(
      (sum, item) => sum + (item.quantity || 0), 0
    );

    const productAmount = items.reduce(
      (sum, item) => sum + (item.quantity || 0) * (item.unitPrice || 0), 0
    );

    const totalAmount = productAmount + (this.data.shippingFee || 0);

    this.setData({
      totalQuantity,
      productAmount: this.formatMoney(productAmount),
      totalAmount: this.formatMoney(totalAmount),
    });
  },

  // ========== 表单验证 ==========

    const { selectedCustomer, orderItems } = this.data;

    const canSubmit = !!(
      selectedCustomer &&
      orderItems.length > 0 &&
      orderItems.every(item =>
        item.quantity > 0 && item.unitPrice > 0
      )
    );

    this.setData({ canSubmit });
  },

  // ========== 提交订单 ==========

    if (!this.data.canSubmit || this.data.submitting) return;

    try {
      this.setData({ submitting: true });
      Toast.loading({ message: '提交中...', forbidClick: true });

      const {
        selectedCustomer,
        orderItems,
        shippingFee,
        remarks
      } = this.data;

      const requestData = {
        customerId: selectedCustomer!.id,
        items: orderItems.map(item => ({
          productId: item.productId,
          quantity: item.quantity,
          unitPrice: item.unitPrice,
        })),
        feeItems: shippingFee > 0 ? [{
          feeType: 'SHIPPING' as const,
          amount: shippingFee,
          payer: 'CUSTOMER' as const,
        }] : [],
        remarks,
      };

      const order = await orderService.createOrder(requestData);

      Toast.clear();
      Toast.success('订单创建成功');

      // 跳转到订单图片页面
      setTimeout(() => {
        wx.redirectTo({
          url: `/pages/orders/image/index?id=${order.id}`,
        });
      }, 1500);

    } catch (error: any) {
      Toast.clear();
      Toast.fail(error.message || '创建订单失败');
    } finally {
      this.setData({ submitting: false });
    }
  },

  // ========== 工具方法 ==========
  formatDate(date: Date): string {
    const year = date.getFullYear();
    const month = String(date.getMonth() + 1).padStart(2, '0');
    const day = String(date.getDate()).padStart(2, '0');
    return `${year}-${month}-${day}`;
  },

  formatMoney(amount: number): string {
    return amount.toFixed(2);
  },
});
```

```typescript
import Toast from '@vant/weapp/toast/toast';
import { orderService } from '../../../services/order.service';
import type { Order } from '../../../types/order';

interface PageData {
  orderId: string;
  order: Order | null;
  loading: boolean;
  generating: boolean;

  canvasWidth: number;
  canvasHeight: number;
}

Page<PageData, WechatMiniprogram.Page.CustomOption>({
  data: {
    orderId: '',
    order: null,
    loading: true,
    generating: false,
    generatedImage: '',
    canvasWidth: 750,
    canvasHeight: 1000,
  },

  async onLoad(options) {
    const { id } = options;
    if (!id) {
      Toast.fail('订单ID不能为空');
      return;
    }

    this.setData({ orderId: id });

  onBack() {
    wx.navigateBack();

  // 分享配置
  onShareAppMessage() {
    return {
      title: `发货单 ${this.data.order?.orderNumber || ''}`,
      path: `/pages/orders/image/index?id=${this.data.orderId}`,
      imageUrl: this.data.generatedImage || '',
    };
  },

  // 加载订单并生成图片
  async loadOrderAndGenerate() {
    try {
      this.setData({ loading: true });

      // 获取订单详情
      const order = await orderService.getOrderDetail(this.data.orderId);
      this.setData({ order });

      // 生成图片
      await this.generateOrderImage(order);

    } catch (error: any) {
      console.error('加载订单失败:', error);
      Toast.fail(error.message || '加载失败');
    } finally {
      this.setData({ loading: false });
    }
  },

  // 生成订单图片
  async generateOrderImage(order: Order) {
    return new Promise<void>((resolve, reject) => {
      const query = wx.createSelectorQuery();
      query.select('#orderCanvas')
        .fields({ node: true, size: true })
        .exec((res) => {
          if (!res[0]) {
            reject(new Error('Canvas 初始化失败'));
            return;
          }

          const canvas = res[0].node;
          const ctx = canvas.getContext('2d');
          const dpr = wx.getWindowInfo().pixelRatio;

          // 设置 Canvas 尺寸
          const width = 750;
          const height = this.calculateCanvasHeight(order);

          canvas.width = width * dpr;
          canvas.height = height * dpr;
          ctx.scale(dpr, dpr);

          this.setData({ canvasWidth: width, canvasHeight: height });

          // 绘制发货单
          this.drawOrderContent(ctx, order, width, height);

          // 导出为图片
          setTimeout(() => {
            wx.canvasToTempFilePath({
              canvas,
              width: width * dpr,
              height: height * dpr,
              destWidth: width * 2,
              destHeight: height * 2,
              fileType: 'png',
              success: (res) => {
                this.setData({ generatedImage: res.tempFilePath });
                resolve();
              },
              fail: (err) => {
                reject(err);
              },
            });
          }, 100);
        });
    });
  },

  // 计算 Canvas 高度
  calculateCanvasHeight(order: Order): number {
    const baseHeight = 400; // 头部 + 表头 + 底部
    const itemHeight = 60;  // 每个明细行高度
    const itemCount = order.items.length;
    return baseHeight + itemCount * itemHeight;
  },

  // 绘制订单内容
  drawOrderContent(
    ctx: CanvasRenderingContext2D,
    order: Order,
    width: number,
    height: number
  ) {
    // 背景
    ctx.fillStyle = '#ffffff';
    ctx.fillRect(0, 0, width, height);

    // 分隔线
    ctx.strokeStyle = '#333333';
    ctx.lineWidth = 2;
    ctx.beginPath();
    ctx.moveTo(40, 80);
    ctx.lineTo(width - 40, 80);
    ctx.stroke();

    // ===== 客户信息 =====
    ctx.fillStyle = '#333333';
    ctx.font = '26px sans-serif';
    ctx.textAlign = 'left';

    let y = 120;
    ctx.fillText(`客户: ${order.customer.name}`, 40, y);

    if (order.customer.phone) {
      ctx.fillText(`电话: ${order.customer.phone}`, 400, y);
    }

    y += 40;
    if (order.customer.address) {
      ctx.fillText(`地址: ${order.customer.address}`, 40, y);

    ctx.fillText(
      `日期: ${this.formatDate(order.createdAt)}`,

    y += 40;

  async onSaveImage() {
    if (!this.data.generatedImage) {
      Toast.fail('图片未生成');
      return;
    }

    try {
      await wx.saveImageToPhotosAlbum({
        filePath: this.data.generatedImage,
      });
      Toast.success('已保存到相册');
    } catch (error: any) {
      if (error.errMsg?.includes('auth deny')) {
        // 引导授权
        wx.showModal({
          title: '提示',
          content: '需要您授权保存图片到相册',
          confirmText: '去授权',
          success: (res) => {
            if (res.confirm) {
              wx.openSetting();
            }
          },
        });
      } else {
        Toast.fail('保存失败');
      }

  },

  // 日期格式化
  formatDate(dateStr: string): string {
    const date = new Date(dateStr);
    const year = date.getFullYear();
    const month = String(date.getMonth() + 1).padStart(2, '0');
    const day = String(date.getDate()).padStart(2, '0');
    return `${year}年${month}月${day}日`;
  },

  // 数字转中文大写
  numberToChinese(num: number): string {
    const digits = ['零', '壹', '贰', '叁', '肆', '伍', '陆', '柒', '捌', '玖'];
    const units = ['', '拾', '佰', '仟'];
    const bigUnits = ['', '万', '亿'];

    if (num === 0) return '零元整';

    const [intPart, decPart] = num.toFixed(2).split('.');
    let result = '';

    // 处理整数部分
    const intNum = parseInt(intPart);
    if (intNum > 0) {
      let intStr = String(intNum);
      let groupIndex = 0;

      while (intStr.length > 0) {
        const group = intStr.slice(-4);
        intStr = intStr.slice(0, -4);

        let groupResult = '';
        for (let i = 0; i < group.length; i++) {
          const d = parseInt(group[i]);
          const unitIndex = group.length - 1 - i;

          if (d !== 0) {
            groupResult += digits[d] + units[unitIndex];
          } else if (groupResult && !groupResult.endsWith('零')) {
            groupResult += '零';
          }
        }

        if (groupResult) {
          groupResult = groupResult.replace(/零+$/, '');
          result = groupResult + bigUnits[groupIndex] + result;
        }

        groupIndex++;
      }
      result += '元';
    }

    // 处理小数部分
    const jiao = parseInt(decPart[0]);
    const fen = parseInt(decPart[1]);

    if (jiao === 0 && fen === 0) {
      result += '整';
    } else {
      if (jiao > 0) result += digits[jiao] + '角';
      if (fen > 0) result += digits[fen] + '分';
    }

    return result || '零元整';
  },
});
```

## 10. 注意事项

### 10.1 技术注意

1. **Canvas 兼容性**: 使用 `type="2d"` 的新版 Canvas API，兼容性更好
2. **图片保存权限**: 首次保存需要用户授权，需处理授权拒绝情况
3. **网络请求超时**: 产品/客户搜索需要做防抖处理
4. **表单状态管理**: 使用 `setData` 时注意性能，避免频繁全量更新

### 10.2 业务注意

1. **权限前置**: 进入页面先检查权限，无权限直接返回
2. **库存校验**: 产品选择时显示库存，但不强制限制（可能有线下库存）
3. **价格历史**: 后续可扩展自动带入历史价格功能
4. **离线处理**: 当前不支持离线创建，需提示用户检查网络

### 10.3 测试要点

1. 无权限用户尝试访问
2. 未登录用户尝试访问
3. 空表单提交
4. 产品数量为 0
5. 单价为 0
6. 大量产品（10+ 项）的性能
7. 图片生成在不同机型的表现
8. 保存图片权限拒绝后的处理
