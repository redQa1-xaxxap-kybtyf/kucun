# 产品列表布局优化说明

## 修复日期
2025-12-16

## 问题描述
产品列表页面在显示库存信息时，会遮盖规格信息，导致规格文本被过度压缩，用户无法看到完整的产品规格。

### 问题分析

**原始布局** (水平 flex):
```
┌─────────────────────────────────┐
│ 产品编码              [有货]    │
│ 产品名称                        │
│ 规格: 800x800  | 库存: 123箱56片│  ← 库存挤压规格！
└─────────────────────────────────┘
```

**问题原因**:
1. 规格和库存在同一行 (`flex-direction: row`)
2. 库存信息设置 `flex-shrink: 0` 不被压缩
3. 规格信息设置 `flex: 1` 会被压缩
4. 当库存数字较长时，规格被过度压缩甚至看不清

## 解决方案

### 核心改动：垂直布局

将 `product-footer` 从水平布局改为垂直布局，规格和库存各占一行。

**新布局** (垂直 flex):
```
┌─────────────────────────────────┐
│ 产品编码              [有货]    │
│ 产品名称                        │
│ 规格: 800x800mm 哑光面 加厚版   │  ← 规格完整显示
│ [库存: 123箱56片]               │  ← 库存独立一行
└─────────────────────────────────┘
```

### 样式改动详情

#### 1. product-footer 布局改动

**之前**:
```css
.product-footer {
  display: flex;
  justify-content: space-between;  /* 水平两端对齐 */
  align-items: center;
  gap: 12rpx;
}
```

**之后**:
```css
.product-footer {
  display: flex;
  flex-direction: column;  /* ✅ 改为垂直布局 */
  gap: 8rpx;
  align-items: flex-start;  /* 左对齐 */
}
```

#### 2. product-spec 规格样式优化

**之前**:
```css
.product-spec {
  flex: 1;  /* 占据剩余空间，会被压缩 */
  min-width: 0;  /* 允许被压缩 */
  /* ... */
}
```

**之后**:
```css
.product-spec {
  font-size: 24rpx;
  color: #999999;
  line-height: 1.4;
  width: 100%;  /* ✅ 占满整行宽度 */

  /* 单行截断（优雅处理超长规格） */
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

**优势**:
- ✅ 完整显示规格信息
- ✅ 超长规格用省略号处理
- ✅ 不受库存信息影响

#### 3. product-stock 库存样式优化

**之前**:
```css
.product-stock {
  flex-shrink: 0;  /* 不被压缩 */
  padding: 4rpx 8rpx;  /* 紧凑 */
  border-radius: 6rpx;
}
```

**之后**:
```css
.product-stock {
  font-size: 24rpx;
  font-weight: 600;
  padding: 6rpx 12rpx;  /* ✅ 更舒适的内边距 */
  border-radius: 8rpx;  /* ✅ 更圆润 */
  align-self: flex-start;  /* 左对齐 */
  line-height: 1.3;
}
```

**优势**:
- ✅ 独立一行，不挤压其他内容
- ✅ 更大的 padding，更易点击
- ✅ 视觉上更突出

## 响应式优化

### 单排布局 (layout-list)
```css
.product-footer {
  gap: 8rpx;  /* 标准间距 */
}
```

### 双排布局 (layout-grid-2)
```css
.layout-grid-2 .product-footer {
  gap: 10rpx;  /* 适中间距 */
}
```

### 三排布局 (layout-grid-3)
```css
.layout-grid-3 .product-footer {
  gap: 6rpx;  /* 紧凑间距，节省空间 */
}

.layout-grid-3 .product-stock {
  font-size: 20rpx;
  padding: 4rpx 8rpx;
  border-radius: 6rpx;
}
```

## 信息层次设计

优化后的产品卡片信息层次：

```
┌─────────────────────────────────┐
│ 【主标识】编码        [状态]    │  ← 最重要，字大加粗
│ 【次要】产品名称                │  ← 双行显示
│ 【辅助】规格信息                │  ← 单行完整
│ 【补充】库存数量（可选）        │  ← 有权限才显示
└─────────────────────────────────┘
```

**视觉权重**:
1. **产品编码** (32rpx, 700字重, 黑色) - 最突出
2. **产品名称** (26rpx, 400字重, #666) - 清晰可读
3. **规格** (24rpx, 400字重, #999) - 辅助信息
4. **库存** (24rpx, 600字重, 绿色背景) - 视觉标签

- 渲染性能: 相同（仅改变 flex-direction）
- 布局计算: 相同

## 设计原则总结

### 1. 信息优先级
**原则**: 重要信息完整显示，次要信息优雅降级。

- 产品编码（最重要）→ 必须完整显示
- 产品名称（重要）→ 双行显示
- 规格信息（重要）→ 单行完整，超长省略
- 库存数字（补充）→ 独立显示，不影响其他

### 2. 布局灵活性
**原则**: 垂直布局优于水平布局，在信息密度高的场景。

- ✅ 垂直布局：清晰、独立、易扩展
- ❌ 水平布局：拥挤、冲突、难维护

### 3. 响应式适配
**原则**: 不同布局密度下，调整间距和字号，保持可读性。

- 单排：标准字号，舒适间距
- 双排：标准字号，适中间距
- 三排：缩小字号，紧凑间距
