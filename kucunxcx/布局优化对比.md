### 4. 性能优化

#### 加载策略

**优化前：**

```typescript
// 一次性加载所有数据
loadProducts() {
  const products = getAllProducts()
  this.setData({ products })
}
```

**优化后：**

```typescript
// 分页加载 + 懒加载
async loadProducts(reset = false) {
  if (reset) {
    page = 1
    products = []
  }
  const newProducts = await fetchProducts(page, pageSize)
  this.setData({
    products: [...products, ...newProducts],
    finished: newProducts.length < pageSize
  })
}
```

#### 渲染优化

**优化前：**

- 所有图片立即加载
- 无占位符
- 无错误处理

**优化后：**

- 图片懒加载 `lazy-load="{{true}}"`
- 渐变占位符背景
- 错误降级处理

### 5. 代码质量

#### 样式组织

**优化前：**

```css
/* 样式分散，重复代码多 */
.layout-grid-2 .product-card {
  flex-direction: column;
  padding: 0;
  margin-bottom: 0;
  gap: 0;
}

.layout-grid-3 .product-card {
  flex-direction: column;
  padding: 0;
  margin-bottom: 0;
  gap: 0;
}
```

**优化后：**

```css
/* 提取公共样式 */
.layout-grid-2,
.layout-grid-3 {
  display: grid;
  padding: 12rpx 16rpx;
}

/* 各自特殊样式 */
.layout-grid-2 {
  gap: 12rpx;
}
.layout-grid-3 {
  gap: 8rpx;
}
```

#### TypeScript类型安全

**优化前：**

```typescript
toggleLayout() {
  const nextMode = ['list', 'grid-2', 'grid-3'][index]
  this.setData({ layoutMode: nextMode }) // 类型不安全
}
```

**优化后：**

```typescript
toggleLayout() {
  const modes: ('list' | 'grid-2' | 'grid-3')[] = ['list', 'grid-2', 'grid-3']
  const nextMode = modes[index]
  this.setData({ layoutMode: nextMode }) // 类型安全
}
```
