# 首页导航修复报告

**日期**: 2025-12-08
**问题**: 登录后点击左上角房子图标无法返回首页

---

## 🎯 问题描述

用户反馈：登录后点击左上角的房子图标（返回首页按钮）无法正常导航到首页。

## 🔍 问题分析

### 根本原因

1. **页面顺序配置错误**
   - `app.json` 中第一个页面是 `pages/auth/login`（登录页）
   - 微信小程序将第一个页面视为"首页"
   - 左上角房子图标尝试返回到登录页，但登录页有自动跳转逻辑，导致导航失败

2. **登录跳转路径不合理**
   - 登录成功后直接跳转到 `/pages/products/list`（产品列表页）
   - 跳过了真正的首页 `/pages/index/index`
   - 用户无法通过正常导航访问首页功能

3. **页面栈问题**
   - 使用 `wx.reLaunch()` 清空页面栈后，产品列表页成为栈底
   - 但微信识别的"首页"仍然是 `app.json` 第一个页面
   - 造成导航逻辑混乱

## ✅ 解决方案

### 修改 1: 调整 app.json 页面顺序

**文件**: `miniprogram/app.json`

```json
// ❌ 修改前
{
  "pages": [
    "pages/auth/login",      // 登录页作为第一个页面（错误）
    "pages/products/list",
    "pages/index/index",     // 首页在第三位
    ...
  ]
}

// ✅ 修改后
{
  "pages": [
    "pages/index/index",     // 首页作为第一个页面（正确）
    "pages/auth/login",
    "pages/products/list",
    ...
  ]
}
```

**作用**:

- 将真正的首页 `pages/index/index` 设为第一个页面
- 符合微信小程序最佳实践
- 左上角房子图标能正确识别首页位置

### 修改 2: 更新登录跳转逻辑

**文件**: `miniprogram/pages/auth/login.ts`

#### 位置 1: onLoad 中的自动跳转（第 14-22 行）

```typescript
// ❌ 修改前
if (authService.isLoggedIn()) {
  // 已登录，跳转到产品列表
  wx.reLaunch({
    url: '/pages/products/list', // 跳过首页
  });
}

// ✅ 修改后
if (authService.isLoggedIn()) {
  // 已登录，跳转到首页
  wx.reLaunch({
    url: '/pages/index/index', // 跳转到首页
  });
}
```

#### 位置 2: 登录成功后的跳转（第 85-89 行）

```typescript
// ❌ 修改前
setTimeout(() => {
  wx.reLaunch({
    url: '/pages/products/list', // 跳过首页
  });
}, 1500);

// ✅ 修改后
setTimeout(() => {
  wx.reLaunch({
    url: '/pages/index/index', // 跳转到首页
  });
}, 1500);
```

**作用**:

- 登录成功后用户首先看到首页（包含统计、轮播、热门产品等）
- 提供更好的用户体验和应用导览
- 用户可以从首页自由导航到各个功能模块

## 📝 技术说明

### 微信小程序页面配置规则

1. **首页定义**
   - `app.json` 中 `pages` 数组的第一个页面是小程序的首页
   - 小程序启动时默认加载首页
   - 左上角房子图标返回的就是这个首页

2. **页面导航 API**
   - `wx.reLaunch()`: 关闭所有页面，打开到应用内的某个页面
   - 使用 `wx.reLaunch()` 后，目标页面成为新的页面栈底部
   - 但"首页"的定义仍由 `app.json` 决定，不受 `reLaunch` 影响

3. **最佳实践**
   - 首页应该是应用的主要功能页面（统计、导航、概览）
   - 登录页不应该作为首页
   - 登录成功后应该跳转到真正的首页，而不是某个功能页面
