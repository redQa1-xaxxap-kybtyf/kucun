# 库存管理小程序 - UI界面设计说明

## 🎨 设计概览

### 设计理念

- **简洁高效** - 清晰的信息层级，突出核心功能
- **现代美观** - 渐变色彩，圆角卡片，阴影效果
- **易用友好** - 符合用户操作习惯，减少学习成本
- **响应迅速** - 加载反馈，交互动画，操作提示

### 视觉风格

```yaml
主色调: #1989fa (蓝色 - 科技感、专业)
辅助色:
  - 成功: #07c160 (绿色)
  - 警告: #ff976a (橙色)
  - 危险: #ee0a24 (红色)
  - 信息: #1989fa (蓝色)

背景色:
  - 页面背景: #f7f8fa (浅灰)
  - 卡片背景: #ffffff (白色)
  - 遮罩背景: rgba(0, 0, 0, 0.7)

文字颜色:
  - 主标题: #323233 (深灰)
  - 副标题: #646566 (中灰)
  - 辅助文本: #969799 (浅灰)
  - 禁用文本: #c8c9cc (极浅灰)

圆角:
  - 卡片: 16rpx
  - 按钮: 12rpx
  - 小标签: 8rpx

阴影:
  - 卡片: 0 2rpx 12rpx rgba(0, 0, 0, 0.04)
  - 悬浮: 0 4rpx 12rpx rgba(0, 0, 0, 0.08)
```

## 🎯 通用组件说明

### 1. 加载状态

```xml
<!-- 骨架屏 -->
<van-skeleton title row="3" />

<!-- 加载中 -->
<van-loading type="spinner" size="24px" />

<!-- 空状态 -->
<van-empty description="暂无数据" />
```

### 2. 提示反馈

```typescript
// 成功提示
wx.showToast({ title: '操作成功', icon: 'success' });

// 错误提示
wx.showToast({ title: '操作失败', icon: 'none' });

// 加载提示
wx.showLoading({ title: '加载中...' });
```

### 3. 下拉刷新/上拉加载

```xml
<van-pull-refresh bind:refresh="onRefresh">
  <van-list
    finished="{{ finished }}"
    bind:load="onLoad"
  >
    <!-- 列表内容 -->
  </van-list>
</van-pull-refresh>
```

## 📐 响应式设计

### 屏幕适配

```
基准宽度: 750rpx (iPhone 6)

单位说明:
- rpx: 响应式像素 (推荐)

- %: 百分比 (弹性布局)
```

## 🔧 实现注意事项

### 1. 性能优化

- 图片懒加载 (`lazy-load="{{true}}"`)
- 长列表虚拟滚动
- 防抖/节流搜索输入
- 骨架屏占位

### 2. 兼容性

- 微信基础库 ≥ 2.31.0
- 支持iOS 12+ / Android 5+
- Vant Weapp 兼容性良好

### 3. 无障碍

- 图片添加alt描述
- 按钮添加aria-label
- 表单添加label关联
