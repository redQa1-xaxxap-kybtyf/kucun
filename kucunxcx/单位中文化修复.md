# 小程序单位中文化修复

**日期**: 2025-12-08
**需求**: 小程序的单位要显示中文，和库存总览保持一致

---

## 🎯 需求说明

用户要求小程序中显示的单位（如 pieces, box, kg 等）要转换为中文（件、箱、千克等），和Web端库存总览的显示方式保持一致。

---

## 📝 实施方案

### 1. 创建格式化工具模块

#### TypeScript版本（用于逻辑处理）

**文件**: `miniprogram/utils/format.ts`

提供了以下函数：

- `formatUnit(unit)` - 单位英文转中文
- `formatAmount(amount)` - 金额格式化
- `formatDate(date)` - 日期格式化
- `formatDateTime(date)` - 日期时间格式化
- `formatQuantity(quantity, unit)` - 数量+单位组合
- `formatStockStatus(quantity)` - 库存状态判断

#### WXS版本（用于WXML模板）

**文件**: `miniprogram/utils/format.wxs`

WXS是微信小程序的模板脚本语言，可以直接在WXML中使用，提供了相同的格式化功能。

### 2. 单位映射表

```typescript
{
  // 通用单位
  'piece': '件',
  'pieces': '件',
  'box': '箱',
  'boxes': '箱',

  // 重量单位
  'kg': '千克',
  'g': '克',

  // 长度单位

  'sqm': '平方米',
```

**特性**:

- 自动处理单复数（pieces → 件, piece → 件）
- 大小写不敏感（PIECES → 件, Pieces → 件）
- 如果没有映射，返回原始单位

### 1. 产品列表页 (`pages/products/list.wxml`)

**修改内容**:

- 引入WXS模块：`<wxs src="../../utils/format.wxs" module="fmt" />`
- 更新库存显示：

  ```html

  fmt.formatQuantity(product.inventory.reservedQuantity, product.unit) }}
  ```

- 总库存：`100 pieces` → `100件`
- 可用库存：`80 pieces` → `80件`

### 3. 库存列表页 (`pages/inventory/list.wxml`)

  ```html

  fmt.formatQuantity(item.availableQuantity, item.unit) }}
  ```

**效果**:

- 原显示：`总库存: 100 pieces`
- 现显示：`总库存: 100件`

## 💡 使用方法

### 在WXML中使用（推荐）

```html
<!-- 1. 引入WXS模块 -->
<wxs src="../../utils/format.wxs" module="fmt" />

<!-- 2. 使用格式化函数 -->
<!-- 单位转换 -->
<text>{{ fmt.formatUnit('pieces') }}</text>
<!-- 显示：件 -->

<!-- 数量+单位 -->
<text>{{ fmt.formatQuantity(100, 'pieces') }}</text>
<!-- 显示：100件 -->

<!-- 金额格式化 -->
<text>{{ fmt.formatAmount(1234.56) }}</text>
<!-- 显示：￥1,234.56 -->

<!-- 库存状态 -->
<text>{{ fmt.formatStockStatus(10) }}</text>
<!-- 显示：偏低 -->
```

### 在TypeScript中使用

```typescript
import { formatUnit, formatQuantity, formatAmount } from '../../utils/format';

// 单位转换
const unit = formatUnit('pieces'); // 返回：件

// 数量+单位
const stock = formatQuantity(100, 'pieces'); // 返回：100件

// 金额格式化
const price = formatAmount(1234.56); // 返回：￥1,234.56
```

## 🔄 扩展性

如果需要添加新的单位映射，只需：

1. 在 `format.ts` 和 `format.wxs` 的 `UNIT_MAP` 中添加新映射：

```typescript
const UNIT_MAP = {
  // ... 现有映射
  newunit: '新单位',
};
```

2. 无需修改任何页面代码，新单位自动生效
