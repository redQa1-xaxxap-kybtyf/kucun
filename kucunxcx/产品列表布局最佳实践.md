# 产品列表布局最佳实践

## 概述

参考**小红书**、**淘宝**、**京东**等主流电商APP的设计，实现单列/双列/三列布局切换功能。

## 设计原则

### 1. 用户体验至上

- 🎯 **一键切换**：轻触图标即可切换布局
- 🔄 **状态记忆**：保存用户偏好设置
- ⚡ **流畅动画**：平滑的过渡效果
- 📱 **响应式**：适配不同屏幕尺寸

### 2. 信息层次清晰

- **单列模式**：信息最全面，适合详细浏览
- **双列模式**：平衡信息与视觉，推荐模式
- **三列模式**：信息最紧凑，快速浏览

### 3. 视觉一致性

- 统一的卡片样式
- 一致的间距规范
- 协调的色彩系统

## 三种布局模式

### 📋 单列布局（List Mode）

**适用场景：**

- 需要查看详细产品信息
- 对比产品参数
- 库存管理场景

**设计特点：**

```
┌─────────────────────────────┐
│ [图片]  产品名称        [标签]│
│ 160px   编码：P001           │
│        规格：800x800mm       │
│        库存：500片           │
└─────────────────────────────┘
```

**优势：**

- ✅ 信息展示最完整
- ✅ 易于扫描阅读
- ✅ 适合键盘操作

**样式规范：**

- 图片尺寸：160rpx × 160rpx
- 卡片间距：16rpx
- 内边距：20rpx
- 圆角：16rpx

---

### 🎨 双列布局（Grid-2 Mode）

**适用场景：**

- 普通商品浏览
- 推荐商品展示
- 默认推荐模式

**设计特点：**

```
┌────────────┐  ┌────────────┐
│    图片     │  │    图片     │
│  340px高    │  │  340px高    │
├────────────┤  ├────────────┤
│  产品名称    │  │  产品名称    │
│  编码       │  │  编码       │
│  库存       │  │  库存       │
└────────────┘  └────────────┘
```

**优势：**

- ✅ 视觉平衡感好
- ✅ 图片展示突出
- ✅ 信息适中
- ✅ 最受欢迎模式

**样式规范：**

- 图片高度：340rpx
- 列间距：12rpx
- 圆角：12rpx
- 内容区内边距：16rpx

**参考APP：**

- 小红书（推荐页）
- 京东（商品列表）
- 淘宝（商品瀑布流）

---

### 🏪 三列布局（Grid-3 Mode）

**适用场景：**

- 快速浏览大量商品
- SKU较多的场景
- 节省屏幕空间

**设计特点：**

```
┌────┐ ┌────┐ ┌────┐
│图片 │ │图片 │ │图片 │
│220 │ │220 │ │220 │
├────┤ ├────┤ ├────┤
│名称 │ │名称 │ │名称 │
│库存 │ │库存 │ │库存 │
└────┘ └────┘ └────┘
```

**优势：**

- ✅ 最大化商品展示数量
- ✅ 快速扫描浏览
- ✅ 节省滚动距离

**样式规范：**

- 图片高度：220rpx
- 列间距：8rpx
- 圆角：8rpx
- 内容区内边距：12rpx
- 隐藏：编码、规格等次要信息

**参考APP：**

- 淘宝（类目页）
- 拼多多（商品列表）
- 1688（批发页面）

## 切换逻辑

### 切换顺序

```
单列 → 双列 → 三列 → 单列
 ↓      ↓      ↓      ↓
bars  apps-o  grid-o  bars
```

### 图标映射

| 模式 | 图标名称 | 视觉效果   |
| ---- | -------- | ---------- |
| 单列 | bars     | ≡ 横条列表 |
| 双列 | apps-o   | ⊞ 四宫格   |
| 三列 | grid-o   | ⊡ 九宫格   |

### 反馈提示

```typescript

  const modes = ['list', 'grid-2', 'grid-3']

```

## 常见问题

### Q1: 为什么三列布局隐藏部分信息？

**A**: 参考淘宝、拼多多的做法，三列布局主要用于快速浏览大量商品，过多信息会造成视觉拥挤。保留**商品名称**和**库存数量**这两个核心信息即可。

### Q2: 图片高度如何确定？

**A**:

- 单列：160rpx（小缩略图）
- 双列：340rpx（主推模式，接近1:1）
- 三列：220rpx（紧凑模式）

参考小红书双列340rpx的黄金比例。

### Q3: 如何处理图片加载失败？

```xml
<image
  src="{{item.thumbnailUrl}}"
  binderror="onImageError"
  default-source="/assets/placeholder.png"
/>
```

### Q4: 是否需要瀑布流？

**A**:

- ✅ 推荐：图片高度一致时（如商品主图）
- ❌ 不推荐：本项目为库存管理，不需要瀑布流
- 💡 如需实现：使用`recycle-view`或`waterfall-flow`组件
