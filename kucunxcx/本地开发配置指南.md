# 微信小程序本地开发配置指南

## 🔧 本地开发环境配置

### 1. 微信开发者工具设置

打开微信开发者工具后，需要进行以下设置：

#### 方法一：关闭域名校验（推荐用于本地开发）

1. 打开微信开发者工具
2. 点击右上角"详情"按钮
3. 在"本地设置"标签页中
4. ✅ 勾选 **"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"**

![设置位置](https://developers.weixin.qq.com/miniprogram/dev/devtools/images/devtools2/not-verify-domain.png)

这样就可以在开发环境中访问 localhost 了。

### 2. 配置本机IP地址（可选，更稳定）

如果 localhost 不稳定，可以使用本机的局域网IP地址：

#### 获取本机IP地址

**Windows系统：**

```bash
ipconfig
```

查找 "IPv4 地址" 或 "IPv4 Address"，通常是 `192.168.x.x` 格式

**Mac/Linux系统：**

```bash
ifconfig | grep "inet "
```

#### 修改API配置

编辑 `miniprogram/config/api.ts`：

```typescript
const ENV = {
  // 开发环境
  development: {
    // 方式1: 使用 localhost（需要关闭域名校验）
    baseURL: 'http://localhost:3000/api',

    // 方式2: 使用本机IP（更稳定，推荐）
    // baseURL: 'http://192.168.1.100:3000/api', // 替换为你的实际IP

    timeout: 30000,
  },
  // ...
};
```

### 3. 确保后端服务运行

#### 启动后端服务

```bash
cd E:/kucun
npm run dev
```

后端应该运行在 `http://localhost:3000` 或 `http://0.0.0.0:3000`

#### 验证后端可访问

在浏览器中访问:

```
http://localhost:3000/api/products?page=1&limit=1
```

如果返回JSON数据，说明后端正常运行。

### 4. 小程序项目配置

#### project.config.json 配置

小程序项目的 `project.config.json` 应该包含:

```json
{
  "description": "项目配置文件",
  "setting": {
    "urlCheck": false, // 关闭URL合法性检查（本地开发）
    "es6": true,
    "enhance": true,
    "postcss": true,
    "minified": true
  },
  "compileType": "miniprogram",
  "appid": "你的AppID",
  "projectname": "kucunxcx"
}
```

**重要**: `"urlCheck": false` 允许访问非HTTPS的本地接口

### 常见错误排查

#### 错误1: "net::ERR_CONNECTION_REFUSED"

**原因**: 后端服务未启动
**解决**:

```bash
cd E:/kucun
npm run dev
```

#### 错误2: "request:fail url not in domain list"

**原因**: 未关闭域名校验
**解决**: 在开发者工具中勾选"不校验合法域名"

#### 错误3: "request:fail -2:net::ERR_FAILED"

**原因**:

1. localhost 解析问题
2. 端口被占用

**解决**:

1. 使用本机IP替代localhost
2. 检查后端是否真的运行在3000端口:
   ```bash
   netstat -ano | findstr 3000
   ```

#### 错误4: "404 Not Found"

**原因**: API路径不正确
**解决**: 确认后端API路径正确，应该是:

- `http://localhost:3000/api/auth/mini-login` (登录)
- `http://localhost:3000/api/products` (产品列表)
- `http://localhost:3000/api/categories` (分类列表)
- `http://localhost:3000/api/inventory` (库存列表)

## 📱 真机调试（可选）

如果需要在真机上调试：

### 方法1: 使用开发版

1. 微信开发者工具中点击"预览"
2. 用微信扫描二维码
3. **重要**: 手机和电脑必须在同一个局域网
4. 使用本机IP地址，不能使用localhost

```typescript
// config/api.ts 中使用本机IP
development: {
  baseURL: 'http://192.168.1.100:3000/api', // 你的实际IP
  timeout: 30000,
}
```

### 方法2: 使用局域网调试

1. 确保后端监听 `0.0.0.0` 而不是 `127.0.0.1`
2. 检查防火墙是否允许3000端口访问
3. 在小程序中使用本机IP地址

## 🔒 生产环境配置

### 正式上线前需要：

1. **准备HTTPS域名**
   - 小程序只能访问HTTPS接口
   - 需要SSL证书

2. **配置服务器域名**
   - 登录微信公众平台
   - 开发 → 开发管理 → 开发设置 → 服务器域名
   - 添加你的API域名

3. **修改生产环境配置**

   ```typescript
   // config/api.ts
   production: {
     baseURL: 'https://your-domain.com/api', // 替换为实际域名
     timeout: 30000,
   }
   ```

4. **启用URL检查**
   ```json
   // project.config.json
   {
     "setting": {
       "urlCheck": true // 生产环境启用
     }
   }
   ```
