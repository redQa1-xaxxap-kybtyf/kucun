### ❌ 存在问题

**后端使用NextAuth管理认证**，但小程序的token不被NextAuth识别。

#### 问题根源：

```
小程序登录 → 创建原始Session记录
             ↓
后端API → 使用NextAuth getServerSession验证
           ↓
        验证失败（格式不匹配）
           ↓
        返回401
```

3. **并行开发**：前后端可以分离开发
4. **后期联调**：UI完成后统一联调API

### 步骤2：创建专门的小程序认证中间件

创建 `lib/api/mini-middleware.ts`:

```typescript
import { NextRequest } from 'next/server';
import { prisma } from '@/lib/db';
import { unauthorizedResponse } from './response';

export function withMiniAuth(handler: Function) {
  return async (request: NextRequest, context: any) => {
    try {
      // 获取token
      const authHeader = request.headers.get('Authorization');
      if (!authHeader || !authHeader.startsWith('Bearer ')) {
        return unauthorizedResponse('请先登录');
      }

      const token = authHeader.substring(7);

      // 从数据库验证session
      const session = await prisma.session.findUnique({
        where: { sessionToken: token },
        include: { user: true },
      });

      if (!session || session.expires < new Date()) {
        return unauthorizedResponse('登录已过期');
      }

      // 将user信息添加到context
      const sessionWithUser = {
        user: session.user,
        expires: session.expires.toISOString(),
      };

      return await handler(request, context, sessionWithUser);
    } catch (error) {
      return unauthorizedResponse('认证失败');
    }
  };
}
```
