# 小程序数据格式适配修复

**日期**: 2025-12-08
**问题**: `Setting data field "products" to undefined is invalid`

---

## 🔍 问题分析

### 错误原因

微信小程序不允许将 `data` 字段设置为 `undefined`。当后端API返回的数据格式与小程序期望的格式不匹配时，会导致某些字段为 `undefined`，触发此错误。

### 数据格式差异

#### 产品API (`/api/products`)

**后端返回**:

```json
{
  "success": true,
  "data": {
    "data": [...],      // 产品数组
    "pagination": {
      "page": 1,
      "limit": 10,
      "total": 30,
      "totalPages": 3
    }
  }
}
```

**小程序期望**:

```typescript
{
  items: Product[],
  pagination: {
    page: number,
    limit: number,
    total: number,
    totalPages: number,
    hasNextPage: boolean,
    hasPreviousPage: boolean
  }
}
```

**问题**:

- 后端使用 `data.data` 存放产品数组，小程序期望 `items`
- 后端的 `pagination` 缺少 `hasNextPage` 和 `hasPreviousPage` 字段

---

## ✅ 修复方案

### 修改文件: `miniprogram/services/product.service.ts`

在 `getProducts()` 方法中添加数据格式转换：

```typescript
async getProducts(
  params: Partial<ProductQueryParams> = {}
): Promise<PaginationResponse<Product>> {
  // ... 设置查询参数 ...

  // 调用后端API
  const response = await get<any>(API_ENDPOINTS.PRODUCTS.LIST, queryParams)

  // 🔧 适配后端返回格式：将 data.data 转换为 items
  // 后端返回: { data: [...], pagination: {...} }
  // 小程序期望: { items: [...], pagination: {...} }
  return {
    items: response.data || [],
    pagination: {
      page: response.pagination?.page || params.page || 1,
      limit: response.pagination?.limit || params.limit || 10,
      total: response.pagination?.total || 0,
      totalPages: response.pagination?.totalPages || 0,
      hasNextPage: response.pagination?.page < response.pagination?.totalPages,
      hasPreviousPage: response.pagination?.page > 1,
    },
  }
}
```

### 关键改进

1. **字段映射**: `response.data` → `items`
2. **默认值处理**: 所有字段都有默认值，防止 `undefined`
3. **计算派生字段**:
   - `hasNextPage`: 根据 `page` 和 `totalPages` 计算
   - `hasPreviousPage`: 根据 `page` 计算

## 🔧 request.ts 响应处理逻辑

```typescript
// miniprogram/utils/request.ts:112
if (response.success) {
  // 如果有 data 字段，返回 data；否则返回整个 response
  resolve((response.data !== undefined ? response.data : response) as T);
}
```

**处理规则**:

1. 如果 `response.data` 存在（不是undefined），返回 `response.data`
2. 否则返回整个 `response`（兼容不同响应格式）

**对各API的影响**:

- **产品API**: 返回 `{data: [...], pagination: {...}}` ❌ 不匹配期望
- **分类API**: 返回 `[...]` ✅ 匹配期望
- **库存API**: 返回 `{inventories: [...], pagination: {...}}` ✅ 匹配期望

### 1. 数据服务层做格式适配

### 2. 总是提供默认值

```typescript

```
