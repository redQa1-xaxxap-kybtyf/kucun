# ERP 小程序开发需求

## 1. 项目定位

本小程序不是把 ERP 页面搬到微信里，而是在同一套 ERP 数据基础上，做两套入口：

- 客户端：无需登录，用于看产品、看花色、看案例、分享产品。
- 管理端：管理员登录后使用，用于查库存、查客户、开销售单、收付款、维护产品。

核心原则：

- 产品、分类、图片、库存、销售单、收付款全部复用现有 ERP 数据。
- 不在小程序里维护第二套产品库，避免重复上传、重复分类、数据不一致。
- 客户端不展示 ERP 的复杂字段，只展示客户能理解的“花色、图片、用途、规格、案例”。
- 管理端保留必要 ERP 操作，但流程要适配手机，优先搜索、扫码、快速操作。

## 2. 客户端找货方式

外墙罗马柱产品不能用传统树形分类展示。客户通常不知道该搜什么，也不清楚柱头、柱脚、转角石、线条这些专业叫法。

客户端主入口采用“花色货架”：

- 左侧：花色/系列。
- 右侧：当前花色下的产品组、配套件、案例。
- 顶部：当前花色内的快捷筛选。

示例：

- 左侧花色：热门、雅士白、爵士白、米黄、灰色、咖啡、红棕、青石。
- 右侧快捷筛选：全部、罗马柱、转角石、线条、外墙砖、配套、案例。
- 右侧产品组：雅士白罗马柱、雅士白转角石、雅士白线条、雅士白外墙砖、雅士白实拍案例。

客户找“雅士白转角石”的路径：

1. 打开小程序。
2. 点左侧“雅士白”。
3. 点右侧“转角石”。
4. 查看雅士白转角石产品组和规格。

## 3. 产品展示层级

不要直接向客户展示上百个 SKU。需要在 ERP 产品之上增加“小程序展示分组”。

展示层级：

1. 花色系列：雅士白、米黄、灰色等。
2. 产品组：雅士白转角石、雅士白罗马柱、雅士白线条。
3. 具体产品/SKU：具体编码、规格、图片、库存。
4. 案例图：实拍效果、铺贴展示、整套搭配。

产品组不是新产品，只是 ERP 产品的前台聚合视图。

产品组字段建议：

- 分组名称。
- 所属花色。
- 部件类型：罗马柱、转角石、线条、外墙砖、配套。
- 主图。
- 展示排序。
- 关联 ERP 产品 ID 列表。
- 关联案例图列表。
- 是否首页推荐。
- 是否客户端展示。

## 4. ERP 数据共用要求

小程序必须读取现有 ERP 数据：

- 产品：`Product`
- 分类：`Category`
- 产品图片：现有产品图片字段/图库。
- 库存：`Inventory`
- 客户：`Customer`
- 销售单：`SalesOrder`
- 销售明细：`SalesOrderItem`
- 收款：`PaymentRecord`

不允许在小程序项目内单独创建一套产品表。

允许新增的是“展示配置表”，用于把 ERP 产品整理成小程序更好理解的展示方式：

- 小程序花色系列表。
- 小程序产品组表。
- 小程序案例图表。
- 产品组与 ERP 产品关联表。
- 案例图与产品组/产品关联表。

这些表只负责前台展示，不替代 ERP 产品主数据。

## 5. 客户端页面需求

### 5.1 首页

目标：客户第一眼能知道怎么找货，不依赖搜索。

页面结构：

- 顶部：品牌名称、分享按钮。
- 主入口：热门花色/常用花色，使用真实产品纹理图做入口。
- 花色货架：左侧花色，右侧产品组。
- 推荐案例：按花色展示真实案例图。

搜索保留，但不作为主要入口。搜索用于懂产品编码、产品名称的客户。

### 5.2 花色货架页

核心页面，类似美团点餐的左右联动。

左侧：

- 热门
- 雅士白
- 爵士白
- 米黄
- 灰色
- 咖啡
- 红棕
- 其他

右侧：

- 当前花色标题。
- 快捷筛选：全部、罗马柱、转角石、线条、外墙砖、配套、案例。
- 产品组卡片。
- 案例图卡片。

产品组卡片展示：

- 主图。
- 名称。
- 所属花色。
- 产品数量。
- 规格数量。
- 是否有案例。
- 查看按钮。

### 5.3 产品组详情页

用于承接上百款同色产品，避免客户直接看到复杂 SKU 列表。

内容：

- 产品组主图。
- 花色、部件类型。
- 案例图横滑。
- 同色配套。
- 规格列表。
- 关联产品列表。
- 分享按钮。

规格列表要适合手机浏览：

- 默认只显示常用规格。
- 点击“展开全部规格”再显示完整 SKU。
- SKU 里展示编码、规格、图片、是否有货。

### 5.4 产品详情页

内容顺序：

1. 产品图片。
2. 产品名称、编码、花色、部件类型。
3. 规格信息。
4. 所属产品组。
5. 同色配套。
6. 实拍案例。
7. 分享。

客户端不显示成本、进价、内部库存调整、核销等 ERP 字段。

### 5.5 案例详情页

案例不是单独孤立展示，必须能反向带出产品。

内容：

- 案例大图。
- 花色。
- 使用位置。
- 相关产品组。
- 相关产品。
- 分享案例。

## 6. 分享要求

客户端不保留 ERP 旧入口，只允许客户分享、转发。

需要支持：

- 分享首页。
- 分享花色。
- 分享产品组。
- 分享产品。
- 分享案例。

分享路径必须带参数：

- `colorSeriesId`
- `groupId`
- `productId`
- `caseId`

用户打开分享链接后，必须直接进入对应内容，不要回到首页让用户重新找。

分享卡片建议：

- 标题：花色/产品组/产品名称。
- 图片：对应主图或案例图。
- 路径：带来源参数，方便后续统计分享效果。

## 7. 管理端需求

管理员从“我的”或隐藏管理入口登录。

管理员登录后显示移动工作台：

- 查库存。
- 开销售单。
- 收款登记。
- 开票状态。
- 产品维护。
- 客户查询。

### 7.1 查库存

支持：

- 扫码查产品。
- 输入产品编码/名称查产品。
- 按花色、产品组筛选。
- 查看总库存、可用库存、锁定库存、批次、库位。

### 7.2 开销售单

手机端流程要短：

1. 选客户。
2. 选产品/扫码产品。
3. 选批次/库存。
4. 填数量、单价。
5. 确认金额。
6. 提交销售单。

销售单创建后同步 ERP，不在小程序单独保存一套订单。

### 7.3 收付款

支持：

- 查看客户应收。
- 查看销售单未收金额。
- 登记收款。
- 上传凭证。
- 关联销售单。

### 7.4 开票

支持：

- 查看待开票销售单。
- 登记发票号。
- 登记开票金额。
- 查看开票状态。

### 7.5 产品维护

管理员可在小程序维护产品，但必须走 ERP 产品数据。

支持：

- 新增产品。
- 编辑产品。
- 上传/更换产品图片。
- 设置花色系列。
- 设置产品组。
- 设置是否客户端展示。
- 设置排序。
- 下架产品。

删除规则：

- 有库存的产品不能删除。
- 有销售单、入库、出库、收付款关联的产品不能删除。
- 无库存且无业务记录的产品才允许删除。
- 不满足删除条件时，只允许停用/下架。

## 8. 权限规则

客户端：

- 不需要登录。
- 只能看公开展示的产品、产品组、案例。
- 不能看到成本、内部库存、客户资料、销售单、收付款。

管理员：

- 必须登录。
- 按 ERP 权限控制功能。
- 产品删除、销售单创建、收款登记需要记录操作人。

## 9. UI 设计要求

整体风格：

- 产品图片优先。
- 页面简单，不堆字段。
- 用真实纹理图做花色入口，不用纯色块。
- 手机端优先，按钮要大，路径要短。

建议配色：

- 背景：`#F8F6F1`
- 卡片：`#FFFFFF`
- 主文字：`#1F2328`
- 次文字：`#73716D`
- 边框：`#E7E0D6`
- 选中态：`#27594F`
- 点缀：`#B68A45`

交互要求：

- 首页 3 秒内能进入目标花色。
- 2 步内能找到某个花色下的转角石/罗马柱/线条。
- 产品组默认不展开全部 SKU。
- 案例图必须能带出相关产品。
- 分享按钮要显眼，但不要压过产品图。

## 10. 接口需求

建议新增小程序专用 API，不直接复用所有 ERP 后台列表接口。

客户端 API：

- 获取公开花色系列。
- 获取花色下产品组。
- 获取产品组详情。
- 获取产品详情。
- 获取案例列表。
- 获取案例详情。
- 记录浏览/分享统计。

管理端 API：

- 管理员登录。
- 库存查询。
- 产品新增/编辑/下架/删除校验。
- 产品图片上传。
- 销售单创建。
- 收款登记。
- 开票状态更新。

## 11. 第一期范围

第一期先做：

- 小程序项目基础结构。
- 客户端首页。
- 花色货架页。
- 产品组详情页。
- 产品详情页。
- 案例详情页。
- 分享能力。
- 管理员登录。
- 管理端库存查询。
- 管理端产品新增/编辑/下架。
- 删除产品校验。

第一期暂缓：

- 完整报表。
- 复杂财务核销。
- 打印设计器。
- 大批量导入。
- 复杂审批流。

## 12. 验收标准

客户端：

- 不登录可以浏览公开产品。
- 用户能从首页快速进入“雅士白”等花色。
- 用户能在同一花色下快速切换罗马柱、转角石、线条、外墙砖。
- 用户能分享产品组、产品、案例。
- 分享链接能直达对应页面。
- 产品和图片来自 ERP，不重复维护。

管理端：

- 管理员登录后能查库存。
- 管理员能新增和编辑 ERP 产品。
- 有库存或有关联业务的产品不能删除。
- 小程序创建的销售单能进入 ERP 销售单列表。
- 小程序登记的收款能进入 ERP 收款记录。

数据：

- ERP 产品改名、换图、上下架后，小程序展示同步变化。
- 小程序展示分组只影响前台展示，不改变 ERP 原始业务数据。
