# 数据清理脚本使用说明

## 📋 可用的清理命令

### 1. 清空销售订单和收款记录 (推荐用于测试)

```bash
npm run db:clear-sales
```

**清理内容**:

- ✅ 销售订单 (SalesOrder)
- ✅ 销售订单明细 (SalesOrderItem)
- ✅ 销售订单费用项 (SalesOrderFeeItem)
- ✅ 收款记录 (PaymentRecord)
- ✅ 退货订单 (ReturnOrder)
- ✅ 退货订单明细 (ReturnOrderItem)
- ✅ 退款记录 (RefundRecord)
- ✅ 出库记录 (OutboundRecord)
- ✅ 客户往来账单 (AccountStatement - 仅客户)
- ✅ 往来账单交易 (StatementTransaction - 仅客户相关)

**保留内容**:

- ✅ 客户 (Customer)
- ✅ 产品 (Product)
- ✅ 产品变体 (ProductVariant)
- ✅ 库存 (Inventory)
- ✅ 供应商 (Supplier)
- ✅ 用户 (User)
- ✅ 厂家发货订单 (FactoryShipmentOrder)
- ✅ 应付款记录 (PayableRecord)
- ✅ 付款记录 (PaymentOutRecord)

**使用场景**:

- 测试销售订单创建功能
- 测试收款记录功能
- 清理测试数据但保留基础数据

---

### 2. 清空所有业务数据 (保留用户)

```bash
npm run db:clear
```

**清理内容**:

- ✅ 所有业务数据 (订单、收款、库存、产品等)
- ✅ 非管理员用户

**保留内容**:

- ✅ 管理员用户
- ✅ 系统设置

**使用场景**:

- 重新开始测试
- 清理所有测试数据

---

### 3. 清空所有数据 (包括用户)

```bash
npm run db:clear-all
```

**清理内容**:

- ✅ 所有业务数据
- ✅ 所有用户 (包括管理员)

**保留内容**:

- ❌ 无 (除了数据库结构)

**使用场景**:

- 完全重置系统
- 准备生产环境部署

---

### 4. 重置数据库 (重新迁移)

```bash
npm run db:reset
```

**操作内容**:

- ✅ 删除所有数据
- ✅ 重新运行所有迁移
- ✅ 运行 seed 脚本

**使用场景**:

- 数据库结构变更后重置
- 开发环境初始化

## ⚠️ 注意事项

### 1. 数据不可恢复

所有清理操作都是**永久性删除**,无法恢复!

建议:

- 在生产环境使用前务必备份数据库
- 在测试环境先验证清理效果
- 确认清理范围后再执行

### 2. 等待时间

所有清理脚本都有 **5 秒等待时间**,可以按 `Ctrl+C` 取消操作。

### 3. 外键约束

清理脚本已按照正确的依赖关系顺序删除数据:

1. 先删除子表数据 (如订单明细)
2. 再删除父表数据 (如订单)

### 4. 级联删除

某些表配置了级联删除 (`onDelete: Cascade`):

- 删除销售订单时,会自动删除订单明细和费用项
- 删除退货订单时,会自动删除退货订单明细

## 📊 清理脚本详细说明

### `clear-sales-and-payments.ts`

**执行顺序**:

1. 获取所有客户往来账单 ID
2. 删除往来账单交易记录 (仅客户相关)
3. 删除客户往来账单
4. 删除退款记录
5. 删除退货订单明细
6. 删除退货订单
7. 删除收款记录
8. 删除出库记录
9. 删除销售订单费用项
10. 删除销售订单明细
11. 删除销售订单

**为什么这样设计**:

- 保留供应商往来账单 (用于应付款管理)
- 保留基础数据 (客户、产品、库存)
- 只清理销售相关的业务数据

## 🛠️ 自定义清理脚本

如果需要自定义清理范围,可以参考 `scripts/clear-sales-and-payments.ts`:

```typescript
// 示例: 只清空草稿状态的销售订单
const deletedOrders = await prisma.salesOrder.deleteMany({
  where: {
    status: 'draft',
  },
});

// 示例: 只清空某个客户的收款记录
const deletedPayments = await prisma.paymentRecord.deleteMany({
  where: {
    customerId: 'customer-id-here',
  },
});

// 示例: 只清空某个时间段的数据
const deletedOrders = await prisma.salesOrder.deleteMany({
  where: {
    createdAt: {
      gte: new Date('2024-01-01'),
      lte: new Date('2024-01-31'),
    },
  },
});
```

## 📝 常见问题

### Q1: 清理后还有数据残留?

**A**: 检查以下几点:

1. 是否有其他表引用了这些数据 (外键约束)
2. 是否有级联删除配置错误
3. 查看脚本输出的清理汇总

### Q2: 清理失败怎么办?

**A**:

1. 查看错误信息
2. 检查数据库连接
3. 检查外键约束
4. 手动删除有问题的数据

### Q3: 如何只清理某个客户的数据?

**A**: 修改脚本,添加 `where` 条件:

```typescript
const deletedOrders = await prisma.salesOrder.deleteMany({
  where: {
    customerId: 'customer-id-here',
  },
});
```

### Q4: 清理后如何恢复数据?

**A**:

- 如果有数据库备份,可以恢复备份
- 如果没有备份,数据无法恢复
- 建议在清理前先备份数据库
