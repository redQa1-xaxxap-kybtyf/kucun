# 数据库清理脚本使用指南

## 概述

`database-cleanup.ts` 脚本用于全面清理数据库中的所有测试数据，同时保留管理员账户和系统配置。

## 功能特性

✅ **安全性保障**

- 在事务中执行，确保原子性（要么全部成功，要么全部回滚）
- 自动识别并保留所有管理员账户（role = 'ADMIN'）
- 保留系统配置数据

✅ **全面清理**

- 删除所有业务数据（客户、产品、订单、库存等）
- 删除所有非管理员用户及其关联数据
- 重置订单序号

✅ **详细报告**

- 实时显示清理进度
- 统计每类数据的删除数量
- 验证保留的管理员账户和系统配置

## 使用方法

### 1. 备份数据库（强烈建议）

在执行清理前，先备份数据库：

```bash
# 如果有备份脚本
npm run db:backup

# 或手动备份 MySQL 数据库
mysqldump -u root -p your_database_name > backup_$(date +%Y%m%d_%H%M%S).sql
```

### 2. 执行清理脚本

```bash
npx tsx scripts/database-cleanup.ts
```

### 3. 查看执行结果

脚本会显示：

- 保留的管理员账户列表
- 每类数据的删除数量
- 总删除记录数
- 验证保留的数据

## 注意事项

⚠️ **重要警告**

1. **不可撤销**: 一旦执行成功，删除的数据无法恢复（除非有数据库备份）
2. **生产环境**: 谨慎在生产环境使用，建议只在开发/测试环境执行
3. **备份优先**: 执行前务必备份数据库
4. **管理员账户**: 确保至少有一个管理员账户，否则清理后将无法登录

⚠️ **执行前检查**

- [ ] 已确认当前是开发/测试环境
- [ ] 已备份数据库
- [ ] 已确认存在管理员账户
- [ ] 已了解清理范围

## 故障排除

### 问题：事务超时

**原因**: 数据量过大，超过事务超时时间（10分钟）

**解决方案**:

1. 分批删除数据
2. 或修改脚本中的 `timeout` 参数

### 问题：外键约束错误

**原因**: 删除顺序不正确，违反外键约束

**解决方案**:

- 脚本已按正确顺序删除，如遇此问题请报告

### 问题：连接失败

**原因**: 数据库连接配置错误

**解决方案**:

1. 检查 `.env` 文件中的 `DATABASE_URL`
2. 确保数据库服务正在运行

## 恢复数据

如果需要恢复数据：

```bash
# 从备份恢复
mysql -u root -p your_database_name < backup_20250113_120000.sql

# 或重新运行seed脚本
npm run db:seed
```

## 技术细节

### 事务配置

```typescript
{
  maxWait: 300000,  // 最大等待时间: 5分钟
  timeout: 600000,  // 超时时间: 10分钟
}
```

### 删除顺序

脚本按照以下顺序删除数据，确保不违反外键约束：

1. 库存相关（从子表到父表）
2. 财务相关
3. 订单相关（从明细到主单）
4. 产品相关（从价格到产品）
5. 客户和供应商
6. 非管理员用户
7. 订单序号
