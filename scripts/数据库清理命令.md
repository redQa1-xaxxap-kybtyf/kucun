# 数据库清理命令快速参考

## 🚀 快速命令

### 1. 清空所有数据（保留管理员）

```bash
npm run db:clear-all
```

**功能**：

- ✅ 删除所有业务数据
- ✅ 保留管理员账户
- ✅ 适合完全重置数据库

**输出示例**：

```
🧹 开始清空数据库...
⚠️  警告：此操作将删除所有业务数据，但保留管理员账户！
...
✨ 数据库清空完成！
```

---

### 2. 验证管理员账户

```bash
npm run db:verify-admin
```

**功能**：

- ✅ 检查管理员账户是否存在
- ✅ 验证密码是否正确
- ✅ 显示用户统计信息

**输出示例**：

```
🔍 验证管理员账户...
✅ 找到 1 个管理员账户：
👤 系统管理员
   用户名: admin
   密码验证: ✅ 正确 (admin123456)
```

---

### 3. 清空测试数据（保留用户）

```bash
npm run db:clear
```

**功能**：

- ✅ 删除业务数据
- ✅ 保留所有用户账户
- ✅ 适合清理测试数据

---

### 4. 重新生成测试数据

```bash
npm run db:seed
```

**功能**：

- ✅ 创建管理员和销售员账户
- ✅ 生成测试客户、供应商
- ✅ 生成测试产品、订单等

---

### 5. 完全重置数据库

```bash
npm run db:reset
```

**功能**：

- ⚠️ 删除所有数据（包括管理员）
- ⚠️ 重新运行所有迁移
- ⚠️ 自动运行 seed 脚本

---

## 📋 常用组合命令

### 组合1：完全清空 + 验证

```bash
npm run db:clear-all && npm run db:verify-admin
```

**说明**：清空所有数据后，立即验证管理员账户

---

### 组合2：完全清空 + 重新生成测试数据

```bash
npm run db:clear-all && npm run db:seed
```

**说明**：清空所有数据后，重新生成完整的测试数据

---

### 组合3：验证 + 清空 + 生成

```bash
npm run db:verify-admin && npm run db:clear-all && npm run db:seed
```

**说明**：先验证管理员，然后清空数据，最后生成新的测试数据

## ⚠️ 注意事项

1. **环境限制**
   - ✅ 开发环境：可以使用
   - ✅ 测试环境：可以使用
   - ❌ 生产环境：禁止使用

2. **数据备份**
   - 执行前请确认已备份重要数据
   - 可以使用 `scripts/backup-database.bat` 进行备份

3. **数据库连接**
   - 确保 `.env.local` 文件配置正确
   - 确保 `DATABASE_URL` 指向正确的数据库

## 💡 使用建议

### 场景1：开发测试

```bash
# 每天开始工作前
npm run db:clear-all && npm run db:seed
```

### 场景2：功能测试

```bash
# 测试前清空数据
npm run db:clear-all

# 测试后验证
npm run db:verify-admin
```

### 场景3：数据修复

```bash
# 如果数据混乱，完全重置
npm run db:clear-all && npm run db:seed
```

## 🔧 故障排除

### 问题1：找不到管理员账户

**解决方案**：

```bash
# 创建管理员账户
npx tsx scripts/create-correct-admin.ts
```

### 问题2：命令执行失败

**解决方案**：

```bash
# 检查数据库连接
npx tsx scripts/verify-database-connection.ts

# 检查环境变量
cat .env.local  # Linux/Mac
type .env.local  # Windows
```

### 问题3：数据没有清空

**解决方案**：

```bash
# 使用完全重置
npm run db:reset

# 然后重新生成数据
npm run db:seed
```
