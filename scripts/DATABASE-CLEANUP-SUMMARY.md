### 🚀 使用方法

#### 1. 备份数据库（强烈建议）

```bash
mysqldump -u root -p your_database_name > backup_$(date +%Y%m%d_%H%M%S).sql
```

#### 2. 执行清理脚本

```bash
npx tsx scripts/database-cleanup.ts
```

#### 3. 查看执行结果

脚本会显示：

- 保留的管理员账户列表
- 每类数据的删除数量
- 总删除记录数
- 验证保留的数据

### 🔍 清理范围

#### 将被删除的数据

- **库存相关**: 库存成本队列、库存盘点、出入库记录、批次规格等
- **财务相关**: 账户流水、退款记录、收付款记录、应付账款等
- **订单相关**: 销售订单、采购订单、退货单、发货单等
- **产品相关**: 产品、产品变体、临时产品、价格记录等
- **业务实体**: 所有客户、所有供应商
- **用户数据**: 所有非管理员用户及其日志
- **其他**: 订单序号

#### 将被保留的数据

- ✅ 所有管理员用户账户（role = 'ADMIN'）
- ✅ 管理员的登录日志和系统日志
- ✅ 系统配置（SystemSetting 表）
- ✅ 设置变更日志（SettingChangeLog 表）

### ⚠️ 安全特性

1. **事务保护**: 所有删除操作在事务中执行，失败会自动回滚
2. **管理员保护**: 自动识别并保留所有管理员账户
3. **系统配置保护**: 保留系统配置数据
4. **详细日志**: 记录每类数据的删除数量

### 📊 技术实现
