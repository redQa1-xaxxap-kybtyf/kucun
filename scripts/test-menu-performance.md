# 菜单性能测试指南

## 🎯 测试目标

验证菜单优化后的性能提升和用户体验改善

## 📋 快速测试清单

### 1. 启动开发服务器

```bash
npm run dev
```

### 2. 基础功能测试（5分钟）

#### ✅ 测试1: 单次菜单切换

1. 点击"仪表盘"菜单
2. 点击"产品管理"菜单
3. 点击"库存管理"菜单

**预期结果**:

- 切换时间 < 100ms
- 有轻微的过渡动画
- 菜单高亮状态即时更新
- 无数据闪烁

#### ✅ 测试2: 快速连续点击

1. 快速点击5-6个不同菜单项
2. 观察是否有卡顿或延迟

**预期结果**:

- 每次点击都有即时视觉反馈（opacity变化）
- 没有积累延迟
- 界面保持流畅

#### ✅ 测试3: 子菜单展开/收起

1. 点击"库存管理"菜单
2. 观察子菜单展开动画
3. 再次点击收起

**预期结果**:

- 展开/收起动画流畅（150ms）
- 图标旋转动画流畅
- 无抖动或跳跃

#### ✅ 测试4: 响应式布局

1. 调整浏览器窗口宽度
2. 测试移动端（< 768px）
3. 测试平板端（768-1024px）
4. 测试桌面端（> 1024px）

**预期结果**:

- 布局切换流畅无卡顿
- 侧边栏状态正确
- 无布局抖动

#### ✅ 测试5: 数据加载切换

1. 点击"产品管理"（有数据的页面）
2. 快速点击"客户管理"

**预期结果**:

- 切换时保持上一页面数据（不闪烁）
- 新数据加载时平滑替换
- 无白屏或空白状态

| 指标           | 目标值 | 检查位置     |
| -------------- | ------ | ------------ |
| **Scripting**  | < 50ms | Summary 面板 |
| **Rendering**  | < 30ms | Summary 面板 |
| **Painting**   | < 20ms | Summary 面板 |
| **Long Tasks** | 0个    | Main 时间线  |

**如何判断**:

- ✅ 绿色区域：性能良好

- ❌ 红色区域：严重性能问题

- 高度越低越好

- 灰色组件表示未渲染（最优）

## 🔧 故障排查

### 问题1: 菜单切换仍然卡顿

**可能原因**:

1. 浏览器缓存未清除
2. 数据量过大
3. 其他页面组件性能问题

**解决方法**:

```bash
# 清除缓存重新构建
rm -rf .next
npm run dev
```

### 问题2: View Transitions不生效

**检查**:

1. `next.config.js` 中 `viewTransitions: true` 是否存在
2. 浏览器是否支持
3. 是否在开发模式

**测试**:

```bash
# 构建生产版本测试
npm run build
npm start
```

### 问题3: 数据仍然闪烁

**检查**:

1. React Query是否正确导入 `keepPreviousData`
2. 是否有其他组件在清除缓存
3. 网络请求是否过慢

**调试**:

```javascript
// 打开React Query DevTools查看
// 检查 placeholderData 是否正常工作
```
