# 数据库清空脚本使用说明

## 功能说明

`clear-database.ts` 脚本用于清空数据库中的所有业务数据，但会保留管理员账户，方便开发和测试。

## 保留的数据

- **管理员账户**: admin@inventory.com
  - 用户名: admin
  - 密码: admin123456
  - 角色: admin

## 删除的数据

脚本会删除以下所有业务数据：

1. 运输查询记录
2. 登录记录和账户锁定记录
3. 付款记录（应付款、付款记录）
4. 系统日志和设置变更日志
5. 系统设置
6. 订单序列
7. 往来账单和交易记录
8. 退款记录
9. 退货订单
10. 厂家发货订单
11. 收款记录
12. 库存调整记录
13. 库存操作记录
14. 出入库记录
15. 批次规格
16. 库存记录
17. 价格历史
18. 销售订单
19. 产品变体
20. 产品
21. 产品分类
22. 供应商
23. 客户
24. 非管理员用户

### 1. 清空数据库

```bash
npx tsx scripts/clear-database.ts
```

## 注意事项

⚠️ **警告**：此脚本会删除所有业务数据，请谨慎使用！

- 仅适用于开发和测试环境
- 生产环境禁止使用此脚本
- 执行前请确认已备份重要数据
- 脚本会保留管理员账户 (admin@inventory.com)

## 安全建议

1. 不要在生产环境执行此脚本
2. 执行前确认当前数据库连接
3. 建议在执行前做好数据库备份
4. 可以通过环境变量限制脚本只在开发环境运行

## 完整清理流程

```bash
# 1. 清空数据库
npx tsx scripts/clear-database.ts

# 2. 验证管理员账户
npx tsx scripts/verify-admin.ts

# 3. （可选）重新生成测试数据
npm run db:seed
```
