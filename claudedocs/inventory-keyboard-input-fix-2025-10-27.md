## 🐛 根本原因分析

**问题文件**: `app/(dashboard)/inventory/page-client.tsx`
**问题位置**: 第130-133行的 `useEffect` Hook

### 错误代码

```typescript
// ❌ 问题代码 (修复前)
React.useEffect(() => {
  if (searchTimerRef.current) return; // 如果有防抖定时器在运行,跳过
  if ((paramsSearch || '') !== (searchInput || ''))
    setSearchInput(paramsSearch || '');
}, [paramsSearch, searchInput]); // ⚠️ 监听了searchInput,导致问题
```

### 问题流程分析

1. **用户输入第一个字符** "测"
   - `handleSearch("测")` 被调用
   - `setSearchInput("测")` - 本地状态更新为"测"
   - **因为长度 < 2**, 不创建防抖定时器,直接 `return`
   - `searchTimerRef.current` 保持为 `null`

2. **组件重新渲染**
   - `useEffect` 触发 (因为 `searchInput` 从空字符串变为"测")
   - 检查条件: `searchTimerRef.current` 是 `null`, **不会 return**
   - 检查条件: `paramsSearch`(URL中的search,为空) !== `searchInput`("测") ✅ 满足
   - **执行**: `setSearchInput('')` - **把输入框重置为空!**

3. **结果**: 用户看到输入的字符立即消失,感觉"键盘输入没有效果"

### 为什么复制粘贴可以工作?

Playwright的 `.fill()` 方法和用户的复制粘贴都是**一次性设置完整值**:

- 不会触发多次 `onChange` 事件
- 如果粘贴的内容长度 ≥ 2,会创建防抖定时器
- 有定时器时,`useEffect` 的第一个条件 `if (searchTimerRef.current) return` 会阻止重置

但**键盘逐字输入**时:

- 每个字符都触发单独的 `onChange` 事件
- 单字符输入不创建定时器
- `useEffect` 每次都会把输入重置为空

## ✅ 修复方案

### 修复代码

```typescript
// ✅ 修复后的代码
React.useEffect(() => {
  // ✅ 修复BUG: 只在URL参数变化时同步本地状态,不在本地输入时触发
  // 之前的问题: 单字符输入时,因为不创建定时器,useEffect会把输入重置为空
  // 现在: 只有当paramsSearch变化且与当前输入不同时才更新
  if ((paramsSearch || '') !== (searchInput || '')) {
    setSearchInput(paramsSearch || '');
  }
}, [paramsSearch]); // ✅ 只监听paramsSearch,不监听searchInput
```

### 修复关键点

1. **移除 `searchTimerRef.current` 检查**:
   - 原来的检查逻辑不可靠(单字符输入时定时器为null)
   - 新方案不依赖定时器状态

2. **只监听 `paramsSearch`**:
   - 只在URL参数变化时同步状态(例如用户点击浏览器后退按钮)
   - 不监听 `searchInput`,避免本地输入触发重置

3. **保持状态同步逻辑**:
   - 仍然确保URL参数和本地状态的一致性
   - 只在真正需要同步时才更新状态

## 💡 技术要点总结

### React受控组件的陷阱

本次BUG的核心教训:

1. **受控组件的状态来源**:
   - 输入框的 `value` 应该只有**一个**数据源
   - 本例中是 `searchInput` 状态

2. **useEffect依赖数组的重要性**:
   - 监听了 `searchInput` 导致输入时触发效果
   - 应该只监听**外部数据源**的变化(URL参数)

3. **防抖与状态管理**:
   - 防抖定时器的存在不应该影响UI状态的正确性
   - 状态同步逻辑应该独立于防抖逻辑

### 正确的受控输入模式

```typescript
// ✅ 正确模式
const [localValue, setLocalValue] = useState(externalValue);

// 只在外部值变化时同步
useEffect(() => {
  setLocalValue(externalValue);
}, [externalValue]); // 只监听外部值

// 用户输入时立即更新本地状态
const handleChange = newValue => {
  setLocalValue(newValue); // 立即更新UI
  debouncedUpdate(newValue); // 防抖提交
};
```
