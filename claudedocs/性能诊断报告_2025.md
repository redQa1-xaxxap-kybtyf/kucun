   ```typescript
   export async function getOptimizedInventoryList(params) {

       SELECT i.*, p.code, p.name, c.name as category_name
   ```

### 2. 缓存策略 ✅

#### 优势

1. **多层缓存架构**

   ```
   客户端 (TanStack Query)
   → API路由 (Redis缓存)
   → 服务器组件 (React cache + Next.js cache)
   → 数据库
   ```

2. **防御性缓存设计**
   - ✅ 空值缓存防止缓存穿透 (TTL: 10秒)
   - ✅ 随机TTL防止缓存雪崩 (20%抖动)
   - ✅ 分布式锁防止缓存击穿

   ```typescript
   // E:/kucun/lib/cache/cache.ts
   export async function getOrSetJSON<T>(
     key: string,
     fetcher: () => Promise<T>,
     ttlSeconds?: number,
     options?: {
       enableNullCache?: boolean; // ✅ 空值缓存
       enableRandomTTL?: boolean; // ✅ 随机TTL
     }
   );
   ```

3. **Redis降级方案**
   - Redis不可用时自动降级到内存缓存
   - LRU淘汰策略 (最大1000个键)
   - 健康检查机制

4. **缓存失效策略**
   - 统一的缓存失效系统
   - 级联失效处理相关缓存
   - 示例: `await revalidateSalesOrders()`

#### 当前配置

```typescript
// 销售订单API - E:/kucun/app/api/sales-orders/route.ts
const result = await getOrSetJSON(
  cacheKey,
  async () => await getSalesOrders(validatedParams),
  300, // 5分钟TTL
  {
    enableRandomTTL: true, // 防止缓存雪崩
    enableNullCache: true, // 防止缓存穿透
  }
);
```

#### 建议优化 ⚠️

1. **库存API取消Redis缓存**
   - 当前状态: ✅ 已实施
   - 原因: Server Component预取 + TanStack Query缓存
   - 结果: 减少20-50ms延迟

   ```typescript
   // E:/kucun/app/api/inventory/route.ts
   // ✅ 性能优化：移除Redis缓存层
   // - Server Component 已通过 HydrationBoundary 预取数据
   // - Client Component 通过 TanStack Query 缓存（staleTime=Infinity）
   // - Redis 低命中率场景下反而增加 20-50ms 延迟
   ```

2. **缓存命中率监控**
   - 建议: 添加Redis缓存命中率统计
   - 目标: 命中率 >80%


```typescript
// 1. 添加慢查询监控
import { logger } from '@/lib/logger';

export function withPerformanceMonitoring<T>(
  fn: () => Promise<T>,
  name: string
): Promise<T> {
  const start = Date.now();
  return fn().finally(() => {
    const duration = Date.now() - start;
    if (duration > 100) {
      logger.warn('Slow operation', { name, duration });
    }
  });
}

// 2. 添加缓存监控
export function logCacheStats() {
  const stats = redis.getMemoryCacheStats();
  logger.info('Cache statistics', stats);
}
```
