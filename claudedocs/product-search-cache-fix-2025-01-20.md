# 产品搜索缓存失效问题修复报告

**报告时间**: 2025-01-20
**问题描述**: 入库成功后，产品搜索显示的库存数量不更新
**严重程度**: 🟡 中 - 影响用户体验，但不影响数据准确性
**修复状态**: ✅ 已修复

---

## 📋 问题概述

### 用户反馈

> "入库成功后的产品没有显示库存数量，产品中我输入3605显示库存是0但是我输入360库存就会有"

### 关键观察

1. 入库操作成功完成
2. 立即搜索产品时，库存显示不正确
3. 不同搜索关键词（"360" vs "3605"）显示不同的库存数量
4. 数据库中的库存数据是正确的

---

## 🔍 根本原因分析

### React Query缓存机制

React Query为每个查询生成唯一的缓存键：

- 搜索"360"：`['products', 'search', '360']`
- 搜索"3605"：`['products', 'search', '3605']`

### 问题场景重现

```
1. 用户搜索"360"
   → API返回产品3605（假设库存2000片）
   → React Query缓存: ['products', 'search', '360'] = {产品3605, 库存2000}

2. 用户选择产品3605，入库2000片
   → 数据库库存更新为4000片
   → 缓存失效：✅ inventory缓存失效
   → 缓存失效：❌ products.search缓存未失效！

3. 用户搜索"3605"
   → React Query查找缓存['products', 'search', '3605']
   → 缓存不存在（这是新的搜索词）
   → 发起API请求，返回最新数据（库存4000片）✅

4. 用户搜索"360"
   → React Query查找缓存['products', 'search', '360']
   → 缓存命中！返回旧数据（库存2000片）❌
```

### 核心问题

**入库成功后的缓存失效逻辑不完整**：

```typescript
// ❌ 修复前：只失效了inventory相关缓存
onSuccess: () => {
  queryClient.invalidateQueries({ queryKey: queryKeys.inventory.inbounds() });
  queryClient.invalidateQueries({ queryKey: queryKeys.inventory.all });
  // 缺少：产品搜索缓存失效
};
```

---

## 🛠️ 修复方案

### 代码修改

**文件**: `lib/api/inbound.ts:137-146`

```typescript
// ✅ 修复后：同时失效产品搜索缓存
onSuccess: () => {
  // 刷新入库记录列表
  queryClient.invalidateQueries({
    queryKey: queryKeys.inventory.inbounds(),
  });
  // 刷新库存数据
  queryClient.invalidateQueries({ queryKey: queryKeys.inventory.all });
  // ✅ 刷新产品搜索缓存，确保入库后搜索显示最新库存
  queryClient.invalidateQueries({ queryKey: queryKeys.products.all });
};
```

### 修复原理

使用 `queryKeys.products.all` 失效所有产品相关查询：

- `['products']` - 产品列表
- `['products', 'search', '360']` - 所有搜索缓存
- `['products', 'search', '3605']` - 所有搜索缓存
- `['products', 'detail', 'xxx']` - 所有产品详情

React Query的缓存失效是**级联的**：

- 失效 `['products']` 会同时失效所有以 `['products', ...]` 开头的缓存键

## 🎓 经验教训

### 1. React Query缓存失效的级联性 ⭐⭐⭐

**关键原则**：

- 使用 `queryKey` 的层级结构（如 `['products', 'search', query]`）
- 失效父级键会级联失效所有子级键
- 优先失效较高层级的键，避免遗漏

**最佳实践**：

```typescript
// ❌ 不推荐：逐个失效具体查询
queryClient.invalidateQueries({ queryKey: ['products', 'search', '360'] });
queryClient.invalidateQueries({ queryKey: ['products', 'search', '3605'] });
// ... 可能遗漏其他搜索词

// ✅ 推荐：失效顶层键，级联失效所有相关查询
queryClient.invalidateQueries({ queryKey: queryKeys.products.all });
```

### 2. 数据变更后的完整缓存失效策略

**原则**：识别所有受影响的数据视图

入库操作影响的数据：

1. ✅ 入库记录列表（已处理）
2. ✅ 库存数据（已处理）
3. ❌ 产品搜索结果（修复前遗漏）← **本次修复**
4. ⚠️ 产品详情页库存（可能需要检查）
5. ⚠️ 销售订单可用库存（可能需要检查）

**检查清单**：

- [ ] 入库操作
- [ ] 出库操作
- [ ] 库存调整
- [ ] 销售订单创建/取消
- [ ] 退货操作
