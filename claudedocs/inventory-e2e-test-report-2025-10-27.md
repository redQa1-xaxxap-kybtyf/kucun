**预期结果**: 显示库存偏低的产品

## 🐛 发现的BUG汇总

### BUG #1: 搜索不存在关键词仍显示数据（严重）

- **严重程度**: 🔴 高
- **影响范围**: 搜索功能核心逻辑
- **重现步骤**:
  1. 进入库存管理页面
  2. 搜索任意不存在的关键词
  3. 观察仍然显示所有产品数据
- **建议修复**:
  - 检查 API 路由 `/api/inventory` 的查询逻辑
  - 验证 Prisma 查询条件是否正确应用
  - 添加搜索结果的单元测试和集成测试

### BUG #2: 清空筛选功能失效（严重）

- **严重程度**: 🔴 高
- **影响范围**: 筛选功能用户体验
- **重现步骤**:
  1. 应用任意筛选条件（如"库存偏低"）
  2. 点击"清空筛选"按钮
  3. 观察URL参数未被清除
- **建议修复**:
  - 检查前端状态管理逻辑（`page-client.tsx`）
  - 确保点击"清空筛选"时正确调用路由更新
  - 可能需要检查 `useUrlParams` hook 的实现

### 潜在问题 #3: 库存状态分类不准确（中等）

- **严重程度**: 🟡 中
- **影响范围**: 库存状态显示和筛选一致性
- **现象**: 高库存产品被归类为"库存偏低"
- **建议调查**:
  - 检查库存阈值配置（env.ts 中的 `INVENTORY_DEFAULT_LOW_STOCK_THRESHOLD`）
  - 验证批次级别与产品级别的库存计算逻辑
  - 确保前端显示状态与后端筛选条件一致
