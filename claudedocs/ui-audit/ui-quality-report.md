## ⚠️ 需要改进的问题

### 1. **面包屑导航一致性问题** 🔴 P0

**问题描述**: 不同页面的面包屑导航存在中英文混合和格式不一致的问题

**具体案例**:
- ✅ **正确**: 库存管理页 → `首页 > 库存管理`
- ✅ **正确**: 产品管理页 → `首页 > 产品管理`
- ✅ **正确**: 客户管理页 → `首页 > 客户管理`
- ✅ **正确**: 退货订单页 → `首页 > 退货订单`
- ⚠️ **问题**: 销售订单页 → `首页 > 销售订单` (当前显示正常,但需要核查代码实现)
- ⚠️ **问题**: 财务账单页 → `首页 > 财务管理 > 往来账单` (三级结构需要验证一致性)

**影响范围**: 全局导航体验

**建议修复**:
1. 检查 `components/common/Breadcrumb.tsx` 中的 `PATH_TITLES` 映射表
2. 确保所有路由路径都有明确的中文标题定义
3. 统一面包屑层级结构(2级或3级)
4. 避免在页面组件中硬编码面包屑标题

### 2. **数据加载状态不统一** 🟡 P1

**问题描述**: 不同页面在加载数据时显示的状态提示不一致

**具体案例**:
- 销售订单: 显示"暂无数据"(表格空状态)
- 客户管理: 显示"暂无客户记录"(表格空状态)
- 退货订单: 显示"加载退货订单数据..."(带加载图标的动画)
- 财务账单: 显示"暂无往来账单"(带文档图标的空状态)

**影响**: 用户体验不统一,无法区分"正在加载"vs"真的没有数据"

**建议修复**:
1. 统一定义三种状态:
   - **加载中**: 显示骨架屏或加载动画 + "加载中..."文字
   - **空数据**: 显示图标 + "暂无XX数据"统一文案
   - **加载失败**: 显示错误图标 + 重试按钮
2. 创建统一的 `<EmptyState>` 和 `<LoadingState>` 组件
3. 在所有列表页面统一应用

### 3. **空状态图标使用不一致** 🟡 P1

**问题描述**: 空状态页面的图标设计和样式不统一

**具体案例**:
- 销售订单: 纯文字提示,无图标
- 客户管理: 纯文字提示,无图标
- 财务账单: 使用文档图标 + 文字提示

**建议修复**:
1. 为所有空状态页面添加统一的图标设计
2. 使用 shadcn/ui 的图标库保持风格一致
3. 可选择性添加空状态操作引导(如"新建第一个产品"按钮)

### 4. **按钮文案一致性问题** 🟢 P2

**问题描述**: 部分操作按钮的文案命名不够统一

**具体案例**:
- 产品管理: "新建产品"
- 客户管理: "新建客户"
- 退货订单: "新建退货单"
- 顶部栏: "新建"(全局按钮,可能需要根据上下文调整)

**建议**:
- 保持每个页面的主要操作按钮使用"新建XX"格式
- 顶部全局"新建"按钮可以保留,但建议添加下拉菜单显示可创建的内容类型

### 5. **表格操作列设计不统一** 🟢 P2

**问题描述**: 不同页面表格的"操作"列设计不一致

**具体案例**:
- 库存管理: 操作列显示"查看库存变动详情"文字按钮
- 产品管理: 操作列显示"打开菜单"(三点图标)
- 其他页面: 需要进一步检查

**建议修复**:
1. 统一使用三点菜单图标(...)
2. 菜单项包含常用操作(查看详情、编辑、删除等)
3. 避免在表格中放置过长的文字按钮

  icon?: React.ReactNode;
  title: string;
  description?: string;
  action?: React.ReactNode;
}

export function EmptyState({ icon, title, description, action }: EmptyStateProps) {
  return (
    <div className="flex flex-col items-center justify-center py-12">
      {icon && <div className="mb-4 text-gray-400">{icon}</div>}
      <h3 className="text-lg font-medium text-gray-900">{title}</h3>

  );
