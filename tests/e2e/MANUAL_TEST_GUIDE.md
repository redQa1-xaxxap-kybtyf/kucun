# 采购订单端到端测试 - 手动测试指南

## 测试环境
- 开发服务器：http://localhost:3001
- Prisma Studio：http://localhost:5555
- 测试账号：admin@example.com / admin123

## 测试前准备

### 1. 检查测试数据
打开 Prisma Studio (http://localhost:5555)，确认以下数据存在：

- **suppliers** 表：至少1个供应商
- **products** 表：至少2-3个产品

如果没有，请先创建测试数据。

### 2. 打开浏览器开发者工具
按 F12 打开开发者工具，切换到以下标签：
- **Console**：查看 JavaScript 错误
- **Network**：查看 API 请求和响应

## 测试步骤

### 第一步：登录系统
1. 访问 http://localhost:3001
2. 输入账号密码登录
3. **验证**：成功跳转到首页

### 第二步：创建采购订单

#### 2.1 访问创建页
1. 点击侧边栏"采购订单"
2. 点击"新建订单"按钮
3. **验证**：跳转到 `/purchase-orders/create`

#### 2.2 填写基本信息
1. 点击"选择供应商"下拉框
2. 选择一个供应商
3. 输入集装箱号：`TEST-CONTAINER-001`（可选）
4. 输入备注：`E2E测试订单`

#### 2.3 添加产品明细
**第一个产品**：
1. 点击"选择产品"下拉框
2. 选择一个产品
3. 选择供应商
4. 输入数量：`10`
5. 输入单价：`100`
6. **验证**：总价自动计算为 `1000`

**第二个产品**：
1. 点击"添加产品"按钮
2. 重复上述步骤
3. 输入数量：`5`
4. 输入单价：`200`
5. **验证**：总价自动计算为 `1000`

#### 2.4 添加费用项（可选）
1. 点击"添加费用"按钮
2. 选择费用类型：`运费`
3. 输入费用名称：`海运费`
4. 输入金额：`500`

#### 2.5 保存订单
1. 点击"保存草稿"按钮
2. **验证**：
   - 显示成功提示
   - 跳转到详情页
   - 订单号格式：`PO-20250104-0001`
   - 状态显示：`草稿`（灰色边框）
   - 所有数据正确显示

### 第三步：查看订单列表

#### 3.1 访问列表页
1. 点击侧边栏"采购订单"
2. **验证**：
   - 新创建的订单出现在列表中
   - 显示订单号、供应商、集装箱号、状态、金额、时间

#### 3.2 测试搜索功能
1. 在搜索框输入：`TEST-CONTAINER-001`
2. 等待1秒（防抖）
3. **验证**：列表只显示匹配的订单

#### 3.3 测试状态筛选
1. 点击"全部状态"下拉框
2. 选择"草稿"
3. **验证**：列表只显示草稿状态的订单

#### 3.4 测试供应商筛选
1. 点击"选择供应商"下拉框
2. 选择一个供应商
3. **验证**：列表只显示该供应商的订单

#### 3.5 测试日期范围筛选
1. 点击日期范围选择器
2. 选择今天的日期范围
3. **验证**：列表只显示今天创建的订单

#### 3.6 重置筛选
1. 点击"重置筛选"按钮
2. **验证**：所有筛选条件清空，显示全部订单

### 第四步：编辑订单

#### 4.1 进入编辑页
1. 在列表页找到刚创建的订单
2. 点击"编辑"按钮
3. **验证**：跳转到 `/purchase-orders/[id]/edit`

#### 4.2 修改订单信息
1. 修改集装箱号：`TEST-CONTAINER-001-EDITED`
2. 修改第一个产品的数量：`20`
3. **验证**：总价自动更新为 `2000`

#### 4.3 保存修改
1. 点击"保存"按钮
2. **验证**：
   - 显示成功提示
   - 跳转回详情页
   - 集装箱号显示为 `TEST-CONTAINER-001-EDITED`
   - 产品数量显示为 `20`

### 第五步：订单状态流转

#### 5.1 草稿 → 已下单
1. 在详情页点击"标记为已下单"按钮
2. **验证**：
   - 状态变为"已下单"（灰色）
   - 编辑按钮消失
   - 显示"标记为已发货"按钮

#### 5.2 已下单 → 已发货
1. 点击"标记为已发货"按钮
2. **验证**：
   - 状态变为"已发货"（蓝色）
   - 显示"标记为运输中"按钮

#### 5.3 已发货 → 运输中
1. 点击"标记为运输中"按钮
2. **验证**：
   - 状态变为"运输中"（蓝色）
   - 显示"标记为已到货"按钮

#### 5.4 运输中 → 已到货
1. 点击"标记为已到货"按钮
2. **验证**：
   - 状态变为"已到货"（黄色）
   - 显示"标记为已完成"按钮

### 第六步：验证成本核算

#### 6.1 查看成本核算卡片
1. 在详情页滚动到"成本核算"卡片
2. **验证**：
   - 产品总额 = 第一个产品总价 + 第二个产品总价
   - 费用总额 = 所有费用项之和
   - 总成本 = 产品总额 + 费用总额

#### 6.2 验证产品明细
1. 查看"产品明细"表格
2. **验证**：
   - 显示所有产品
   - 数量、单价、总价正确
   - 供应商信息正确

#### 6.3 验证费用明细
1. 查看"费用明细"卡片
2. **验证**：
   - 显示所有费用项
   - 费用类型、名称、金额正确

### 第七步：删除订单（仅草稿状态）

#### 7.1 创建新的草稿订单
1. 重复第二步创建一个新订单
2. 保持状态为"草稿"

#### 7.2 删除订单
1. 在详情页点击"删除"按钮
2. 在确认对话框点击"确认删除"
3. **验证**：
   - 显示成功提示
   - 跳转回列表页
   - 订单从列表中消失

#### 7.3 验证数据库
1. 打开 Prisma Studio
2. 查看 `purchase_orders` 表
3. **验证**：订单记录已删除
4. 查看 `purchase_order_items` 表
5. **验证**：关联的产品明细也被删除（级联删除）

## 错误处理测试

### 测试1：表单验证
1. 访问创建页
2. 不填写任何内容，直接点击"保存草稿"
3. **验证**：显示"供应商为必填项"错误提示

### 测试2：产品数量验证
1. 在产品明细中输入数量：`0`
2. 点击"保存草稿"
3. **验证**：显示"数量必须大于0"错误提示

### 测试3：非草稿订单不能编辑
1. 将订单状态改为"已下单"
2. 返回列表页
3. **验证**：该订单的"编辑"按钮不显示

### 测试4：非草稿订单不能删除
1. 访问非草稿状态订单的详情页
2. **验证**：删除按钮不显示

## 浏览器控制台检查

### Console 标签
- **验证**：无红色错误信息
- **允许**：蓝色 info 信息和黄色 warning

### Network 标签
1. 筛选 XHR/Fetch 请求
2. 检查以下 API：
   - `GET /api/purchase-orders` - 状态码 200
   - `POST /api/purchase-orders` - 状态码 200
   - `GET /api/purchase-orders/[id]` - 状态码 200
3. **验证**：无 404、500 错误

## 数据库验证

### 使用 Prisma Studio
1. 打开 http://localhost:5555
2. 查看 `purchase_orders` 表
3. **验证**：
   - 订单记录存在
   - 字段值正确
   - 时间戳正确

4. 查看 `purchase_order_items` 表
5. **验证**：
   - 产品明细记录存在
   - 关联的 `purchase_order_id` 正确
   - 数量、单价、总价正确

6. 查看 `expense_records` 表
7. **验证**：
   - 费用记录存在
   - `related_type` = 'purchase_order'
   - `related_id` 关联正确
