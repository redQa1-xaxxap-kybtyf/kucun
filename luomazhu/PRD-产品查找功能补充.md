## 一、功能定位与需求分析

### 1.1 双功能体系

小程序需要同时支持两个核心功能，形成完整的产品工具链：

| 功能     | 目标用户 | 使用场景                     | 核心价值                    |
| -------- | -------- | ---------------------------- | --------------------------- |
| 快速拼柱 | 新经销商 | 不知道怎么配砖，需要系统推荐 | 3步生成清单，零门槛使用     |
| 产品查找 | 老经销商 | 知道要什么产品，需要快速定位 | 直接搜索/筛选，快速查看详情 |

**功能关系：**

- 互补关系，不是竞争关系
- 新用户：快速拼柱 → 了解产品 → 后续直接查找
- 老用户：直接查找产品 → 快速拼柱验证

### 1.2 产品查找使用场景

**场景1：精确搜索（老经销商）**

```
用户知道产品编号"48A50" → 直接搜索 → 查看详情 → 添加到拼柱方案
```

**场景2：关键词搜索**

```
用户想找"欧式"风格产品 → 搜索"欧式" → 查看相关产品 → 选择添加
```

**场景3：分类浏览**

```
用户想看所有"柱身"图案 → 选择"柱身"分类 → 浏览产品列表 → 选择添加
```

**场景4：多条件筛选**

```
用户想找800mm高、可切、400宽的柱身 → 设置筛选条件 → 查看匹配产品 → 选择添加
```

**场景5：拼柱结果联动**

```
用户在拼柱结果中看到"48A50" → 点击查看详情 → 了解产品 → 返回继续拼柱
```

**场景6：快速添加**

```
用户在产品详情页看到满意产品 → 点击"添加到方案" → 自动填入拼柱流程
```

### 1.3 核心需求

**P0（必须有）：**

- [ ] 产品编号/名称搜索（支持模糊搜索）
- [ ] 按位置分类（柱身/底座/盖帽）
- [ ] 产品详情页（参数、图片、是否可切）
- [ ] 添加到拼柱方案

**P1（重要）：**

- [ ] 多条件筛选（高度、是否可切、面型宽度）
- [ ] 排序功能（编号、高度、使用频率）
- [ ] 最近浏览记录

**P2（可选）：**

- [ ] 收藏功能
- [ ] 产品对比
- [ ] 分享产品

### 3.1 接口设计

**请求参数：**

```

slot: string            # 位置（BODY/BASE/CAP/全部）
heightRange: string     # 高度范围（600/800/1000/全部）
cuttable: boolean       # 是否可切（true/false/全部）
faceWidth: number       # 面型宽度（200/400/全部）
page: number            # 页码
pageSize: number        # 每页数量
sortField: string       # 排序字段（code/height/usageCount）
sortOrder: string       # 排序方式（asc/desc）
```

### 3.2 搜索算法设计

#### 3.2.1 搜索匹配规则

**优先级1：精确匹配**

- 产品编号完全匹配（如"48A50"）
- 命中，直接返回结果

**优先级2：前缀匹配**

- 产品编号前缀匹配（如"48A"匹配"48A50"、"48A51"）
- 按使用频率排序

**优先级3：模糊匹配**

- 产品名称包含关键词（如"欧式"）
- 按相关度排序

**优先级4：拼音/拼音首字母匹配**

- 支持"Oushi"、"os"等拼音搜索
- 扩展搜索范围

#### 3.2.2 搜索性能优化

**索引设计：**

```
CREATE INDEX idx_material_code ON material(code);
CREATE INDEX idx_material_name ON material(name);
CREATE INDEX idx_material_slot ON material(slot);
CREATE INDEX idx_material_height ON material(height);
```

**缓存策略：**

```
- 热门搜索词缓存（Redis，TTL 1小时）
- 搜索结果缓存（Redis，TTL 5分钟）
- 产品详情缓存（Redis，TTL 30分钟）
```

**搜索建议：**

```
- 输入时实时提示搜索建议
- 展示最近搜索记录
- 展示热门搜索词
```
