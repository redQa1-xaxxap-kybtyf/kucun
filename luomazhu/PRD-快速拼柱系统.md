## 一、需求分析

### 1.1 核心目标

让用户通过快速拼柱流程，自动计算用砖高度、自动切割兜底，生成可直接使用的用砖清单。

### 1.2 产品定位

**SaaS 单品牌实例**

- 前台不出现品牌概念
- 规则、素材、可切属性全部后台配置

**核心特性**

- 高度自动算
- 切割自动算
- 默认切柱身，不可切再切柱尾
- 素材按位置固定
- 支持 1-4 面
- 支持面型（宽度不同但高度一致）

### 1.3 功能需求

- [ ] 输入目标高度
- [ ] 拼柱（选择素材、设置面型）
- [ ] 生成用砖清单（自动切割兜底）
- [ ] 修改切割位置

## 三、技术设计

### 3.1 系统定位

**SaaS 单品牌实例**

- 前台无品牌概念
- 规则、素材、可切属性全部后台配置

### 3.2 核心数据模型（抽象）

#### 3.2.1 Slot（位置）

```
BODY（柱身）
BASE（底座）
CAP（盖帽）
```

每个 Slot：

- 绑定可选素材集合
- 是否可切（布尔）

#### 3.2.2 FaceType（面型）

```json
{
  "id": "front",
  "width": 400,
  "faces": 1
}
```

一根柱子可有多个 FaceType，FaceType 内结构完全一致。

#### 3.2.3 Material（素材）

```json
{
  "code": "A-800",
  "slot": "BODY",
  "height": 800,
  "cuttable": true
}
```

### 3.3 核心计算逻辑

#### 3.3.1 单面高度计算

```
buildHeight =
  sum(bodySegments × bodyHeight)
+ baseHeight
+ capHeight
```

#### 3.3.2 高度差值

```
delta = buildHeight - targetHeight
```

判断逻辑：

- delta = 0 → 完美
- delta > 0 → 切割
- delta < 0 → 补高度（本期可仅提示）

### 3.4 切割规则（最终版）

#### 3.4.1 切割量

```
cutAmount = delta
```

系统唯一答案。

#### 3.4.2 切割优先级

```
柱身（可切）
柱尾 / 底座（兜底）
```

规则：

- 不可切素材直接跳过
- 不出现在切割候选中

#### 3.4.3 切割执行单位

**按面型**

同一面型内：

- 每面切割量一致
- 切割片数 = 面数

### 3.5 清单汇总规则

```
先算 单面
再按面型 × 面数汇总
```

汇总原则：

- 高度不乘
- 数量乘

## 附录

### 核心原则

1. **快速：** 3步完成拼柱，自动计算高度、自动切割
2. **自由：** 高度自由输入，面型自由配置（1-4面）
3. **兜底：** 系统自动计算切割方案，确保高度匹配
4. **简化：** 前台不出现品牌概念，素材按位置固定选择

### 关键逻辑

```
高度计算：buildHeight = body + base + cap
切割判断：delta = buildHeight - targetHeight
切割优先：柱身 → 底座
汇总规则：先算单面，再按面型×面数
```

### 一句话总结

通过3步快速拼柱流程，实现高度自动计算、切割自动兜底，支持多面型配置，生成可直接使用的用砖清单。
