## 一、需求分析

### 1.1 核心目标

让不懂罗马柱、不认识砖号的新经销商在3步内生成一份可直接使用的用砖清单

### 1.2 目标用户

**核心用户群体：**

- 新经销商
- 工程销售
- 门店导购
- 对罗马柱不熟悉但有项目需求的人

**用户已知信息（假设）：**

- 知道"我要做罗马柱"
- 知道"大概高度/粗细"
- 不知道具体砖型编号

### 1.3 功能需求

#### 1.3.1 核心功能

- [ ] Step 1：选择柱体类型（3种类型）
- [ ] Step 2：选择尺寸区间（高度区间 + 粗细）
- [ ] Step 3：生成用砖清单

#### 1.3.2 非功能需求（明确不做）

- ❌ 不做下单/支付
- ❌ 不要求用户理解砖型体系
- ❌ 不要求用户输入精确尺寸
- ❌ 不展示完整SKU列表

### 1.4 验收标准

**通过标准（必须全部满足）：**

- 新用户 3 次点击内看到用砖清单
- 全流程不出现完整产品列表
- 不要求输入砖编号
- 清单可直接截图使用

## 二、产品设计

### 2.1 整体流程

```
START
 ↓
Step1_SelectColumnType（选择柱体类型）
 ↓
Step2_SelectSizeRange（选择尺寸区间）
 ↓
Step3_GenerateBrickList（生成用砖清单）
 ↓
END
```

### 2.2 页面设计

#### 2.2.1 Step 1 - 选择柱体类型

**页面路径：** `/pages/column/type`

**页面目的：**
把用户的"模糊需求"映射到系统内置方案类型，不出现任何砖编号

**UI 结构：**

```
[ 标准装饰罗马柱 ]
[ 工程加厚柱 ]
[ 半柱 / 贴墙柱 ]
```

**交互规则：**

- 必选一项
- 点击即进入 Step 2
- 本页不支持跳过

**数据结构：**

```json
{
  "columnType": "STANDARD"
}
```

**可选值：**
| 值 | 含义 |
|----|------|
| STANDARD | 标准装饰罗马柱 |
| ENGINEERING | 工程加厚柱 |
| HALF | 半柱/贴墙柱 |

---

#### 2.2.2 Step 2 - 选择尺寸区间

**页面路径：** `/pages/column/size`

**页面目的：**
用区间选择代替精确尺寸，降低用户决策成本

**UI 结构：**

```
① 高度区间（必选）
◉ 常规高度（2.8-3.0m）
○ 加高柱（3.2-3.6m）
○ 定制高度（>3.6m）

② 粗细（必选）
◉ 常规柱
○ 加厚柱
```

**数据结构：**

```json
{
  "heightRange": "H_3000",
  "thickness": "NORMAL"
}
```

**字段定义：**
| 字段 | 可选值 |
|------|--------|
| heightRange | H_3000 / H_3400 / H_CUSTOM |
| thickness | NORMAL / THICK |

---

#### 2.2.3 Step 3 - 生成用砖清单

**页面路径：** `/pages/column/result`

**页面结构：**

```
你选择的是：
- 标准装饰罗马柱
- 高度约 3 米
- 常规柱体

【系统推荐方案】
标准罗马柱方案 A

【用砖清单】
中柱件：48A50 × 6
双边柱：48B50 × 4
收边柱：48C50 × 2
线条：15C20 × 1
```

**允许的操作（不强制）：**

- 查看砖型图片
- 切换同级方案（如加厚）
- 保存方案（本地/服务端）
- 分享方案（生成图片）

## 三、技术设计

### 3.1 接口设计

#### 3.1.1 生成用砖方案接口

**接口名称：** `POST /api/column/generate-scheme`

**请求参数：**

```json
{
  "columnType": "STANDARD",
  "heightRange": "H_3000",
  "thickness": "NORMAL"
}
```

**后端处理逻辑：**

1. 根据 `columnType + heightRange + thickness`
2. 匹配 `scheme_master` 表
3. 获取 `scheme_id`
4. 查询 `scheme_items` 表
5. 返回用砖清单 + 方案信息

**返回数据结构：**

```json
{
  "schemeId": "S3000-A",
  "schemeName": "标准罗马柱方案 A",
  "description": "适用于常规家装罗马柱",
  "brickList": [
    {
      "role": "中柱件",
      "brickCode": "48A50",
      "quantity": 6
    },
    {
      "role": "双边柱",
      "brickCode": "48B50",
      "quantity": 4
    },
    {
      "role": "收边柱",
      "brickCode": "48C50",
      "quantity": 2
    },
    {
      "role": "线条",
      "brickCode": "15C20",
      "quantity": 1
    }
  ]
}
```

### 3.2 数据库设计

#### 3.2.1 scheme_master（方案表）

| 字段         | 类型    | 说明     |
| ------------ | ------- | -------- |
| scheme_id    | VARCHAR | 方案ID   |
| column_type  | VARCHAR | 柱体类型 |
| height_range | VARCHAR | 高度区间 |
| thickness    | VARCHAR | 粗细     |
| name         | VARCHAR | 方案名称 |
| description  | TEXT    | 说明     |

#### 3.2.2 scheme_items（方案明细表）

| 字段       | 类型    | 说明     |
| ---------- | ------- | -------- |
| scheme_id  | VARCHAR | 方案ID   |
| role       | VARCHAR | 砖角色   |
| brick_code | VARCHAR | 砖型编号 |
| quantity   | INT     | 数量     |

### 3.3 异常处理

#### 3.3.1 未匹配到方案

**返回数据：**

```json
{
  "error": "NO_SCHEME",
  "message": "当前条件暂无标准方案"
}
```

**前端提示：**
"该高度为定制方案，请联系厂家支持"
