《新经销商 3 步找到用砖清单》开发文档

版本：v1.0
适用对象：罗马柱瓷砖系统（产品数量极多场景）

1. 功能目标（必须写在文档最前）
1.1 核心目标

让不懂罗马柱、不认识砖号的新经销商
在 3 步内生成一份可直接使用的用砖清单

1.2 非目标（明确不做）

❌ 不做下单 / 支付

❌ 不要求用户理解砖型体系

❌ 不要求用户输入精确尺寸

❌ 不展示完整 SKU 列表

2. 用户画像与使用前提
2.1 目标用户

新经销商

工程销售

门店导购

对罗马柱不熟悉但有项目需求的人

2.2 用户已知信息（假设）

知道「我要做罗马柱」

知道「大概高度 / 粗细」

不知道具体砖型编号

3. 整体流程总览（状态机）
START
 ↓
Step1_SelectColumnType
 ↓

 ↓
Step3_GenerateBrickList
 ↓
END

4. STEP 1｜选择柱体类型
4.1 页面说明

页面名称：选择柱体类型
页面路径：/pages/column/type

4.2 页面目的

把用户的“模糊需求”映射到系统内置方案类型

不出现任何砖编号

4.3 页面 UI 结构（逻辑）
[ 标准装饰罗马柱 ]
[ 工程加厚柱 ]
[ 半柱 / 贴墙柱 ]

4.4 数据结构（前端）
{
  "columnType": "STANDARD" 
}


可选值：

值	含义
STANDARD	标准装饰罗马柱
ENGINEERING	工程加厚柱
HALF	半柱 / 贴墙柱
4.5 交互规则

必选一项

点击即进入 Step 2

本页不支持跳过

5. STEP 2｜选择尺寸区间（模糊输入）
5.1 页面说明

页面名称：选择柱体尺寸
页面路径：/pages/column/size

5.2 页面目的

用区间选择代替精确尺寸

降低用户决策成本

5.3 页面 UI 结构
① 高度区间（必选）
◉ 常规高度（2.8–3.0m）
○ 加高柱（3.2–3.6m）
○ 定制高度（>3.6m）

② 粗细（必选）
◉ 常规柱
○ 加厚柱

5.4 数据结构（前端）
{
  "heightRange": "H_3000",
  "thickness": "NORMAL"
}

字段	可选值
heightRange	H_3000 / H_3400 / H_CUSTOM
thickness	NORMAL / THICK
6. STEP 3｜生成用砖清单（核心）
6.1 页面说明

页面名称：用砖清单
页面路径：/pages/column/result

6.2 后端接口设计（关键）
接口名称
POST /api/column/generate-scheme

请求参数
{
  "columnType": "STANDARD",
  "heightRange": "H_3000",
  "thickness": "NORMAL"
}

6.3 后端处理逻辑（必须按这个来）
1. 根据 columnType + heightRange + thickness
2. 匹配 scheme_master 表
3. 获取 scheme_id
4. 查询 scheme_items 表
5. 返回用砖清单 + 方案信息

6.4 返回数据结构（标准）
{
  "schemeId": "S3000-A",
  "schemeName": "标准罗马柱方案 A",
  "description": "适用于常规家装罗马柱",
  "brickList": [
    {
      "role": "中柱件",
      "brickCode": "48A50",
      "quantity": 6
    },
    {
      "role": "双边柱",
      "brickCode": "48B50",
      "quantity": 4
    },
    {
      "role": "收边柱",
      "brickCode": "48C50",
      "quantity": 2
    },
    {
      "role": "线条",
      "brickCode": "15C20",
      "quantity": 1
    }
  ]
}

7. 用砖清单页面展示规则
7.1 页面结构
你选择的是：
- 标准装饰罗马柱
- 高度约 3 米
- 常规柱体

【系统推荐方案】
标准罗马柱方案 A

【用砖清单】
中柱件：48A50 × 6
双边柱：48B50 × 4
收边柱：48C50 × 2
线条：15C20 × 1

7.2 允许的操作（不强制）

查看砖型图片

切换同级方案（如加厚）

保存方案（本地 / 服务端）

分享方案（生成图片）

8. 数据库表（最小实现）
8.1 scheme_master（方案表）
字段	说明
scheme_id	方案ID
column_type	柱体类型
height_range	高度区间
thickness	粗细
name	方案名称
description	说明
8.2 scheme_items（方案明细）
字段	说明
scheme_id	方案ID
role	砖角色
brick_code	砖型编号
quantity	数量
9. 兜底与异常处理
9.1 未匹配到方案

返回：

{
  "error": "NO_SCHEME",
  "message": "当前条件暂无标准方案"
}


前端提示：

“该高度为定制方案，请联系厂家支持”
